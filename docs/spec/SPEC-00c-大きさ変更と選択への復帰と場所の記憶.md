# SPEC-00c: 大きさの変更、選択への自動復帰、前回の場所の記憶

## 実行モデル指定（必須）

- モデル: `gpt-5.6-sol`
- reasoning effort: `high`
- 選定理由: 書き込みの操作（SPEC-00b-2）の続きで、複数のファイルにまたがる操作の追加と、ブラウザの保存領域の扱いを含むため

---

## 目的

公開した試作版を利用者が触った結果、次の要望が出た。これに応える。

1. 四角を作った後に、大きさを変えられない。
2. 文字や四角を作り終えたら、自動で「選択」ツールに戻ってほしい。
3. 一度 PDF を開いたら、次に開くときは前回の場所から始めたい。

あわせて、狭い画面幅でツールバーのボタンの文字が2行に折り返す問題を直す。

最初に `docs/要件と設計方針.md`、`docs/spec/SPEC-00b-2-書き込み操作と保存の画面.md`、今の `src/editor/`、`src/App.tsx` を読むこと。

## 変更内容

### 1. 大きさの変更（選択ツール）

- **四角を選んでいるとき**
  - 四隅と四辺の中央に、**取っ手を8個**表示する。
    - 画面上の大きさは、倍率に関係なく 8×8 CSS px とし、白地に青い枠にする。
    - SVG の中で描く場合は、pt 単位の大きさを倍率から計算する。
  - 取っ手をドラッグすると、大きさが変わる。反対側の辺（隅なら反対側の隅）は動かさない。
  - 最小は 4pt×4pt。反対側を越えてドラッグしたら、そこで止める（裏返さない）。
  - マウスカーソルは、場所に応じた形にする（`nwse-resize`、`nesw-resize`、`ew-resize`、`ns-resize`）。
- **文字を選んでいるとき**
  - 左右の辺の中央に取っ手を2個表示し、幅だけを変えられるようにする。最小は 20pt。
  - 離したら、`pool.layoutText(text, fontSize, 新しい幅)` で配置を計算し直し、`height` から rect の高さを決める。
- ドラッグ中は、SPEC-00b-2 と同じく **React の state を更新せず**、ref と requestAnimationFrame で SVG の属性を書き換える。ストアへの反映は `pointerup` のときだけにする。
- ストアに `resize(id, rect)` を追加する。既存の注釈なら、touch と同じ扱いにする（下地から除き、`dirty` にする）。
- 取っ手は、移動のドラッグより優先して反応するようにする。

### 2. 作り終えたら「選択」に戻る

- 四角ツールで四角を作り終えた（`pointerup` で作成した）とき、ツールを「選択」に戻し、作った四角を選んだ状態にする。
- 文字ツールで入力を確定したとき、ツールを「選択」に戻し、作った文字を選んだ状態にする。
  - 本文が空で書き込みを消した場合も、「選択」に戻す。選んだ状態にはしない。
- 既存の文字をダブルクリックして書き直した場合は、もともと選択ツールなので、そのまま選んだ状態を保つ。
- ツールバーの表示（今のツールを目立たせる表示）も、それに合わせて切り替える。

### 3. 前回の場所の記憶

- **開くとき**
  - `showOpenFilePicker` に `id: 'karu-pdf-open'` を渡す。
  - 前回開いたファイルのハンドルが保存されていれば、`startIn` にそのハンドルを渡す。これでファイル選択の画面が、そのファイルのフォルダから始まる。
- **別名で保存するとき**
  - `showSaveFilePicker` に `id: 'karu-pdf-save'` を渡す。
  - 今開いているファイルのハンドルがあれば、`startIn` に渡す。
- **ハンドルの保存**（`recentStore.ts`）
  - 開いたファイルのハンドル（「開く」ボタンでも、ドラッグ＆ドロップでも）を、IndexedDB（データベース名 `karu-pdf`、ストア名 `handles`、キー `lastOpened`）に保存する。
  - 保存するのはハンドル、ファイル名、日時だけで、**ファイルの中身は保存しない**。
- **前回見ていた位置の復元**
  - 文書ごとに「最後に見ていたページ番号と、倍率」を localStorage（キー `karu-pdf:view`）に保存する。
    - 保存するのは、スクロールが止まってから 500ms 後と、別のファイルを開く直前。
  - 文書の識別子は「ファイル名 + バイト数」とする。
  - 50件を上限とし、古いものから消す。
  - 同じ文書を開いたら、そのページと倍率に戻す。ページが無ければ（ページ数が減った場合）1ページ目にする。
  - 開いてから1ページ目の表示までの時間（試作の基準①）を悪くしないこと。復元先のページから描き始める。
- IndexedDB と localStorage の読み書きは、すべて try/catch で包む。使えない環境（プライベートウィンドウなど）では、記憶せずに普段どおり動くようにする。
- `startIn` にハンドルを渡して例外になった場合（ファイルが消えた、移動したなど）は、`startIn` なしで開き直す。

### 4. ツールバーの折り返し

- ツールバーのボタンの文字は折り返さない（`white-space: nowrap`）。
- 画面の幅が足りないときは、ツールバー全体を2段に折り返す（`flex-wrap: wrap`）。ボタンの中の文字は折り返さない。

## 禁止事項

- 対象外のファイルを変更しないこと。git の操作をしないこと。
- ファイルの中身を、IndexedDB と localStorage に保存しないこと。
- ドラッグ中に、マウスの動きごとに React の state を更新しないこと。
- 自分で起動したサーバーは必ず止めること。一時ファイルは削除すること。

## テスト

- `tests/AnnotationStore.test.ts`: `resize` の反映（新規と既存）、既存を resize したら下地から除く対象になること、`toEdits` の中身。
- `tests/recentStore.test.ts`: 見ていた位置の保存、読み出し、50件の上限、localStorage が例外を投げる環境でも落ちないこと。localStorage はテストの中で差し替えてよい。
- `e2e/annotate.spec.ts` に追加する。
  1. 四角ツールで四角を作る → ツールが「選択」になり、その四角が選ばれている → 右下の取っ手をドラッグして大きくする → 保存して開き直し、大きさが変わっていることを確かめる。
  2. 文字ツールで文字を作って確定する → ツールが「選択」になる → 右辺の取っ手で幅を狭める → 行数が増え、高さが大きくなることを確かめる。
- `e2e/resume.spec.ts`
  - `sample-small.pdf` を開いて、3ページ目まで進め、倍率を 150% にする。
  - ページを再読み込みして同じファイルを開き、3ページ目と 150% に戻ることを確かめる。
  - ファイル選択の画面は Playwright では出せないため、`showOpenFilePicker` に渡す引数（`id` と `startIn`）を確かめるテストは、`window.showOpenFilePicker` を差し替えて行う。
