## 変更内容

### 1. 注釈の種類の追加（`src/core/annotations.ts`）

`AnnotationEdit` と `AnnotationInfo` に、次の種類を追加する。どれも、外観は MuPDF の `update()` に作らせる（フォントを使わないため）。

| 種類 | PDF の注釈 | 主な属性 |
|---|---|---|
| 線 | Line | `line: [Point, Point]`、`color`、`borderWidth`、`lineEnding: {start, end}`（'None' か 'OpenArrow'） |
| 矢印 | Line | 線と同じで、終点を 'OpenArrow' にする |
| 丸 | Circle | `rect`、`color`、`borderWidth`、`interiorColor: null` |
| 蛍光ペン | Ink | `inkList: Point[][]`、`color`（既定は黄）、`borderWidth`（既定 12pt）、`opacity`（既定 0.35） |
| 手書き | Ink | `inkList`、`color`、`borderWidth`（既定 1.5pt）、`opacity: 1` |
| 白塗り | Square | `rect`、`interiorColor: [1,1,1]`、`color: []`（枠なし）、`borderWidth: 0` |

- 既存の Square の編集（`createSquare`、`updateSquare`）に、`interiorColor`（省略時は塗りなし）を追加する。
- Ink は `setInkList`、Line は `setLine` と `setLineEndingStyles`、透明度は `setOpacity` を使う。
- 蛍光ペンと手書きは、同じ Ink 注釈である。画面の側で区別するため、`AnnotationInfo` に `opacity` を含める（opacity が 1 未満なら蛍光ペンとして扱う）。
- 白塗りは、`interiorColor` が白で枠が無い Square として扱う（`AnnotationInfo.kind` の判定に使う）。
- **FreeText の書体**
  - `font: 'BIZUDGothic' | 'BIZUDMincho'` にする。
  - `FontResource` を書体ごとに持ち、Worker 0 は必要になったときに `public/fonts/BIZUDMincho-Regular.ttf` を読み込む。
  - `AnnotationInfo` に `fontName` を追加する（DA から読む）。
  - 外観の作り方（一時文書でサブセット化してから移す）は SPEC-00b-1 のままとし、書体ごとに別のフォントとして埋め込む。
- 他のソフトで作られた Line、Circle、Ink も `editable: true` とし、移動・大きさの変更・削除・色と太さの変更ができるようにする。

### 2. 道具と操作（`src/editor/`）

- **ツール**と、入力欄を開いていないときのキー:

| ツール | キー |
|---|---|
| 選択 | V |
| 文字 | T |
| 線 | L |
| 矢印 | A |
| 四角 | R |
| 丸 | O |
| 蛍光ペン | H |
| 手書き | P |
| 白塗り | W |

- ツールバーには、ツールのボタンを、文字（アイコンは作らない）で並べる。
- **線・矢印**
  - ドラッグで、始点から終点まで引く。`Shift` を押している間は、角度を 0°・45°・90° の倍数に揃える。
  - 選んだときは、両端に取っ手を出し、端をドラッグで動かせるようにする。線の上をドラッグすると、全体が動く。
  - 当たり判定は、線から 4 CSS px 以内とする。
- **丸**
  - ドラッグで外接する四角を決める。`Shift` で正円にする。
  - 選んだときの取っ手は、四角と同じ8個にする。
- **白塗り**
  - ドラッグで四角を描く。白で塗りつぶし、枠は描かない。
  - 選んでいるときだけ、点線の枠を表示する（白い紙の上で見えるようにするため）。
  - 取っ手は四角と同じにする。
- **蛍光ペン・手書き**
  - ドラッグの軌跡を線として描く。
  - `pointermove` の点は ref に溜め、SVG の `<polyline>` の `points` を requestAnimationFrame で更新する。
  - 描き終えたら、間引き（Ramer–Douglas–Peucker、許容誤差 0.5pt）をしてからストアへ入れる。
  - **同じページで、前の線を描き終えてから 1.5 秒以内に描き始めた線は、同じ注釈の `inkList` に加える**（手書きの1文字が1つの注釈になるように）。
  - 選んだときは外接する四角に8個の取っ手を出し、全体を拡大縮小と移動できるようにする。
- **作り終えた後のツール**
  - 文字・線・矢印・四角・丸・白塗りは、作り終えたら「選択」に戻り、作ったものを選んだ状態にする（SPEC-00c と同じ）。
  - **蛍光ペンと手書きは、続けて描けるよう、描き終えてもツールを保つ。** `Esc` か「選択」で戻る。
- ドラッグ中（作成、移動、大きさの変更、手書き）は、React の state を更新しない（SPEC-00b-2 の決まり）。

### 3. 書式パネル（`src/app/FormatPanel.tsx`）

- 表示する項目は、ツールや、選んでいる書き込みの種類で切り替える。

| 種類 | 色 | 太さ | 文字の大きさ | 書体 |
|---|---|---|---|---|
| 文字 | ○ | ― | ○ | ○（ゴシック／明朝） |
| 線・矢印・四角・丸 | ○ | ○（0.5、1、1.5、2、3、5 pt） | ― | ― |
| 手書き | ○ | ○（0.5、1、1.5、2、3、5 pt） | ― | ― |
| 蛍光ペン | ○（黄、緑、水色、桃の4色） | ○（6、9、12、18 pt） | ― | ― |
| 白塗り | ― | ― | ― | ― |

- 初期値はツールごとに保存する（localStorage の `karu-pdf:format` を、ツールごとの値を持つ形に広げる。古い形の値も読めるようにする）。

### 4. 元に戻す／やり直し（`src/editor/AnnotationStore.ts`、`src/editor/history.ts`）

- 操作1回（作成、移動、大きさの変更、書式の変更、文字の書き直し、削除）を、履歴の1手とする。
  - 1手には、影響した注釈の「前の状態」と「後の状態」を記録する。
  - 既存の注釈に触れただけ（選んだだけ）の操作は、履歴に入れない。
- `Ctrl+Z` で元に戻す。`Ctrl+Y` と `Ctrl+Shift+Z` でやり直す。ツールバーに「元に戻す」「やり直し」のボタンを置き、できないときは押せないようにする。
- 履歴はタブ（文書）ごとに持ち、100 手までとする。
- 文字の入力欄を開いている間は、`Ctrl+Z` を入力欄に任せる（ストアの履歴は動かさない）。
- **保存後の扱い**（ストアは「最後に反映した状態」との差から `toEdits()` を作る）
  - 保存済み（objNum あり）の作成を元に戻したら、次の保存で `delete` を送る。
  - 保存済みの削除を元に戻したら、その注釈は文書から消えている。そのため objNum を null にし、次の保存で `create…` として作り直す。
  - 保存済みの移動や書式の変更を元に戻したら、`update…` を送る。
- 新しい操作をしたら、やり直しの履歴は消す。

## 禁止事項

- 対象外のファイルを変更しないこと。git の操作をしないこと。
- ドラッグ中に、React の state を更新しないこと。
- 自分で起動したサーバーは必ず止めること。一時ファイルは削除すること。

## テスト

- **Node の結合テスト**（`tests/annotations.integration.test.ts` に追加）
  - 線（矢印あり）、丸、蛍光ペン（opacity 0.35）、手書き（2本の線）、白塗り、明朝の文字を作って保存し、開き直して属性（点、色、太さ、線端、opacity、interiorColor、fontName）が戻ることを確かめる。
  - 明朝の文字の外観に `BIZUDMincho` のサブセットが埋め込まれていること。
- **PDFium の確認**（`tests/pdfium.compat.test.ts` に追加）
  - 上の各注釈が、PDFium で描いても見える（その色に近い画素がある）こと。白塗りは、下の内容が隠れていること。
- **単体テスト**: 履歴（戻す、やり直す、新しい操作でやり直しが消える、100手の上限）、保存後の戻しで作られる `toEdits()`（上の3つのケース）、間引き、1.5 秒以内の線の結合。
- **画面のテスト（e2e）**
  - 各ツールで1つずつ作る → 保存して開き直す → すべてがあることを確かめる。
  - 手書きで、1秒以内に2本の線を描く → 注釈が1つで inkList が2本であることを確かめる。
  - 四角を作る → 移動 → `Ctrl+Z` で元の位置 → `Ctrl+Y` で移動後に戻る。
  - 保存後に作成を元に戻して保存 → 開き直すと消えていることを確かめる。
- **性能**（`e2e/perf-edit.spec.ts` に追加）: A1（400%）の上で手書きを2秒描いたときの、フレーム間隔の p95 と最大値を計測する（目標: p95 ≤ 20ms、最大 ≤ 50ms）。
