# SPEC-01e: 塗りつぶし、吹き出し、文字の背景と枠、直線の蛍光ペン

## 実行モデル指定（必須）

- モデル: `gpt-5.6-sol`
- reasoning effort: `high`
- 選定理由: 注釈の中核（FreeText の自前の外観に、吹き出しの引き出し線と枠を加える）と、画面の操作・書式パネルの両方にまたがる新機能のため

---

## 目的

第1版を触った利用者から、次の要望が出た。

1. 四角の中を塗りつぶしたい。**これができれば、白塗りの道具は要らない。**
2. 図の一部を指して指摘を残せるよう、吹き出し（矢印つきのコメント）を使いたい。
3. 文字にも、背景色と枠線の色を設定したい。
4. 蛍光ペンで、Ctrl を押しながら線を引くと直線にしたい。

最初に次を読むこと。
- `docs/要件と設計方針.md`（第4章）
- SPEC-00b-1（FreeText の外観の作り方）、SPEC-01b（道具と書式パネル）、SPEC-01d
- 今の `src/core/annotations.ts`、`src/editor/`、`src/app/FormatPanel.tsx`、`src/app/HelpDialog.tsx`

## 対象

- 変更してよいファイル: `src/core/annotations.ts`、`src/worker/`、`src/client/PdfWorkerPool.ts`、`src/editor/`、`src/app/`、`src/App.tsx`、`src/styles.css`、`tests/`、`e2e/`

## 変更内容

### 1. 四角と丸の塗りつぶし（白塗りの道具を廃止）

- 四角と丸の書式に、次を加える。
  - **塗り**: なし＋8色（今の色見本と同じ）。初期値は「なし」
  - **枠線の色**: なし＋8色。初期値は「赤」
  - **透明度**: 100%、50%、25%。注釈全体の `/CA` として保存する。初期値は 100%
  - 太さは今のまま
- PDF では、塗りは `interiorColor`（`/IC`）で、枠線の色は `color`（`/C`、「なし」は `[]`）で表す。枠線の色が「なし」のときは、`borderWidth` を 0 にする。
- **白塗りの道具（W キー）を廃止する。**
  - 四角の書式パネルに「白塗りにする」ボタンを置く。押すと、塗りを白、枠線をなし、透明度を 100% にする。
  - ツールチップに「上に白い四角を重ねて見えなくします。下の文字やデータはファイルに残ります」と出す。
- これまでに作った白塗り（白で塗りつぶし、枠のない Square）は、四角として読み込み、塗りと枠線の設定で編集できるようにする。`Kind` の `'whiteout'` は、読み込みの互換のためだけに残すか、四角へ統合する（統合を推奨）。
- 選んでいるときは、どの図形も点線の外接枠を表示する（枠線が「なし」でも位置が分かるように）。
- 重ね表示（SVG）でも、塗りと透明度を同じように描く。

### 2. 文字の背景と枠

- 文字（FreeText）の書式に、次を加える。
  - **背景色**: なし＋8色。初期値は「なし」
  - **枠線の色**: なし＋8色。初期値は「なし」
  - **枠線の太さ**: 0.5、1、1.5、2 pt。初期値は 1pt
- 外観（自前で作る AP）で、背景を塗り、枠線を描いてから文字を描く。枠は、注釈の Rect の内側に線の太さの半分だけ入れて描く。
- 保存のしかた:
  - 枠線の太さは `/BS << /W … >>` に入れる。
  - 背景色と枠線の色は、他のソフトとの互換のため、標準のキーに入れられる範囲で入れる。どのキーを使うかは、MuPDF と PDFium での見え方を確かめて決め、報告する。
  - かるPDF で確実に読み戻せるよう、`/KaruStyle << /Fill [r g b] /Border [r g b] /BorderWidth w >>` にも記録する（色が「なし」なら、そのキーを入れない）。
  - 読み込むときは `/KaruStyle` を優先し、無ければ標準のキーから推定する。
- 重ね表示と入力欄も、背景と枠を表示する。

### 3. 吹き出し（引き出し線つきのコメント）

- 新しい道具「吹き出し」（キー `C`）
  1. 指摘したい点でマウスを押す。
  2. 文字の枠を置きたい所までドラッグして離す。
  3. 離した位置を左上として、幅 160pt の文字の枠を作り、すぐに入力欄を開く。
  - ドラッグせずにクリックだけした場合は、クリックした点から右上に 40pt 離れた位置に枠を作る。
  - 確定したら、「選択」に戻り、作った吹き出しを選んだ状態にする（本文が空なら消す）。
- **PDF での表し方**: FreeText に `setIntent('FreeTextCallout')` を設定する。
  - `setCalloutLine`: 指した点 → 枠の辺の中点。枠の辺は、4辺の中点のうち、指した点に最も近いものを選ぶ。
  - `setCalloutStyle('OpenArrow')`: 指した点の側を矢印にする。
  - `/Rect` は、枠と引き出し線の両方を含む範囲にする。`/RD` で、枠の位置を表す。
- **外観**（自前で作る AP）: 次の順に描く。どれも1つの外観にまとめ、BIZ UD の埋め込みとサブセット化は今の方式（SPEC-00b-1 の方式 A）のままとする。
  1. 背景
  2. 枠線
  3. 文字
  4. 引き出し線と矢印（線と矢印の色は枠線の色。枠線が「なし」なら文字の色）
- 書式の初期値（吹き出しの道具）: 文字は赤・10.5pt・ゴシック、背景は白、枠線は赤・1pt。
- **選んでいるとき**
  - 枠の移動と幅の変更は、文字と同じようにする。
  - 指した点に取っ手を出し、ドラッグで動かせるようにする。
  - 枠を動かしたら、引き出し線の接続先（最も近い辺の中点）を計算し直す。
- 他のソフトで作られた吹き出し（`FreeTextCallout`）も、編集できる注釈として読み込む（指した点、引き出し線、本文、書式）。
- 書式パネルの項目は「文字」と同じ（色、大きさ、書体、背景色、枠線の色、枠線の太さ）。

### 4. 直線の蛍光ペン（と手書き）

- 蛍光ペンと手書きで、**Ctrl を押しながらドラッグすると、始点から今の点までの直線**にする。
  - `Ctrl+Shift` のときは、0°・45°・90° の倍数に揃える。
- 直線にした線は、2点の Ink の線として保存する。1.5 秒以内の線の結合（SPEC-01b）は、直線にも同じく適用する。
- 描いている途中で Ctrl を押したり離したりしたら、その時点の状態で切り替える（押したら直線、離したら自由な線）。

### 5. 使い方の画面

- 塗り、白塗りにするボタン（下の文字は残ること）、吹き出し、文字の背景と枠、Ctrl で直線、を追記する。
- W キーの記載を消し、C キーを加える。

## テスト

- **Node の結合テスト**
  - 塗り・枠線なし・透明度 50% の四角と丸を保存して開き直し、`/IC`、`/C`、`/CA`、枠の太さが戻る。
  - 背景と枠つきの文字、吹き出しを保存して開き直し、本文、書式、指した点、引き出し線が戻る。外観に BIZ UD のサブセットがある。
  - 以前の白塗り（白の Square、枠なし）が、四角として読み込まれ、塗りが白、枠線がなしになる。
- **PDFium の確認**: 塗りの四角（半透明を含む）、背景つきの文字、吹き出し（矢印を含む）が、PDFium で描いても見える。
- **単体テスト**: 引き出し線の接続先（最も近い辺の中点）の計算、Ctrl と Ctrl+Shift の直線の点、書式の初期値の移行（古い `whiteout` の初期値があっても落ちない）。
- **画面のテスト（e2e）**
  1. 四角を作り、塗りを青・透明度 50% にする → 保存して開き直す → 戻ることを確かめる。
  2. 四角を作り、「白塗りにする」を押す → 塗りが白・枠線がなしになることを確かめる。
  3. 吹き出しの道具で、点から離れた位置までドラッグして文字を入力する → 保存して開き直す → 本文と指した点を確かめる → 指した点の取っ手を動かす → 保存して開き直し、動いていることを確かめる。
  4. 文字の背景を黄、枠線を黒にする → 保存して開き直して確かめる。
  5. 蛍光ペンで、Ctrl を押しながら曲がった軌跡を描く → 保存して開き直し、その線が2点であることを確かめる。
- 既存のテスト（白塗りの道具のテストは、四角の「白塗りにする」に置き換える）がすべて通ること。
