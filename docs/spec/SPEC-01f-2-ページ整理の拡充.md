# SPEC-01f-2: ページ整理の拡充（Acrobat 相当のページ操作）

## 実行モデル指定（必須）

- モデル: `gpt-5.6-sol`
- reasoning effort: `high`
- 選定理由: ページ整理の下書き・画面・Worker 0 の処理にまたがる、機能の追加のため

---

## 目的

利用者から、次の要望が出た。

> ページの追加・削除・他の PDF の挿入の機能を充実させたい。特に、他の PDF を挿入するときは、複数のファイルをまとめて選べるようにしてほしい。Acrobat と同等程度の機能が欲しい。ただし、動きが重くなるなら要らない。

- 「他のPDFを追加」の選択画面では、実は今も複数のファイルを選べる（`multiple: true`）。ただ、そのことが分かりにくく、順番や挿入位置も指定できない。
- ページ整理は「下書き」を操作し、「適用」のときだけ文書を変える作りなので、操作を増やしても、動きは重くならない。**この作りを保つこと**（下書きの操作で Worker に重い処理をさせない）。

最初に次を読むこと。
- SPEC-01c、01c-2
- 今の `src/organize/`、`src/core/pageOps.ts`、`src/worker/`、`src/client/PdfWorkerPool.ts`

## 対象

- 変更してよいファイル: `src/organize/`、`src/core/pageOps.ts`、`src/worker/`、`src/client/PdfWorkerPool.ts`、`src/app/`、`src/App.tsx`、`src/styles.css`、`tests/`、`e2e/`
- 変更しないファイル: `docs/`（この SPEC を除く）、`public/`、`LICENSE`、設定ファイル、`src/core/annotations.ts`、`textLayout.ts`、`save.ts`

## 変更内容

### 1. ツールバーの整理

- ページ整理のツールバーを、次のまとまりで並べる。多いものは、ボタンを押すと開くメニューにする。
  - **挿入▼**: 他のPDFから／白紙のページ／クリップボードのページを貼り付け
  - **回転▼**: 左に90°／右に90°／180°
  - **削除**
  - **複製**
  - **置換**
  - **抽出**
  - **分割**
  - **並び▼**: 逆順にする（選択範囲、何も選んでいなければ全体）
  - **選択▼**: すべて選ぶ／選択を反転／奇数ページ／偶数ページ／ページ番号で選ぶ
  - **表示の大きさ**: 小・中・大
  - 右側に: 元に戻す／やり直す／適用／やめる
- 画面の下に「選択: 3ページ ／ 全40ページ（下書き）」と表示する。

### 2. 他の PDF から挿入（ダイアログ）

- 「挿入▼ → 他のPDFから」で、ファイル選択の画面を開く（**複数選択できることを、ボタンの説明に書く**）。
- 選んだ後に、次のダイアログを出す。
  - **選んだファイルの一覧**: ファイル名とページ数を表示する。ドラッグか［↑］［↓］で順番を変えられる。［×］で外せる。［ファイルを追加］で、さらに加えられる。
  - **ページの範囲**: 各ファイルに「すべて」か「範囲（例: 1-3,5）」を指定できる。
  - **挿入する位置**: 先頭／末尾／選んだページの前／選んだページの後／ページ番号を指定（N ページの後）
  - ［挿入］で、下書きに、選んだ順・範囲のとおりにカードを入れる。
- 格子へのドラッグ＆ドロップで複数のファイルを落とした場合も、同じダイアログを出す。位置は、落とした場所にする。
- ページ数を数えるために、ファイルは材料の文書（`src-…`）として Worker で開く。ダイアログで外したファイルは閉じる。

### 3. 白紙のページの挿入（ダイアログ）

- 設定できる項目:
  - 枚数（1〜100）
  - 大きさ: 直前のページと同じ／A4／A3／B4／B5
  - 向き: 縦／横
  - 位置: 2. と同じ選び方
- 作るのは下書きのカードだけで、文書は変えない（今と同じ）。

### 4. 複製、置換、貼り付け

- **複製**（`Ctrl+D`）: 選んだカードの直後に、同じカードの写しを入れる。
- **置換**
  1. 選んだカードを、別の PDF のページで置き換える。
  2. ファイルを選んで、ページの範囲を指定する。
  3. 選んだ枚数と、置き換えるページ数が違う場合は、「選んだ 3 ページを、5 ページで置き換えます」と確認してから行う。
- **コピーと貼り付け**
  - `Ctrl+C`: 選んだカードを、アプリの中のクリップボードに記憶する（ページの内容はコピーせず、どの文書の何ページかだけを記憶する）。
  - `Ctrl+V`: 選んだカードの後ろ（無ければ末尾）に貼り付ける。
  - **別のタブのページ整理にも貼り付けられる**ようにする。コピー元の文書は Worker 0 が持っているので、適用のときに `graftPage` で取り込む。
  - 貼り付けた後にコピー元のタブが閉じられていたら、適用の前に「コピー元のファイルが閉じられたため、貼り付けたページを取り込めません」と知らせ、そのカードを外す。

### 5. 抽出と分割の選択肢

- **抽出**のダイアログ
  - 「抽出したページを元の文書から削除する」（下書きから外す。適用するまで文書は変えない）
  - 「1ページずつ別のファイルにする」（フォルダを選び、`<元の名前>_p<ページ番号>.pdf` で書き出す。既存のファイルは上書きしない）
- **分割**の方式
  - 選んだ位置で区切る
  - N ページごと
  - 1ページずつ
  - ファイル数を指定して均等に分ける
- 分割と抽出のファイル名は、既存のファイルと重ならないようにする（今の `(2)` を付ける方式を使う）。

### 6. ページ番号で選ぶ

- 「1-3, 5, 8-10」のような入力を受け付ける。全角の数字・ハイフン・カンマ・空白も受け付ける。
- 範囲外や読めない部分は、赤字で理由を示し、選択は行わない。

## 性能の条件

- 下書きの操作（挿入、複製、並べ替え、選択）で、Worker に描画以外の要求を出さない（材料の文書を開く処理と、適用・抽出・分割を除く）。
- `heavy-300p.pdf` でページ整理を開き、300 枚のカードを「すべて選ぶ → 逆順」にする操作が、画面の反応として 100ms 以内に終わること（e2e で計測する）。
- 適用の時間（SPEC-01c-2 の perf-organize）が悪化しないこと。

## テスト

- **単体テスト**
  - 下書きの操作: 複製、逆順、置換、指定位置への挿入、貼り付け（別の文書のカード）、奇数／偶数／反転の選択
  - ページ番号の入力の読み取り（全角を含む）と、誤りの検出
  - 分割（均等、1ページずつ）の区切り方
- **Node の結合テスト**: 別の文書から貼り付けたページと、置換したページを含む並びを適用して、ページの順番（各ページの文字）が合うこと。
- **画面のテスト（e2e）**
  1. 2つの試験用 PDF を一度に選ぶ（`setInputFiles` に2つ渡す）→ ダイアログで順番を入れ替える → 「選んだページの後」に挿入する → 適用して、順番を確かめる。
  2. 白紙を A3 横で2枚、末尾に挿入する → 適用して、大きさと向きを確かめる。
  3. タブ A でページを `Ctrl+C` し、タブ B のページ整理で `Ctrl+V` して適用する → B に A のページが入ることを確かめる。
  4. 「1-3,5」で選び、抽出（元から削除する）→ 適用して、ページ数を確かめる。
  5. 300 ページの「すべて選ぶ → 逆順」の反応時間を計測する（100ms 以内）。

## 禁止事項

- 下書きの作り（適用するまで文書を変えない）を崩さないこと。
- 分割と抽出で、既存のファイルを上書きしないこと。
- 対象外のファイルを変更しないこと。git の変更操作をしないこと。
- 自分で起動したサーバーは必ず止め、一時ファイルは削除すること。
