# SPEC-01f-5: 記号を続けて置けるようにする

## 実行モデル指定（必須）

- モデル: `gpt-5.6-sol`
- reasoning effort: `high`
- 選定理由: SPEC-01f-4 と同じ回にまとめて実装する、画面の操作の小さな変更のため（途中でモデルを変えない）

---

## 目的

利用者から「記号は連続して使用できるようにしたい」という要望が出た。

今は、記号を置くと「選択」ツールに戻る（`Shift` を押しながらクリックしたときだけ、記号の道具のままになる）。これを、手書きや蛍光ペンと同じく、**置いた後も記号の道具のままにする**。

## 対象

- 変更してよいファイル: `src/editor/`、`src/app/HelpDialog.tsx`、`src/App.tsx`（ツールの切り替えに関わる部分だけ）、`tests/`、`e2e/symbol.annotate.spec.ts`
- 変更しないファイル: それ以外

## 変更内容

1. 記号の道具で記号を置いた後も、**ツールは記号のまま**にする。クリックするたびに、選んでいる記号を置く（ドラッグで大きさを決める動作も今のまま）。
2. 置いた記号は選んだ状態にしない（次のクリックで、すぐ次の記号を置けるようにするため）。
3. 記号の道具を抜けるのは、`Esc`、「選択」ボタン、`V` キー、ほかのツールに切り替えたとき。
4. `Shift`＋クリックの特別な扱い（道具を保つ）は不要になるので、やめる。`Shift`＋クリックも、普通のクリックと同じにする。
5. 使い方の画面の説明を、「記号は続けて置けます。やめるときは Esc か『選択』」に改める。
6. 置いた記号を後から動かしたり、大きさを変えたりするのは、「選択」ツールで行う（今のまま）。

## テスト

- `e2e/symbol.annotate.spec.ts`: 記号の道具で3回クリックして、記号が3つ置かれ、ツールが記号のままであることを確かめる。`Esc` で「選択」に戻ることを確かめる。
- 既存の、Shift で続けて置くテストは、上のテストに置き換える。
