# SPEC-02a: 上部のメニューの作り直しと、プルダウンが閉じない不具合

## 実行モデル指定（必須）

- モデル: `gpt-5.6-sol`
- reasoning effort: `high`
- 選定理由: 画面全体の上部を作り直し、1,100 行ある App.tsx から部品を切り出す、複数のファイルにまたがる改修のため

---

## 目的

利用者の意見に応える。

- 「上部のメニューは一覧性はあるが、パッと見たときにまとまりがない。項目を選ぶとプルダウンが出るようにしたい」
- 「ページ整理で『回転▼』などを一度開くと、もう一度押すまで閉じない。外をクリックしたら閉じるようにしたい」（不具合）

最初に `docs/追加機能の計画.md`（「上部のメニューの形」）と、今の `src/App.tsx`、`src/organize/OrganizeView.tsx`、`src/app/`、`src/styles.css` を読むこと。

## 対象

- 新しく作るファイル:
  - `src/ui/Dropdown.tsx`: 共通のプルダウン部品
  - `src/app/MenuBar.tsx`: メニューバー
  - `src/app/ToolRow.tsx`: 道具の段
- 変更してよいファイル: `src/App.tsx`、`src/app/`、`src/organize/OrganizeView.tsx`、`src/styles.css`、`tests/`、`e2e/`
- 変更しないファイル: `src/core/`、`src/worker/`、`src/client/`、`src/viewer/`、`src/editor/`（ツールの定義を読むのは可）、`docs/`、`public/`、`LICENSE`、設定ファイル

## 変更内容

### 1. 共通のプルダウン部品（`src/ui/Dropdown.tsx`）

- ボタンを押すと、その下に項目の一覧を開く。
- **閉じる条件**（すべて満たすこと）:
  - 外側を押したとき（`pointerdown` を document で拾う）
  - `Esc` を押したとき
  - 項目を選んだとき
  - ほかのプルダウンを開いたとき（同時に開くのは1つだけ）
  - ウィンドウの大きさが変わったとき、スクロールしたとき
- キーボードで操作できるようにする。
  - ボタンで `Enter`、`Space`、`↓` を押したら開く。
  - 項目は `↑`、`↓` で移り、`Enter` で選ぶ。
  - メニューバーの上では、`←`、`→` で隣のメニューへ移る。
- 項目の種類:
  - 普通の項目（右側にショートカットのキーを小さく表示できる）
  - 区切り線
  - 選べない項目（灰色）
  - チェックの付く項目（例: ページ一覧の表示の有無）
- 画面の端にかかる場合は、はみ出さない側に開く。
- ARIA（`role="menu"`、`menuitem`、`aria-expanded`、`aria-haspopup`）を付ける。

### 2. メニューバー（1段目、`src/app/MenuBar.tsx`）

| メニュー | 項目（ショートカット） |
|---|---|
| ファイル▼ | 開く（Ctrl+O）／ 上書き保存（Ctrl+S）／ 別名で保存（Ctrl+Shift+S）／ 確定して別名で保存 ／ ― ／ 印刷（Ctrl+P）／ ― ／ タブを閉じる（Ctrl+W） |
| 編集▼ | 元に戻す（Ctrl+Z）／ やり直し（Ctrl+Y）／ ― ／ 選択を外す（Esc）／ 選んだ書き込みを削除（Delete） |
| 表示▼ | ページ一覧（チェック）／ 書式パネル（チェック）／ ― ／ 拡大 ／ 縮小 ／ 幅に合わせる |
| ページ▼ | ページ整理 ／ ページ整理を元に戻す |
| ヘルプ▼ | 使い方 ／ このアプリについて（版の番号、ライセンス、PDF をパソコンの外へ送らないこと） |

- 右側に、今のタブのファイル名（未保存なら「●」）を表示する。
- 後の SPEC で、ここへ項目を加えていく（ファイル▼ → 画像として保存、ページ▼ → ページ番号、など）。項目の定義を配列で持ち、加えやすい形にする。
- 今ある操作は、すべてどこかのメニューか道具の段から実行できること。消えた操作が無いことを、テストで確かめる。

### 3. 道具の段（2段目、`src/app/ToolRow.tsx`）

```
[選択] [文字▼] [図形▼] [ペン▼] [記号] │ ↶ ↷ │ − 100% ＋ 幅に合わせる
```

- **分割ボタン**:
  - 「文字▼」（文字・吹き出し）、「図形▼」（線・矢印・四角・丸）、「ペン▼」（蛍光ペン・手書き）は、ボタンの本体に**最後に使った道具**を表示する。
  - 本体を押すと、その道具になる。▼を押すと、プルダウンで選べる。
  - 最後に使った道具は localStorage に保存する（try/catch で包む）。
- 今の道具が含まれる分割ボタンを、選んでいる状態として目立たせる。
- 元に戻す（↶）とやり直し（↷）は、記号とツールチップで表示する。
- 倍率は「− 100% ＋」とし、％を押すと、よく使う倍率（50、75、100、150、200、400%、幅に合わせる）をプルダウンで選べる。
- キー（V、T、C、L、A、R、O、S、H、P）は、今のまま使えること。

### 4. ページ整理のツールバー

- 「挿入▼」「回転▼」「並び▼」「選択▼」を、共通のプルダウン部品に置き換える（**閉じない不具合を直す**）。

### 5. 見た目

- メニューバーは高さ 32px 程度で、項目は文字だけにする。
- 道具の段は高さ 40px 程度で、区切り線でまとまりを示す。
- 幅が 800px 程度でも、2段に収まるようにする（入らない場合は、倍率の欄を小さくする）。

## テスト

- **単体テスト**: 分割ボタンの「最後に使った道具」の保存と読み出し。
- **画面のテスト（e2e）**
  1. 各メニューを開き、外側を押すと閉じる。`Esc` で閉じる。ほかのメニューを開くと、前のメニューが閉じる。
  2. ページ整理の「回転▼」を開いて外側を押すと閉じる（不具合の再発防止）。
  3. 「図形▼」から「丸」を選ぶ → 本体が「丸」になる → 再読み込み後も「丸」が本体に出る。
  4. メニューからの操作: ファイル▼ → 別名で保存（テスト用の窓口で確かめる）、表示▼ → ページ一覧の表示の切り替え、ページ▼ → ページ整理。
  5. キーボード: ファイル▼ にフォーカスして `↓` → `↓` → `Enter` で、2番目の項目が実行される。
- 既存のテストは、ボタンの場所が変わった分だけ直す（操作の内容は変えない）。

## 禁止事項

- 対象外のファイルを変更しないこと。git の変更操作をしないこと。
- 既存の操作を消さないこと。
- 自分で起動したサーバーは必ず止め、一時ファイルは削除すること。
