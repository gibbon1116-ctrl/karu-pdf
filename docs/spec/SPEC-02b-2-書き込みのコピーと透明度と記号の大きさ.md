# SPEC-02b-2: 書き込みのコピーと貼り付け、透明度、記号の大きさ、蛍光ペンの後の選択への復帰

## 実行モデル指定（必須）

- モデル: `gpt-5.6-sol`
- reasoning effort: `high`
- 選定理由: 書き込みの状態管理（複数の選択、クリップボード、履歴）と、注釈の中核（自前の外観の透明度）にまたがる変更のため

---

## 目的

利用者から、次の要望が出た。

1. 蛍光ペンを使った後も、自動で「選択」に戻るようにしたい。
2. 記号の大きさも設定できるようにしたい。
3. 文字やその背景色など、蛍光ペン、記号それぞれで、透明度を設定できるようにしたい。
4. 文字、蛍光ペン、線、記号など、書き込んだすべての項目をコピー＆ペーストできるようにしたい。

最初に次を読むこと。
- SPEC-01b、01e、01f-1、01f-5、02a
- 今の `src/editor/`、`src/app/FormatPanel.tsx`、`src/app/ToolRow.tsx`、`src/core/annotations.ts`（FreeText・吹き出し・記号の外観の作り方）

## 対象

- 変更してよいファイル: `src/editor/`、`src/app/`、`src/App.tsx`、`src/core/annotations.ts`、`src/worker/`（新しい属性を通すための最小限）、`src/styles.css`、`tests/`、`e2e/`
- 変更しないファイル: `docs/`（この SPEC を除く）、`public/`、`LICENSE`、設定ファイル、`src/core/textLayout.ts`、`src/viewer/`、`src/organize/`

## 変更内容

### 1. 蛍光ペンの後は「選択」に戻る

- 蛍光ペンで1本描き終えたら、「選択」に戻り、描いた線を選んだ状態にする。
- 1.5 秒以内の線を1つにまとめる仕組み（SPEC-01b）は、蛍光ペンでは使わない。
- **手書きは、今までどおり描き終えても道具を保つ**（1文字を何画にも分けて書くため）。
- 使い方の画面の説明を直す。

### 2. 記号の大きさ

- 書式パネルに「大きさ」を加える: 8、12、16、24、32、48、72 pt（記号の外接枠の一辺）。
- 何かを選んでいるときは、その記号の大きさを変える（中心を保つ）。選んでいないときは、次に置く記号の大きさになる。
- 既定は 16pt（今と同じ）。ツールごとの初期値として保存する。

### 3. 透明度

- 書式パネルに「透明度」を加える: 100%、75%、50%、25%（今ある四角・丸の透明度と同じ選び方）。

| 種類 | 透明度の項目 |
|---|---|
| 文字・吹き出し | **文字の透明度**と、**背景と枠の透明度**を別々に選べる |
| 蛍光ペン | 透明度（既定 35%。今の値を保つ） |
| 手書き・線・矢印 | 透明度 |
| 記号 | 透明度 |
| 四角・丸 | 今のまま |

- **文字・吹き出しの透明度の保存の仕方**
  - 自前の外観の中で、文字を描く部分と、背景・枠を描く部分に、別々の透明度を付ける（`Device.fillText` や `fillPath` の alpha を使う。または外観の中の ExtGState）。
  - 注釈全体の `/CA` は 1 のままにする。
  - かるPDF で読み戻すため、`/KaruStyle` に `/TextOpacity` と `/BoxOpacity` を記録する。
- 手書き・線・矢印・記号は、注釈全体の `/CA` で表す。
- 重ね表示（SVG）と入力欄も、同じ透明度で表示する。

### 4. 書き込みのコピーと貼り付け

- **複数の選択**
  - 選択ツールで、`Shift`＋クリックで選択に加える／外す。
  - 何も無い所からドラッグすると、四角で囲んだ書き込みをまとめて選ぶ（囲みの選択）。
  - 選んでいる書き込みは、まとめて移動と削除ができる（大きさの変更は1つのときだけ）。
- **コピーと貼り付け**
  - `Ctrl+C`: 選んでいる書き込みを、アプリの中のクリップボードに記憶する（種類、ページ座標、書式、本文、線の点など、作り直せる情報）。
  - `Ctrl+X`: 切り取り（コピーして削除）。
  - `Ctrl+V`: 今見ているページ（画面の中央にあるページ）に貼り付ける。
    - コピー元と同じページなら、10pt ずつ右下にずらして置く（続けて貼るたびにずらす）。
    - 別のページなら、同じ位置に置く。ページからはみ出す場合は、内側に収める。
  - `Ctrl+D`: 選んでいる書き込みを、その場で複製する（10pt ずらす）。
  - 貼り付けた書き込みは、新しい書き込みとして作り、選んだ状態にする。1回の貼り付けを、履歴の1手とする（元に戻すと、まとめて消える）。
  - **別のタブにも貼り付けられる**（アプリの中のクリップボードはタブの間で共有する）。
  - 編集メニュー（SPEC-02a）に「切り取り」「コピー」「貼り付け」「複製」を加える。
  - 文字の入力欄を開いている間は、`Ctrl+C/X/V` を入力欄に任せる。
- 対象は、文字、吹き出し、線、矢印、四角、丸、記号、蛍光ペン、手書き、すべてとする。
  - 吹き出しは、指した点と枠をまとめて動かす。
  - 他のソフトで作られた注釈も、編集できるもの（`editable`）はコピーできる。
  - SPEC-02d-2 で作る「文字への印」（ハイライト・下線・取り消し線）は文字に結び付くため、コピーの対象から外す。

## テスト

- **単体テスト**
  - 複数の選択（Shift で加える・外す、囲みの選択）
  - クリップボード（同じページでのずらし、別のページでの位置、ページの内側への収め方、別の文書への貼り付け）
  - 貼り付けの1手の元に戻す
  - 透明度の初期値の保存
- **Node の結合テスト**
  - 文字の透明度 50%・背景の透明度 25% の文字を保存し、開き直して、`/KaruStyle` の値が戻ること。
  - 外観の中で、文字と背景の透明度が別々になっていること（PDFium で描いて、背景の色の濃さと文字の色の濃さが、それぞれの透明度に見合うこと）。
  - 記号の大きさと透明度、線の透明度が戻ること。
- **画面のテスト（e2e）**
  1. 蛍光ペンで1本描く → ツールが「選択」になり、その線が選ばれている。
  2. 記号の大きさを 32pt にして記号を置く → 保存して開き直し、大きさを確かめる。
  3. 文字・四角・記号を Shift で3つ選ぶ → `Ctrl+C` → 2ページ目を表示して `Ctrl+V` → 2ページ目に3つ作られる → `Ctrl+Z` で3つとも消える。
  4. 同じページで `Ctrl+V` を2回 → 10pt、20pt ずれて置かれる。
  5. タブ A で `Ctrl+C` → タブ B で `Ctrl+V` → B に作られる。
  6. 囲みの選択で2つ選び、まとめて移動する。
