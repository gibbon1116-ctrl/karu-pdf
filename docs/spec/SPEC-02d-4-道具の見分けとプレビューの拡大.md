## 変更内容

### 1. 道具の見分け

#### 1-1. 名前

名前に、何に対して使う道具かを入れる。

| 今 | 新しい名前 | プルダウンに添える説明（1行） |
|---|---|---|
| 蛍光ペン | 蛍光ペン | なぞった所に半透明の太い線を引く（Ctrl で直線） |
| 手書き | 手書き | 細い線で自由に書く |
| 文字を選択 | 文字を選択 | PDF の文字を選んでコピーする |
| ハイライト | **文字ハイライト** | 選んだ文字だけに色を付ける |
| 下線 | **文字に下線** | 選んだ文字の下に線を引く |
| 取り消し線 | **文字に取り消し線** | 選んだ文字の中央に線を引く |

- 書き込みの一覧の種類の名前、CSV の種類の列、書式パネルの見出し、使い方の画面も、新しい名前にそろえる。
- 文字を選んだときに出る操作の帯は、文字を選んだ状況で使うので、短いままでよい（［コピー］［ハイライト］［下線］［取り消し線］）。ただし、下のアイコンを付ける。

#### 1-2. アイコン（`src/ui/ToolIcon.tsx`）

- 道具ごとに、16px の小さな SVG のアイコンを作る。外部の画像やフォントは使わない（インラインの SVG）。
  - 蛍光ペン: ペン先と、波打つ黄色の太い線
  - 手書き: ペン先と、細い曲線
  - 文字を選択: 「あ」と、青い選択の帯と、I の形のカーソル
  - 文字ハイライト: 「あ」の後ろに黄色の帯
  - 文字に下線: 「あ」と、その下の赤い線
  - 文字に取り消し線: 「あ」と、その中央の赤い線
  - ほかの道具（選択・文字・吹き出し・線・矢印・四角・丸・記号）にも、同じ作りで付ける。
- 道具の段の分割ボタンには、アイコンと名前を並べて表示する。プルダウンの項目にも、アイコンを付ける。
- 黄色や赤は、アイコンの中の意味を表す部分だけに使う。ボタンが選ばれた状態（青地に白字）でも見分けられること。

#### 1-3. プルダウンの説明

- `src/ui/Dropdown.tsx` の項目に、`icon` と `description` を加える（無くてもよい）。
- 説明は、名前の下に小さい灰色の字で1行表示する。
- 分割ボタンの `title`（カーソルを重ねたときの案内）にも、説明を入れる。

### 2. ページ整理のプレビュー欄の拡大・縮小

#### 2-1. 操作

- プレビュー欄の見出しの右に、［−］［100%］［＋］［幅］を置く。
  - 倍率の段階: 100・150・200・300・400・600・800%（100% は、欄の幅に合わせた大きさ）
  - ［100%］を押すと、倍率の一覧のプルダウンを出す。
  - ［幅］で 100% に戻す。
- プレビューの上で `Ctrl`＋ホイールを回すと、**カーソルの位置を中心に**拡大・縮小する。
- 拡大しているときは、プレビューの中をドラッグして動かせる（つかむ形のカーソル）。ホイールだけを回すと、プレビューの中が上下に動く（下のページの一覧は動かない）。
- 方向キーで選ぶページを変えたときは、倍率を保ち、表示する位置は「同じ割合の位置」にする（図面を同じ倍率で見比べられるように）。
- 拡大プレビュー（大きな窓）も、最大を 800% にし、同じ段階にそろえる。

#### 2-2. 描画（動作の軽さ・最重要）

今は、ページ全体を1枚の画像で描いている。A1 の図面を大きく拡大すると画像が巨大になり（400% で約 1,600 万画素、約 64MB）、重くなる。次のようにする。

- ページ全体の画像は、**800 万画素以下**に抑える。それより大きくなる倍率では、ページ全体は上限の大きさで描き、CSS で引き伸ばして仮に表示する。
- そのうえで、**見えている範囲（＋周りに少しの余白）だけ**を、その倍率の解像度で描き、重ねて表示する。
  - `RenderScheduler` の `deviceRect` を使う。本体の表示の `detailRegion.ts` の考え方を参考にする。
- 拡大・縮小やドラッグの最中は、CSS の拡大と位置の移動だけにする。止まってから 150ms 後に、見えている範囲を1回だけ頼む。前の要求は、新しい要求を出すときに `release` する。
- ページを変えたとき、プレビュー欄を閉じたときは、見えている範囲の画像を捨てる。
- 倍率を変えている間に、ページの一覧（左の格子）の描画を止めないこと。
- 拡大プレビュー（大きな窓）も、同じ描き方にする（共通の部品にする）。

## テスト

- **単体テスト**
  - 倍率の段階の上げ下げ（端で止まること）
  - カーソルの位置を中心にした拡大で、スクロール位置の計算が正しいこと
  - 800 万画素の上限で、ページ全体の描画の倍率を抑える計算
- **画面のテスト（e2e）**
  1. 道具の段に「文字ハイライト」があり、「ハイライト」だけの名前のボタンが無い。プルダウンの各項目に説明の文字がある。分割ボタンに SVG のアイコンがある。
  2. 書き込みの一覧で、文字ハイライトの種類の名前が「文字ハイライト」と出る。
  3. ページ整理でページを選び、プレビューの［＋］を2回押すと 200% になり、プレビューの画像の表示の幅が 2 倍になる。［幅］で 100% に戻る。
  4. `Ctrl`＋ホイールで拡大できる。
  5. 300% のまま方向キーで次のページへ移ると、300% が保たれる。
  6. `heavy-300p.pdf` の A1 のページを 800% にしたとき、ページ全体の画像が 800 万画素以下で、見えている範囲の画像が描かれ、鮮明になる（`data-rendered` などの印で確かめる）。
- 今ある e2e で、「ハイライト」などの名前で道具を選んでいるところは、新しい名前に直す。
