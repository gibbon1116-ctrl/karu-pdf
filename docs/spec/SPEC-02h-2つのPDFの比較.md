# SPEC-02h: 2つの PDF の比較（図面の重ね合わせと、違いの一覧）

## 実行モデル指定（必須）

- モデル: `gpt-6.1-sol`
- reasoning effort: `high`
- 選定理由: 描画用の Worker での2ページの合成、違いの領域の検出、02g の画面との組み合わせにまたがるため

---

## 目的

利用者が選んだ「2つの PDF の比較」を作る（`docs/追加機能の計画.md` の 02h）。

利用者は図面を確認することが多い。旧版と新版の図面の違いを、ひと目で分かるようにする。

- **重ねて表示**: 旧版と新版を重ね、旧版だけにある線を**赤**、新版だけにある線を**青**、共通の部分を**灰色**で描く。
- **違いの一覧**: 変わった場所を自動で囲み、順に飛べるようにする。
- **左右に並べる**: 02g の画面で、旧版と新版を同期して並べる。違いの場所の囲みを、両側に出す。

文字の違いの比較（仕様書などの文章の差分）は、今回は作らない。

動作を重くしないことが最重要。比べる処理は、比較の画面を開いているときに、今のページの組だけについて行う。

最初に次を読むこと。

- SPEC-02g（左右に並べて表示）、SPEC-00a-4・SPEC-01a-2・SPEC-01f-4（詳細描画と分割描画）

## 変更内容

### 1. 入口

- 表示▼ →「2つの PDF を比較…」でダイアログを開く。
  - **旧版**と**新版**を、開いているタブから選ぶ（［ファイルを開く］で新しく開いてもよい）。
  - 既定は、旧版＝今のタブ、新版＝次のタブ。
  - ページの対応: 「同じページ番号どうし」（既定）。比較の画面で、組ごとにずらせる（下の 2.）。
  - ［比較］で、比較の画面にする。

### 2. 比較の画面（`CompareView.tsx`）

```
┌ 比較: 設計図_旧.pdf ↔ 設計図_新.pdf ─────────────────────────────┐
│ 表示 (●重ねる ○並べる)  旧 p.[3] ↔ 新 p.[3]  [‹ 前の組][次の組 ›]       │
│ 違い 4 / 12 [‹][›]  ☐ 書き込みも比べる  位置合わせ: 方向キー [戻す]  [終わる] │
├──────────────────────────────────────────┬────────┤
│                                              │ 違いの一覧  │
│   重ねた図面（赤＝旧版だけ、青＝新版だけ、灰＝共通）   │ 1 p.3 左上   │
│   違いの場所を、橙の点線の四角で囲む              │ 2 p.3 中央   │
│                                              │ …          │
└──────────────────────────────────────────┴────────┘
```

- 表示の切り替え:
  - **重ねる**: 1つの表示で、合成した画像を出す。
  - **並べる**: 02g の左右の表示（旧版を左、新版を右）。同期はオン。
- ページの組:
  - 旧 p.N ↔ 新 p.M の番号は変えられる（図面が1枚増えた・減ったときのため）。
  - ［前の組］［次の組］は、両方の番号を1つずつ動かす。
- 比較の画面では、書き込みの道具は使えない（見るだけ）。［終わる］で元の画面に戻す。

### 3. 重ねた画像の作り方

- **描画用の Worker** で、旧ページと新ページの同じ範囲を、同じ倍率で描き、`compare.ts` の関数で1枚の画像に合成する。
  - 新しいメッセージ `renderCompare`: 旧と新の文書・ページ、倍率、範囲、位置合わせのずれ、書き込みを含めるか
  - 両方の文書は、どの描画用の Worker でも開いている（今の仕組み）ので、1つの Worker で両方を描ける。
- 合成の決まり（画素ごと。各画像を明るさにしてから比べる）:
  - 両方とも暗い（線がある）→ 灰色（共通）
  - 旧だけ暗い → 赤
  - 新だけ暗い → 青
  - 両方とも明るい → 白
  - 暗いとみなすしきい値は、明るさ 200 未満を既定とする。色の付いた線（赤い線など）も、明るさで判断する。
- 描画は、今の本体の表示と同じ考え方で行う。
  - 見えている範囲から先に描く。
  - 高い倍率では、見えている範囲だけを描く。
  - 長い描画は、分割して途中で止められるようにする。
  - キャッシュの鍵には、旧・新・ずれ・書き込みの有無を含める。
- ページの大きさが違うとき（A1 と A3 など）は、新版を旧版の幅に合わせて拡大・縮小して重ねる。
- 書き込み: 既定では、どちらの書き込みも描かずに比べる（図面そのものの違いを見るため）。「書き込みも比べる」をオンにすると、含めて描く。

### 4. 位置合わせ（手で合わせる）

- 図面を出し直すと、全体がわずかにずれて、全部が「違い」に見えることがある。
- 重ねる表示で、方向キーを押すと、新版を旧版に対して動かせる。
  - 1回で画面の 1px 分（倍率で換算した pt）、`Shift` と一緒なら 10px 分。
  - 動かしている間は、今の画像を CSS でずらして見せる。止まってから 150ms 後に描き直す。
- ずれは、ページの組ごとに覚える（比較の画面を閉じるまで）。［戻す］で 0 に戻す。

### 5. 違いの一覧（`compare.ts` の検出）

- 今のページの組について、比較の画面を開いたとき、または組を変えたときに1回だけ検出する。
  - 低い解像度（長い辺 2,000px 以下）で両方を描き、合成と同じ決まりで「片方だけ暗い」画素を求める。
  - 小さな点のゆらぎ（線の端の明暗のちらつき）を除くため、1画素だけの点は捨て、近い画素どうしをまとめる（膨張してから、つながった塊を求める）。
  - 塊ごとの外接の四角を、ページの座標で返す。小さすぎる塊（例: 4×4px 未満）は除く。
  - 数が多いとき（200 を超える）は、近いものをまとめて 200 以下にする。
- 結果は、一覧と、重ねた図・並べた図の上の橙の点線の四角で示す。
  - 一覧の行のクリック、［‹］［›］、`N`・`P` キーで、その場所へ移る（四角が画面に収まるように拡大する）。
  - 一覧の各行には、ページの中のおおよその位置（左上・中央・右下など）を出す。
- 位置合わせのずれを変えたら、止まってから検出し直す。

## 動作の軽さ（最重要）

- 比較の画面を開いていないときは、新しい処理を何も動かさない。
- 比べるのは、今のページの組だけ。ほかのページを先に比べない。
- 合成と違いの検出は、描画用の Worker で行う。画面のスレッドで画素を処理しない。
- 組を変えたら、前の組の要求は取り消す。

## テスト

試験用の PDF は、テストの中で作ってよい。

- 旧版: 四角 A、線 B
- 新版: 四角 A（同じ位置）、線 B（10pt 右へ移動）、丸 C（新しく追加）
- 新版を全体に 2pt ずらしたもの

- **単体テスト**（`compare.ts`）
  - 合成の色: 共通は灰、旧だけは赤、新だけは青、両方白は白
  - 違いの塊: 上の旧版と新版から、違いの四角が「線 B の旧の位置」「線 B の新の位置」「丸 C」の付近に出て、四角 A の付近には出ないこと
  - 1画素の点を捨てること、200 を超えたときにまとめること
- **Node の結合テスト**（Worker の処理を、Node で直接呼んでよい）
  1. 重ねた画像で、四角 A の線の画素が灰、線 B の旧の位置が赤、新の位置が青、丸 C が青であること。
  2. 全体に 2pt ずらした新版では、ずれ 0 だと四角 A も赤と青になり、ずれを (−2pt, 0) にすると、四角 A が灰に戻ること。
  3. A1 と A3 の組で、拡大・縮小して重ねたときに、四角 A が灰になること。
  4. 書き込みを含めない比較で、新版にだけある書き込みが、違いとして出ないこと。
- **画面のテスト（e2e）**
  1. 2つの PDF を開き、表示▼ →「2つの PDF を比較…」で比較を始める。重ねる表示で、違いの一覧に期待どおりの数の行が出る。
  2. 一覧の行をクリックすると、その場所へ移って拡大する。
  3. 方向キーでずらすと、表示のずれが変わり、［戻す］で戻る。
  4. 並べる表示にすると、左に旧版、右に新版が出て、同期して動く。
  5. ［終わる］で元の画面に戻り、比較の部品が DOM に残らない。
- **性能**（1回だけ）: `heavy-300p.pdf` の A1 のページどうし（同じページを旧・新に使ってよい）で、比較を始めてから、重ねた画像が出るまでの時間と、違いの検出の時間を計測する。目標は、画像が 1 秒以内、検出が 2 秒以内。

## 禁止事項

- 対象外のファイルを変更しないこと。git の変更操作をしないこと。
- 画面のスレッドで、画素の配列を処理しないこと。
- 自分で起動したサーバーは必ず止め、一時ファイルは削除すること。
- テストは「画像がある」だけでなく、**画素の色・違いの四角の位置**を確かめること。重ねた画像は、自分の目でも確かめること。
