# SPEC-02i: 縮尺を指定した、距離・連続した長さ・面積の計測

## 実行モデル指定（必須）

- モデル: `gpt-5.6-sol`
- reasoning effort: `high`
- 選定理由: 新しい注釈の種類（PDF 標準の計測注釈）、ページごとの縮尺、外観の自前の生成、画面の操作にまたがる新機能のため

## 目的

利用者から次の要望が出た（2026-10-01）。

> PDF の図面を確認することが頻繁にある。縮尺を指定したうえで、図面上の長さを測定できるようにしたい。測定した情報は、図面上に残せるようにしたい。

利用者が選んだもの:
- 測るもの: **距離（2点間）**、**連続した長さ（折れ線）**、**面積（多角形）**
- 縮尺の合わせ方: **縮尺の入力**と、**図面の寸法をなぞって合わせる**の両方

動作を重くしないことが最重要。図面の線への吸い付き（スナップ）は作らない。

## 変更内容

### 1. 道具「計測▼」（分割ボタン。キー `K` で距離）

| 道具 | 説明（プルダウンに添える1行） | 操作 |
|---|---|---|
| 距離 | 2点の間の長さを測る | 1点目でマウスを押し、2点目で離す（クリック2回でもよい） |
| 連続した長さ | 折れ線の長さの合計を測る | クリックで点を足す。ダブルクリックか `Enter` で終える |
| 面積 | 囲んだ範囲の面積を測る | クリックで点を足す。ダブルクリックか `Enter` で閉じて終える（3点以上） |
| 縮尺の設定… | このページの縮尺を決める | ダイアログを開く（下の 2.） |

- 点を足している途中の操作:
  - `Backspace`: 最後の点を消す
  - `Esc`: やめる
  - `Shift`: 直前の点から、水平・垂直・45° にそろえる
- 描いている間は、カーソルのそばに、今の値（例: `3,600 mm`、`合計 12,450 mm`、`12.50 m²`）を出す。
  - 計算は画面側だけで行う。**Worker には問い合わせない。**
- 終えたら、注釈を作って選んだ状態にする。続けて測れるよう、道具はそのまま。他の道具と同じく、`Esc` で選択に戻る。
- 道具の段の並び: ［選択］［文字▼］［図形▼］［ペン▼］［文字を選択▼］［計測▼］［記号］
- アイコンを `ToolIcon.tsx` に加える（距離: 両端に矢印の線と寸法の数字、連続した長さ: 折れ線、面積: 斜線で塗った多角形）。

### 2. 縮尺（ページごと）

#### 2-1. 縮尺がまだ無いページで測り始めたとき

縮尺のダイアログを開き、「このページの縮尺を決めてください」と示す。決めたら、そのまま測り始められる。

#### 2-2. 縮尺のダイアログ（`ScaleDialog.tsx`）

```
┌ 縮尺の設定（12 ページ） ───────────────────────┐
│ ● 縮尺を入力                                        │
│   縮尺 1 / [100 ▼]（1,2,5,10,20,25,30,50,100,150,  │
│              200,250,300,500,600,1000,1200,2500,    │
│              5000 と、自由入力）                     │
│   原図の用紙 [このPDFの大きさのまま ▼]               │
│              （A0・A1・A2・A3・A4 を選べる）         │
│ ○ 図面の寸法をなぞって合わせる                      │
│   [なぞる] → 図面の上で2点をクリック                │
│   実際の長さ [3600] mm   → 約 1/100 に相当          │
│ 単位 [mm ▼]（mm・m）  小数 [自動 ▼]                │
│ 対象 ● このページ ○ 同じ大きさのすべてのページ      │
│                              [キャンセル] [決定]    │
└──────────────────────────────┘
```

- 「原図の用紙」: A1 の図面を A3 に縮めて PDF にした場合、PDF 上の長さは原図の半分になる。原図の用紙を A1 と選べば、PDF の用紙（長い辺どうし）との比で補正する。PDF の用紙と同じなら補正しない。
- 「なぞって合わせる」:
  - ［なぞる］を押すと、ダイアログを一時的に小さくする（または隠す）。図面の上で2点をクリックすると、ダイアログに戻る。
  - 実際の長さを入れると、「1 pt あたりの実際の長さ」を求める。参考に「約 1/100 に相当」と表示する（原図の用紙は、このPDFの大きさのままとみなす）。
  - なぞっている間も、`Shift` で水平・垂直・45° にそろえられる。
- 単位: 長さは mm か m。面積は、mm を選んだときも **m²** で表示する（建築の図面で一般的なため）。
- 小数の桁（自動）: mm は整数、m は小数2桁、m² は小数2桁。数字は3桁ごとにカンマで区切る。
- 対象: 「同じ大きさのすべてのページ」を選ぶと、PDF の用紙の大きさ（向きを含む）が同じページに、まとめて同じ縮尺を設定する。
- 設定した縮尺は、画面の下の帯（ページ番号の横）に「縮尺 1/100（A1）」のように表示する。帯のクリックで、このダイアログを開く。

#### 2-3. 縮尺の保存（PDF の中）

- 各ページの `/VP`（Viewport の配列）に、ページ全体の `/BBox` と `/Measure` を持つ Viewport 辞書を1つ置く。
  - `/Measure` は、PDF 標準の直線の計測辞書（`/Subtype /RL`）。`/R`（「1 mm = 100 mm」のような説明の文字列）、`/X`（長さの単位と換算係数）、`/D`（距離）、`/A`（面積）を持つ。
  - Acrobat の計測ツールでも、同じ縮尺として読めることを目指す。
- かるPDF で付けた Viewport には、`/KaruScale`（縮尺の設定を JSON にした文字列。縮尺・原図の用紙・単位・なぞった場合の係数）を入れる。
  - 読み込みでは、`/KaruScale` があればそれを使う。無ければ、標準の `/Measure` から係数だけを読む（他のソフトで付けた縮尺）。
- 縮尺の設定は、書き込みと同じく**保存したときに PDF へ書く**（未保存の間は、画面と Worker の書き込みの流れに乗せる）。`Ctrl+Z` で戻せる。

### 3. 計測の注釈（PDF 標準の計測注釈）

| 道具 | 注釈の種類 | `/IT` |
|---|---|---|
| 距離 | Line | `/LineDimension` |
| 連続した長さ | PolyLine | `/PolyLineDimension` |
| 面積 | Polygon | `/PolygonDimension` |

- 各注釈には、測ったときの縮尺の `/Measure` を持たせる。
  - **後からページの縮尺を変えても、すでにある計測の値は変えない**（Acrobat と同じ）。
  - 縮尺のダイアログで縮尺を変えたときに、そのページに計測があれば「すでにある計測 N 件も、新しい縮尺で計算し直しますか」と聞く（［計算し直す］［そのまま］）。
- `/Contents` には、表示している値の文字列（例: `3,600 mm`）を入れる。書き込みの一覧と CSV にも、この文字列を出す。
- かるPDF 用の情報として、`/KaruMeasure`（種類・単位・係数・小数の桁を JSON にした文字列）を持たせる。開き直したときの再計算は、これと頂点の座標から行う。
- 見た目（外観。自前で作る）:
  - 線の色: 既定は赤。太さ: 既定は 1pt。書式パネルで、色・太さ・透明度・文字の大きさ（既定 10.5pt）を変えられる。
  - 距離: 線の両端に、線に直交する短い線（寸法線の端の印）を描く。値は線の中央の上側に、線と平行に置く。線の向きが左向きなどで文字が逆さになるときは、文字を 180° 回して正立させる。
  - 連続した長さ: 折れ線を描き、最後の点の近くに「合計 12,450 mm」を置く。
  - 面積: 多角形を、線の色の 15% の透明度で塗る。値は多角形の重心（はみ出す形なら、内側の点）に「12.50 m²」を置く。
  - 値の文字は、FreeText と同じ方式（BIZ UD フォントを一時文書でサブセットにしてから移す）で外観に描く。白い縁取り（または白の背景の帯）を付け、図面の線の上でも読めるようにする。
  - 回転したページでも、文字が見えている向きで正立すること（`orientAppearanceForAnnotation` の考え方を使う）。
- 編集:
  - 選ぶと、各頂点につかみ（ハンドル）を出す。つかみを動かすと値を計算し直し、重ね表示の値も変わる。
  - 全体の移動（ドラッグ・方向キー）、コピーと貼り付け、削除、`Ctrl+Z` は、他の書き込みと同じ。
  - 他のソフトで作られた計測注釈（`/IT` が上のどれか）も読み込む。`/KaruMeasure` が無ければ、`/Measure` から係数を読み、値は `/Contents` のまま表示する。頂点を動かしたときは計算し直す。

### 4. 書き込みの一覧と CSV

- 種類の名前: 距離・連続した長さ・面積
- 本文: 値の文字列（例: `3,600 mm`）
- CSV に「縮尺」の列を加える（計測以外は空欄）。

## 動作の軽さ（最重要）

- **図面の線への吸い付き（スナップ）は作らない。** 図面の全部の線を調べる必要があり、重くなるため。
- 測っている間は、画面側の計算と SVG の書き換えだけを行う。マウスが動くたびに React の state を更新しない（ref で描き替える。今のドラッグと同じ決まり）。
- 外観（AP）は、保存のとき、または書き込みの反映のときにだけ作る（今の FreeText と同じ）。
- 計測の道具を使っていないときは、新しい処理を何も動かさない。

## テスト

- **単体テスト**（`measure.ts`）
  - 縮尺 1/100・原図の用紙が同じとき、PDF 上の 72pt（25.4mm）が 2,540 mm になること
  - A1 の図面を A3 に縮めた PDF（A3 の用紙）で、原図の用紙を A1 にすると、同じ長さが 2 倍になること
  - なぞって合わせる（2点の距離と実際の長さ）で、係数と「約 1/N」の表示が正しいこと
  - 折れ線の合計、多角形の面積（四角・L 字形・へこんだ形）、m² への換算、数字の書式（カンマ、小数の桁）
  - Shift でそろえる角度（水平・垂直・45°）
- **Node の結合テスト**
  1. 3種類の計測注釈を作って保存し、開き直す。種類、`/IT`、頂点、`/Measure`、`/KaruMeasure`、`/Contents` が戻ること。
  2. ページの `/VP` に縮尺が保存され、開き直して読めること。標準の `/Measure` だけのページ（`/KaruScale` が無い）でも係数を読めること。
  3. 外観に値の文字が描かれていること。ページを `toStructuredText` で読むと値の文字列があり、その行の枠が、線の中央付近（距離）・重心付近（面積）にあること。
  4. 回転（90・180・270）したページで、値の文字が正立している（行の向きが横書きの正方向）こと。
  5. 計測を付けても、元のページの内容（`sample-small` の「Sample page 1」）と、既存の書き込みが残ること。
  6. PDFium で描いても、計測の線と値が見えること（`tests/pdfium.compat.test.ts` の方式）。
- **画面のテスト（e2e）**
  1. 縮尺の無いページで「距離」を選んで測り始めると、縮尺のダイアログが出る。1/100 を選んで決定する。
  2. ページ上の既知の 2 点（ページ座標で 72pt 離れた点。テスト用の窓口で画面の位置に換算してよい）を測ると、`2,540 mm` の計測が1つでき、書き込みの一覧に出る。
  3. 頂点のつかみを動かすと、値が変わる。`Ctrl+Z` で戻る。
  4. 「なぞって合わせる」で 2 点をクリックして実際の長さを入れると、縮尺が決まり、「約 1/N」が表示される。
  5. 面積で4点をクリックして `Enter` を押すと、面積の計測ができる。値が、手で計算した値と一致する。
  6. 連続した長さで、`Backspace` で最後の点が消え、`Esc` でやめられる。
  7. 保存して開き直しても、計測と縮尺の表示が残る。
- **性能**: `heavy-300p.pdf` の A1 のページを 400% に拡大した状態で、面積の点を 20 個置く間の、フレーム間隔の p95 が 20ms 以下であること（1回だけ測る）。
