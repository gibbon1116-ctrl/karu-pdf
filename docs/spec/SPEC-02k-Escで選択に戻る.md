# SPEC-02k: Esc を1回押せば、いつでも「選択」に戻る

## 実行モデル指定（必須）

- モデル: `gpt-6.1-sol`
- reasoning effort: `high`
- 選定理由: 複数の部品（アプリ全体のキー処理、計測・雲の点の置き方、指摘の入力欄、文字の入力欄）の Esc の扱いを、優先順位を決めてそろえる必要があるため

---

## 目的

利用者から次の要望が出た（2026-10-02）。

> ESC を押したら、「選択」に戻るようにしたい

今は、次の場面で Esc を押しても「選択」に戻らない。

1. 書式パネル・左の欄（検索欄、絞り込み）・倍率の欄などの、**入力欄や選択欄にフォーカスがある**とき。`App.tsx` のキー処理が、入力欄からの Esc を無視している。
2. 連続した長さ・面積・雲（多角形）で、**点を置いている途中**。`MeasurementOverlay.tsx` が Esc を受け止め（`stopImmediatePropagation`）、描きかけを消すだけで、道具はそのまま。もう一度 Esc を押す必要がある。
3. **指摘の内容を書く欄**を開いているとき。`IssueEditor.tsx` が Esc で欄を閉じるが、道具は「指摘」のまま。

これを、**Esc を1回押せば、必ず「選択」の道具に戻る**ようにそろえる。

最初に、今の `src/App.tsx`（キー処理の `onKey`）、`src/editor/MeasurementOverlay.tsx`、`src/editor/IssueEditor.tsx`、`src/editor/TextEditor.tsx`、`src/editor/AnnotationLayer.tsx`、`src/viewer/Viewer.tsx`、`src/ui/Dropdown.tsx`、`src/app/DocumentWorkspace.tsx` の Esc の扱いを読むこと。

## 対象

## 変更内容

### Esc の決まり（上から順に当てはめる）

| 状態 | Esc を押したとき |
|---|---|
| プルダウンのメニューが開いている | メニューを閉じるだけ（今のまま） |
| ダイアログ（縮尺・ページ番号・画像から PDF・比較など）が開いている | ダイアログを閉じるだけ（今のまま） |
| ページ整理の画面 | 今のまま（整理をやめる） |
| 文字（FreeText・吹き出し）を入力中 | 今のまま入力を閉じ、**「選択」に戻る**（今もそうなっている） |
| 指摘の内容を入力中 | 今のまま欄を閉じ（印は残す）、**「選択」に戻る** |
| 計測・雲（多角形）で点を置いている途中 | 描きかけを消し、**「選択」に戻る**（1回で） |
| 縮尺の「なぞって合わせる」の途中 | なぞるのをやめて、縮尺のダイアログに戻る（今のまま。道具は変えない） |
| 入力欄・選択欄・ボタンなどにフォーカスがある | フォーカスを外し（`blur`）、**「選択」に戻る**。検索欄では、今までどおり検索の強調も消す |
| それ以外 | **「選択」に戻る**（今のまま） |

- 「選択」に戻るときは、今と同じく、書き込みの選択も外す（`clearSelection`）。文字の選択（青い選択）と、その操作の帯も消す。
- 右の表示（左右に並べて表示）にフォーカスがあるときも、「選択」に戻る（左の道具が変わる）。
- 「選択」の道具のときに Esc を押した場合は、選択を外すだけ（今のまま）。

### 作り方

- キー処理の優先順位は、**アプリ全体の処理（`App.tsx`）で1か所にまとめて判断する**。部品ごとに `stopImmediatePropagation` で Esc を止めて、アプリ全体に届かなくする作りは、上の表の「今のまま」の行（メニュー・ダイアログ・ページ整理・なぞる途中）だけに残す。
- 計測・雲の描きかけを消す処理と、指摘・文字の入力欄を閉じる処理は、Esc の処理の中で呼ぶか、各部品が Esc で後始末をしたうえで、アプリ全体に Esc を届ける。どちらでもよいが、**二重に処理しない**こと（例: 描きかけを消した後に、もう一度別の処理が走らない）。
- 使い方の画面の Esc の説明を、この決まりに合わせて直す。

## テスト

- **画面のテスト（e2e）**。それぞれ、Esc を**1回**押した後に、道具の段の「選択」が押された状態（`aria-pressed="true"`）になっていることを確かめる。
  1. 書式パネルの選択欄（線の太さなど）を操作してフォーカスがある状態
  2. 検索欄にフォーカスがある状態（検索の強調も消えること）
  3. 面積で2点を置いた途中（描きかけの線が消え、書き込みが増えていないこと）
  4. 雲（多角形）で2点を置いた途中
  5. 指摘を置いて内容の欄が開いている状態（印は残り、内容は空であること）
  6. 文字の入力中（今のまま、入力が閉じること）
  7. 「文字を選択」で文字を選んだ状態（青い選択と操作の帯が消えること）
  8. 左右に並べて、右の表示をクリックした状態
  9. プルダウンのメニューが開いている状態では、メニューが閉じるだけで、道具は変わらないこと
  10. 縮尺のダイアログが開いている状態では、ダイアログが閉じるだけで、道具は変わらないこと
- 今ある e2e で、「Esc で描きかけを消し、もう一度 Esc で選択に戻る」ことを前提にしているものは、新しい決まりに合わせて直す。確かめている中身（描きかけが消えること、書き込みが増えないこと）は弱めないこと。
