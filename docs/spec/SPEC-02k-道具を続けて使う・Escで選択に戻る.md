# SPEC-02k: 道具を続けて使う、Esc で「選択」に戻る、蛍光ペンと手書きの Shift

## 実行モデル指定（必須）

- モデル: `gpt-6.1-sol`
- reasoning effort: `high`
- 選定理由: すべての道具の「作った後の動き」と、アプリ全体・各部品の Esc の扱いを、優先順位を決めてそろえる必要があるため

## 目的

利用者から、次の要望が出た（2026-10-02）。

> ESC を押したら、「選択」に戻るようにしたい

> 蛍光ペンの操作も他と同様に「shift」キーを押しながら選択すると直線が引けるようにしたい。

> 自身で「選択」をクリックするまでは、直前に選択した「蛍光ペン」等の操作が続くようにしたい（確認したところ、**すべての道具**が対象）

これまでは、線・矢印・四角・丸・雲（四角）・蛍光ペン・手書き・文字・吹き出しは、1つ作ると自動で「選択」に戻っていた（2026-09-29・30 の利用者の要望による）。**今回の指示で、これを取りやめる。**

最初に次を読むこと。
- SPEC-00c（作った後に選択へ戻る）、SPEC-01e（蛍光ペンの直線）、SPEC-01f-5（記号を続けて置く）、SPEC-02b-2（蛍光ペンの後は選択に戻る）
- 今の `src/App.tsx`（キー処理の `onKey`、`changeTool`）、`src/editor/AnnotationLayer.tsx`、`src/editor/ink.ts`、`src/editor/TextEditor.tsx`、`src/editor/IssueEditor.tsx`、`src/editor/MeasurementOverlay.tsx`、`src/viewer/Viewer.tsx`、`src/ui/Dropdown.tsx`、`src/app/ToolRow.tsx`、`src/app/HelpDialog.tsx`

## 変更内容

### 1. 道具を続けて使う（すべての道具）

- どの道具も、書き込みを1つ作った後に、自動で「選択」に戻さない。**利用者が「選択」をクリックするか、Esc を押す（下の 2.）か、別の道具を選ぶまで、同じ道具のままにする。**
  - 対象: 文字、吹き出し、指摘、線、矢印、四角、丸、雲（四角・多角形）、蛍光ペン、手書き、文字を選択、文字ハイライト、文字に下線、文字に取り消し線、距離、連続した長さ、面積、記号
- 作った直後の書き込みは、今と同じく「選んだ状態」にする。書式パネルでその書き込みの色などを直せ、`Delete` で消せ、`Ctrl+Z` で取り消せる。
  - ただし、道具が「選択」でない間は、次のドラッグやクリックで**新しい書き込みを作る**。選んでいる書き込みのつかみ（大きさの変更のハンドル）は、道具が「選択」でない間は出さない。
- 文字・吹き出し:
  - 入力中に、入力欄の外をクリックしたときは、**その1回は入力を確定するだけ**にし、新しい文字枠は作らない。次のクリックから、新しい文字枠を作る。
  - 文字・吹き出しの道具で、すでにある文字（FreeText）をクリックしたときは、新しく作らずに、その文字の編集に入る。
- 蛍光ペン・手書きの続けて引いた線を1つにまとめる今の決まり（`mergeInkAnnotationId`）は、そのまま使う。
- 道具の段の表示は、今の道具を押された状態（`aria-pressed`）で示し続ける。

### 2. Esc を1回押せば「選択」に戻る

今は、次の場面で Esc を押しても「選択」に戻らない。
1. 書式パネル・左の欄（検索欄、絞り込み）・倍率の欄などの、入力欄や選択欄にフォーカスがあるとき（`App.tsx` が入力欄からの Esc を無視している）
2. 連続した長さ・面積・雲（多角形）で、点を置いている途中（`MeasurementOverlay.tsx` が Esc を止め、描きかけを消すだけ）
3. 指摘の内容を書く欄を開いているとき（`IssueEditor.tsx` が Esc で欄を閉じるが、道具は「指摘」のまま）

これを、次の決まりにそろえる（上から順に当てはめる）。

| 状態 | Esc を押したとき |
|---|---|
| プルダウンのメニューが開いている | メニューを閉じるだけ（今のまま） |
| ダイアログ（縮尺・ページ番号・画像から PDF・比較など）が開いている | ダイアログを閉じるだけ（今のまま） |
| ページ整理の画面 | 今のまま（整理をやめる） |
| 縮尺の「なぞって合わせる」の途中 | なぞるのをやめて、縮尺のダイアログに戻る（今のまま。道具は変えない） |
| 文字（FreeText・吹き出し）を入力中 | 入力を確定して閉じ、**「選択」に戻る** |
| 指摘の内容を入力中 | 欄を閉じ（印は残す。入力した内容は確定する）、**「選択」に戻る** |
| 計測・雲（多角形）で点を置いている途中 | 描きかけを消し、**「選択」に戻る**（1回で） |
| 線・四角・蛍光ペンなどをドラッグしている途中 | ドラッグをやめ（作らない）、**「選択」に戻る** |
| 入力欄・選択欄・ボタンなどにフォーカスがある | フォーカスを外し（`blur`）、**「選択」に戻る**。検索欄では、今までどおり検索の強調も消す |
| それ以外 | **「選択」に戻る** |

- 「選択」に戻るときは、今と同じく、書き込みの選択も外す（`clearSelection`）。文字の選択（青い選択）と、その操作の帯も消す。
- 右の表示（左右に並べて表示）にフォーカスがあるときも、「選択」に戻る（左の道具が変わる）。
- 「選択」の道具のときに Esc を押した場合は、選択を外すだけ（今のまま）。
- 作り方: キー処理の優先順位は、**アプリ全体の処理（`App.tsx`）で1か所にまとめて判断する**。部品ごとに `stopImmediatePropagation` で Esc を止めて、アプリ全体に届かなくする作りは、上の表の「今のまま」の行（メニュー・ダイアログ・ページ整理・なぞる途中）だけに残す。描きかけを消す処理や、入力欄を閉じる処理は、**二重に走らない**こと。

### 3. 蛍光ペンと手書きの Shift

- 蛍光ペンと手書きで、**`Shift` を押しながらドラッグすると、水平・垂直・45° にそろった直線**を引く（線・矢印・計測の `Shift` と同じ）。
- 今の `Ctrl`（好きな角度の直線）は残す。`Ctrl+Shift` は `Shift` と同じ。
- `src/editor/ink.ts` の `inkStrokePoints` の引数の意味を、この決まりに合わせて直す。
- プルダウンの説明を「なぞった所に半透明の太い線を引く（Shift で水平・垂直・45°、Ctrl で好きな角度の直線）」のように直す。手書きも同様。

### 4. 使い方の画面

- 「道具は『選択』を押すか Esc を押すまで続けて使える」こと、Esc の決まり、蛍光ペンと手書きの Shift を、使い方の画面に書く。古い説明（作った後は選択に戻る、など）は消す。

## テスト

- **単体テスト**: `inkStrokePoints` で、Shift のときに水平・垂直・45° にそろい、Ctrl のときは好きな角度のままであること。
- **画面のテスト（e2e）**
  - 道具を続けて使う:
    1. 四角・線・矢印・丸・雲（四角）・蛍光ペン・手書きのそれぞれで、道具を選び直さずに2つ続けて作れる（書き込みが2つ増え、道具の段のその道具が押されたまま）。
    2. 文字の道具で、1つ目を入力 → 外をクリック（確定だけで、文字枠は増えない）→ もう一度クリックで2つ目の文字枠ができる。
    3. 文字の道具で、すでにある文字をクリックすると、その文字の編集に入る（文字枠は増えない）。
    4. 作った直後の書き込みが選ばれていて、書式パネルで色を変えるとその書き込みの色が変わる。`Delete` で消える。
    5. 道具が「選択」でない間は、作った書き込みのつかみが出ない。
    6. 「選択」をクリックすると、道具が「選択」になる。
  - Esc（それぞれ、Esc を**1回**押した後に「選択」が押された状態になることを確かめる）:
    7. 書式パネルの選択欄を操作して、フォーカスがある状態
    8. 検索欄にフォーカスがある状態（検索の強調も消えること）
    9. 面積・雲（多角形）で2点を置いた途中（描きかけが消え、書き込みが増えないこと）
    10. 指摘を置いて内容の欄が開いている状態（印は残ること）
    11. 文字の入力中（入力が確定して閉じること）
    12. 四角をドラッグしている途中（書き込みが増えないこと）
    13. 「文字を選択」で文字を選んだ状態（青い選択と操作の帯が消えること）
    14. 左右に並べて、右の表示をクリックした状態
    15. プルダウンのメニューが開いている状態では、メニューが閉じるだけで、道具は変わらないこと
    16. 縮尺のダイアログが開いている状態では、ダイアログが閉じるだけで、道具は変わらないこと
  - 蛍光ペンの Shift:
    17. `Shift` を押しながら斜め 30° くらいにドラッグすると、45° にそろった2点の線になる。水平に近い向きなら水平になる。
- 今ある e2e で、「作った後に選択へ戻る」ことや、「Esc で描きかけを消し、もう一度 Esc で選択に戻る」ことを前提にしているものは、新しい決まりに合わせて直す。確かめている中身（書き込みの数、位置、内容など）は弱めないこと。
