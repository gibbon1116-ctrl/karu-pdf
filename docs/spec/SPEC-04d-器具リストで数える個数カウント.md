## 目的

利用者から次の指摘と要望が出た（2026-10-04）。

> 個数カウントが追加されていますが、図形の登録をしたうえで照明器具やコンセント種類ごとに項目を指定してカウントできなければ使えない。

> 個数カウントするときは、登録した図形と器具名称のリストを作成し、選択した器具について個数が拾えるようにしたい。また、特定の器具のみを図面に表示させる機能が欲しい。個数カウント書式には、図形の指定や記号の塗りつぶし等の機能が欲しい。図形の種類は図面上で１００以上使われることがある。図形の形状や色でその種別に対応できるように種類が欲しい。

画面例に対する回答（要約）:

> CSVから読み取りは不要。器具を追加するときに名称、略号、図形の書式を設定できるようにすればよい。常時個数カウントの図形の書式を表示する必要はない。色は全体的に暗いので、明るい色を含めてもっと増やす。形は「逆三角」等の文字ではなく、全て図形で表示する。器具リストは建築、電気設備、機械設備で一般的な見本を作成しておく。器具リストの内容を増やすとき、登録済みの項目を複製したうえで図形の種類や名称、略号を修正できるようにする。個数をカウントするとき、全ての図面の合計の個数と、表示された一枚の図面の個数をそれぞれ表示したい。CSVで出力するときは、それらの個数をそれぞれ出力できるようにしたい。

登録した図形を図面から自動で探す機能は**作らない**（利用者の回答）。器具リストから選び、クリックで数える。図面上の記号を切り取って見本にする機能は、次の SPEC-04f で作る。

背景は `docs/営繕改修_実用性レビュー.md` の 4章と「決定事項」を参照。

## 変更内容

### 1. 器具リスト（データと保存）

1. `src/core/countFixtures.ts` に次の型と処理を作る。

   ```ts
   type CountShape = 'circle' | 'doubleCircle' | 'square' | 'roundedSquare' | 'triangle' | 'invertedTriangle'
     | 'diamond' | 'pentagon' | 'hexagon' | 'octagon' | 'star' | 'plus' | 'cross' | 'hourglass'
   type CountFill = 'none' | 'solid' | 'half' | 'dot' | 'hatch'
   interface CountStyle { shape: CountShape; fill: CountFill; color: RGB; size: number; opacity: number; showCode: boolean }
   interface CountFixture { id: string; name: string; code: string; category: string; style: CountStyle; memo?: string; order: number }
   ```

   - `name`（器具名称）は1〜80文字で必須。`code`（略号）は0〜16文字。`category`（分類）は1〜40文字。`memo` は0〜200文字。
   - `size` は 6・8・10・12・14・16・20・24 pt。`opacity` は既存の透明度の選択肢。
   - 検証（`parseCountFixtures`）は不正な項目を読み込まない（既存の `parseCount` と同じ方針）。器具は1文書あたり1,000件まで。
2. 器具リストは文書ごとにPDFへ保存する。カタログ（`Root`）に `KaruCountFixtures` として JSON（`{ version: 1, fixtures: [...] }`）を保存する（`KaruHeaderFooter` と同じ方式）。上限は 1 MiB。通常の保存（上書き・別名）で、注釈と一緒に保存する。
3. 器具リストの変更（追加・編集・複製・削除・並べ替え）は未保存の表示になり、Ctrl+Z / Ctrl+Y で戻せる（`AnnotationStore` の履歴に載せる）。
4. 印の `KaruCount` は `{ version: 2, id, fixtureId }` にする。印の注釈の内容（Contents）は「個数: <略号> <器具名称>」にする（他のPDFソフトで見たときの手がかり）。
5. **旧形式の印との互換**: `version: 1` の印は、開いたとき種類名（`group`）ごとに器具として表示する（分類「その他」、形・色は下の自動割り当て）。利用者が何か変更して保存するまで、PDF は変えず、未保存の表示にもしない。保存するときは `version: 2` と器具リストに書き換える。

### 2. 印の形・塗り・色

1. 形は14種類: 丸、二重丸、四角、角丸四角、三角、逆三角、ひし形、五角形、六角形、八角形、星、十字、バツ、砂時計。**画面のどこでも、形は図形で表示する**（「逆三角」のような文字で代用しない）。
2. 塗りは5種類: 塗りなし（中は透明）、塗りつぶし、半分塗り（左半分）、中心に点、斜線。これも図形で表示する。
3. 色は24色の色見本と、任意の色（`<input type="color">`）。暗い色だけにせず、明るい色を含める。色見本は次の24色とする。

   | 赤 `#E60012` | 橙 `#FF7F00` | 黄 `#FFD400` | 黄緑 `#8FD400` | 緑 `#00A040` | 青緑 `#00B8A9` |
   |---|---|---|---|---|---|
   | 水色 `#00B7EB` | 青 `#0068B7` | 紺 `#1D2088` | 紫 `#7B2CBF` | 赤紫 `#E4007F` | 桃 `#FF66B2` |
   | 茶 `#A0522D` | オリーブ `#808000` | 灰 `#606060` | 黒 `#000000` | 明るい赤 `#FF4D4D` | 明るい橙 `#FFB347` |
   | レモン `#FFF04D` | 明るい緑 `#66E066` | 明るい水色 `#66D9FF` | 明るい青 `#6699FF` | 明るい紫 `#B388FF` | 明るい桃 `#FF99CC` |

4. 明るい色（相対輝度が0.6を超える色）の印は、白い用紙でも見えるよう、外周に 0.5pt の濃い灰色（`#404040`）の縁取りを付ける。
5. 略号の表示（`showCode`）がオンのとき、印の右上に略号を小さく（印の大きさの約0.7倍）表示する。
6. **自動割り当て**: 新しい器具の形・塗り・色は、すでに使っている組合せと重ならないように決める。隣り合う器具で形と色の両方が変わるよう、i番目（0から）の候補を「形 = 形の一覧[i mod 14]、色 = 色見本[(i×7) mod 24]、塗り = 塗りの一覧[floor(i / 14) mod 5]」とし、使用中の組合せは飛ばす。大きさの既定は 10pt、透明度の既定は 0.8、略号の表示の既定はオン。
7. 同じ形・塗り・色の器具がほかにあるときは、追加・編集の画面に「同じ見た目の器具があります: <略号> <器具名称>」と表示する（保存は止めない）。
8. 印の描き方は `src/editor/countMarkers.ts` にまとめ、画面（SVG）と PDF の外観（外観ストリーム）で同じ形・塗り・縁取り・略号になるようにする。他のPDFソフトで開いても同じ見た目にする。

7. 表示の絞り込み:
   - 器具ごとの目の印で、その器具の印を図面に表示・非表示にする。分類の見出しの目の印で、その分類をまとめて切り替える。
   - 「選択中の器具だけ表示」をオンにすると、選んでいる器具の印だけを表示する。

8. 削除: その器具の印があるときは「この器具の印 n 個も削除します」と確認してから、器具と印を削除する（元に戻せる）。

### 4. 追加・編集・複製の画面（`FixtureDialog`）

1. 項目: 器具名称（必須）、略号、分類（既存の分類から選ぶか、新しく入力する）、形（14の図形のボタン）、塗り（5の図形のボタン）、色（24色の色見本と任意の色）、大きさ、透明度、略号を印に表示、メモ。印の見本を大きく表示し、変更をすぐ反映する。
2. 「器具を追加」は、自動割り当ての形・塗り・色を初期値にして開く。
3. 「複製」は、選んでいる器具の内容（名称は「<名称> のコピー」）を初期値にして開き、利用者が形・名称・略号などを直して追加する。

### 6. 数える

1. 個数カウントの道具で図面をクリックすると、選んでいる器具の印を置く。器具を選んでいないときは印を置かず、「器具リストで器具を選んでください」と表示して「器具」タブを開く。
2. 同じ器具の印の中心から 3mm 以内をクリックしたときは、「近くに同じ器具の印があります（二重に数えていないか確認してください）」と表示する。印は置く。

### 7. 画面での描き方と性能

1. 表示・非表示の切替をすぐ反映するため、個数カウントの印は保存済みのものも含めて**常に注釈レイヤー（SVG）で描き**、ページの画像からは既存の `excludeAnnotObjNums` の仕組みで除いてよい。この場合も、除く対象を表示中のページの印に限り、通常の閲覧の描画を遅くしない。
2. 多数の印は、形・塗り・色・大きさ・透明度の組ごとに1本のパスにまとめて描く（既存の500個超の丸印の集約を、すべての形・塗りに広げる）。非表示の器具の印は描かない。
3. 略号の文字は、1ページの表示中の印が1,000個以下のときだけ描く。超えるときは描かず、「器具」タブに「印が多いため略号の表示を省略しています」と出す。
4. 器具リストのタブ・画面は、開いたときだけ読み込む（`lazy`）。通常の読込で器具リストを解析しない（器具リストの読込は、「器具」タブを開いたとき、または個数カウントの道具を初めて使ったときに行う）。
5. 1文書に器具100種類・印5,000個でも、表示・選択・集計・保存が実用的な速さで動くようにする。

### 8. CSV

1. 「個数をCSVに書き出す」（器具タブ）は、次の数量表を出す。行は器具（分類・略号・器具名称）。列は「分類、略号、器具名称、表示中の図面（p.N）、全図面の合計」、続いて印が1個以上あるページごとに「p.1」「p.2」…。0個の器具も行に出す。ファイル名は `<PDF名>_個数.csv`。
2. 種類を選んで書き出すCSV（`CsvExportDialog`）の「個数カウント」の行は、「個数の種類」の代わりに「器具名称」「略号」「分類」の列を出す。
3. 書き込み一覧（`AnnotationListPanel`）の「個数カウント」の絞り込みにある旧来の集計表示と「個数をCSVに書き出す」は削除する（器具タブへ移す）。
4. BOM、CRLF、数式として解釈される文字列の抑止（`quote`）は既存どおり。

### 9. ヘルプ

`src/app/HelpDialog.tsx` の個数カウントの説明を、器具リスト・見本・複製・表示の絞り込み・個数の表示・CSVに合わせて書き直す。

### 10. 試験

- 単体試験:
  - 器具リストの検証・保存・読込（不正値の拒否、件数・容量の上限）。
  - 自動割り当てが100種類で重ならない。隣り合う器具で形と色が変わる。
  - 旧形式（`version: 1`）の印を種類名ごとの器具として読み、保存で `version: 2` になる。
  - 数量表のCSV（表示中の図面・全図面の合計・ページの列、0個の行、BOM・CRLF・数式化の抑止）。
  - 印の図形（14の形×5の塗り）の描画データが作れる。明るい色に縁取りが付く。
- 画面試験:
  - 「見本から追加」で電気設備の見本を追加し、2種類の器具を選んで数え、タブの「表示中の図面」「全図面」の個数が正しい。別のページでも数えて「全図面」が合計になる。
  - 「器具を追加」で名称・略号・形・塗り・色を決めて追加し、印がその書式で描かれる。「複製」で形と略号を変えた器具を作れる。
  - 「編集」で書式を変えると、その器具の印がすべて変わる。
  - 目の印・「選択中の器具だけ表示」・「すべて表示」で、印の表示が切り替わり、非表示の印はクリックで選べない。
  - 印を別の器具へ付け替え、元に戻せる。
  - 保存して開き直すと、器具リスト・印・個数が戻る。
  - 「個数をCSVに書き出す」の列と値。
  - 器具100種類・印5,000個の合成PDFで、表示・範囲選択・集計・保存ができる（既存の5,000個の試験を置き換えてよい）。
- 仕様の変更で期待値が変わる既存の試験は、新しい仕様に合わせて更新し、更新した試験と理由を報告する。
