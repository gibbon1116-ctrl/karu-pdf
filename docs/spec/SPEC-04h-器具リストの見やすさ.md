## 目的

SPEC-04d で作った器具リストを、Claude Code が 1440×900 の画面で操作して確かめた（`work/screens-04d/2-counting.png`、`4-add-dialog.png`）。機能は動くが、実務で100種類以上の器具を扱うには次の点が見づらい。

1. 左の欄が狭い（既定 220px）ため、器具名が3〜4行に折り返し、1行が高くなって一覧が読みにくい。
2. 「表示中の図面／全図面」の個数の表示がタブの上端にあり、一覧をスクロールすると見えなくなる。利用者は「個数をカウントするとき、全ての図面の合計の個数と表示された一枚の図面の個数をそれぞれ表示したい」と求めている。
3. 一覧の印の見本が小さく（透明度もそのまま）、見分けにくい。
4. 左の欄のタブが3列の格子のため、「器具」タブだけ2段目に回っている。
5. 器具の追加・編集の画面が縦に長く、900px の画面では下が切れ、「追加する」ボタンと印の見本がスクロールしないと見えない。

機能・データ・保存・個数の計算は変えず、配置と見た目だけを直す。

## 変更内容

1. **左の欄のタブを1段にする**: `.side-panel-tabs` を4列にし、「ページ・検索・書き込み・器具」を1段に並べる。
2. **器具タブのときは左の欄を広げる**: 器具タブを表示している間は、左の欄の幅を「利用者の幅」と 340px の大きい方にする。利用者が保存した幅（`karu-pdf:side-panel-width`）は書き換えない。器具タブから他のタブに戻ると、利用者の幅に戻る。
3. **個数の表示と操作部を常に見えるようにする**: 器具タブの上部（見出し・個数の表示・操作ボタン・検索・「選択中の器具だけ表示」・「すべて表示」）を固定し、分類ごとの一覧だけをスクロールさせる。
4. **個数の表示を目立たせる**: 選んでいる器具の印の見本（24px）と「略号 器具名称」を1行目に、2行目に「表示中の図面（p.N）: n個」「全図面: m個」を大きめの数字で並べる。器具を選んでいないときは「器具リストで器具を選んでください」。
5. **操作ボタンを詰める**: ボタンの文字を 12px・余白を小さくし、1行目に「器具を追加・見本から追加・複製・編集・削除」、2行目に「他のPDFから読み込む・個数をCSVに書き出す・上へ・下へ」を並べる（幅に応じて折り返してよい）。
6. **一覧の行を1行にする**: 行は「表示の切替（22px）・印の見本（22px）・略号（太字、幅 48px）・器具名称（残りの幅、1行で末尾を「…」で省略、`title` で全文）・このページの個数（右寄せ 34px）・全図面の個数（右寄せ 40px）」の1行、高さ 28px 程度。一覧の上に、同じ列幅の見出し行「表示・印・略号・器具名称・この図面・全図面」を1つ置く。
7. **印の見本を見やすくする**: 一覧と見出しの印の見本は、器具の形・塗り・色で描き、透明度は 100% で表示する（実際の印の透明度は変えない）。
8. **追加・編集の画面を1画面に収める**: 幅を `min(860px, 95vw)` にし、2列に配置する。
   - 左の列: 器具名称、略号、分類、大きさ、透明度、略号を印に表示、メモ、印の見本（大きめ）、同じ見た目の警告。
   - 右の列: 形（7列×2段）、塗り（5つ）、色（12列×2段と任意の色）。
   - 画面の高さは `max-height: 92vh` とし、中身だけをスクロールさせ、「閉じる」「追加する／変更する」は常に下に見えるようにする。幅が狭いとき（640px 未満）は1列に戻す。
9. **アクセシブル名を変えない**: ボタンの文字・`aria-label`・ラベル・`role`・`data-testid`・`data-fixture-id` は、すべて今のまま残す（既存の画面試験がそれで操作しているため）。新しく置く見出し行などは操作の対象にしない。
