## 目的

利用者の要望（2026-10-05）:

> 書き込みタブで種類を選択したとき、図面に表示されるものも制限するか選べるようにしたい。「指摘」をドロップダウンで選択しているときは、指摘だけを表示するか選べたり、「すべて」を選択しているときは全て表示し、「記号」を選択しているときは記号のみを表示したり（中略）したい。また、記号の表示のチェックボックスを追加するときは、器具欄での表示するかしないかの挙動と矛盾しないようにしたい。

利用者は2つの案のうち「種類に連動」を選んだ。書き込みタブの種類の下に「図面にもこの種類だけ表示」を置き、オンのときは、図面に出す書き込みを一覧の絞り込み（種類・分野・状態）に合わせる。

利用者の言う「記号」は、器具タブの印（種類の欄の「個数カウント」）のこと。種類の欄の「記号」は、ツールバーの「☆ 記号」で置くスタンプで、別のもの。

## 変更内容

### 1. 絞り込みの状態をストアで持つ

- `src/editor/annotationFilter.ts` を作り、次を置く。
  - 種類の型（今の `Filter` と同じ値: `all`・`text`・`callout`・`count`・`issue`・`issueOpen`・`issueDone`・`measure`・`shape`・`symbol`・`pen`・`markup`）と、`AnnotationFilter = { kind; discipline: string; status: '' | IssueStatusChoice }`。既定は `{ kind: 'all', discipline: '', status: '' }`。
  - 判定 `matchesAnnotationFilter(annotation, filter)`: 今の一覧の判定（`matchesFilter` と、分野・状態の条件。`legacyChange` の扱いも含む）をそのまま移す。**ページ範囲は含めない**（ページ範囲は今までどおり一覧の中で持つ）。
  - 種類の表示名（選択欄と状態欄で同じものを使う）と、絞り込み全体の表示名 `annotationFilterLabel(filter)`（例: `指摘`、`指摘（未確認）・未回答`、`指摘・分野「電気」`）。
- `AnnotationStore` に、絞り込み（`annotationFilter`）と「図面への反映」（`drawingFollowsFilter`、既定オフ）を持たせる。変えたら通知する。
  - 一覧は、この値を読んで書く。書き込みタブを離れて戻っても、種類・分野・状態・反映は残る（今は「すべて」に戻る。図面と一覧が食い違わないようにするための変更）。
  - 文書ごと、開いている間だけ。PDF には保存しない。ページの整理の `reset(true)` では保ち、`reset()` では既定に戻す。
- 種類の選択欄の「個数カウント」の表示を「個数カウント（器具の印）」にする（値は `count` のまま）。

### 2. 図面での判定

`AnnotationStore` に次を足す。

- `isShownOnDrawing(annotation)`: 反映がオフなら今の `isCountVisible(annotation.count)` と同じ。オンなら `matchesAnnotationFilter(annotation, filter) && isCountVisible(annotation.count)`。
- `drawingFilterActive()`: 反映がオンで、絞り込みが既定（すべて・分野なし・状態なし）でないとき true。
- `drawingHidesCounts()`: `drawingFilterActive()` で、器具の印が条件に合わないとき true（種類が `all`・`count` 以外か、分野・状態の指定があるとき）。
- `drawingHiddenObjNums(pageIndex)`: `drawingFilterActive()` のときだけ、そのページの保存済みの書き込みのうち、絞り込みで隠すものの番号を返す。そうでなければ、すぐ空の配列を返す（**反映がオフの通常の表示に処理を足さない**）。

使う場所:

- `AnnotationLayer.tsx:200` の絞り込みを `isShownOnDrawing` にする（隠したものは描かず、当たり判定もない）。
- `AnnotationStore` の `selectedIds`・`selectOnly`・`toggleSelection`・`selectInRect`・`pruneHiddenSelection`・`visibleCountTotal` を `isShownOnDrawing` にする。絞り込み・反映を変えたら、隠れたものを選択から外す。
- `PageView.tsx:137`、`Viewer.tsx:448`・`:478` の描画から除く番号に `drawingHiddenObjNums` を足す。読み取り専用の文書では、今の `[]` の代わりに `drawingHiddenObjNums` だけを使う（読み取り専用の文書で反映をオンにできるのは一覧を開いたときで、一覧が全ページの書き込みを読み込んでいる）。
- 縮小表示（ページ一覧）・比較・印刷・保存・CSV には効かせない。

### 3. 書き込みタブ

- 種類の選択欄のすぐ下に、チェックボックス「図面にもこの種類だけ表示」を置く。オンのとき、図面は種類・分野・状態の絞り込みに合わせる。ページ範囲は図面には効かない。
- 「次の未対応指摘（ページ範囲内）」で選ぶ指摘が図面への反映で隠れているときは、反映をやめてから選ぶ（6の通知を出す）。
- 一覧の行を押したとき・ダブルクリックしたときの動きは今のまま（反映がオンなら、一覧の行は図面に出ているものだけになる）。

### 4. 器具タブ（目のボタンと矛盾させない）

- `drawingHidesCounts()` のとき、器具リストの見出しの下に「書き込みタブの絞り込み（{絞り込みの表示名}）で、図面に器具の印を出していません。」と、ボタン「図面への反映をやめる」を出す。このあいだ、目のボタンの列は薄く表示する（押すことはできる）。
- 印を表示する操作をしたときは、反映もやめる（押した結果が図面に見えるようにする）:
  - 目のボタンで、器具または分類を表示にしたとき（隠す方向の操作では反映を変えない）
  - 「すべて表示」を押したとき
  - 「選択中の器具だけ表示」をオンにしたとき
- 個数（この図面・全図面）は、表示にかかわらず今までどおり数える。

### 5. 隠れているものを使う操作をしたとき

- **個数カウントの道具を選んだとき**（器具タブで器具を選んだときを含む。`changeTool('count')`）: 器具の印が反映で隠れていれば反映をやめる。選んでいる器具を目のボタンで隠していれば、その器具だけ表示に戻す。隠れた印のまま数えて二重に数えないようにするため。
- **書き込みを作ったとき**（`AnnotationStore.create`。道具・貼り付け・指摘の引継ぎ）: 作った書き込みが反映で隠れるなら、反映をやめる。器具の印で、その器具を目のボタンで隠していれば表示に戻す（「選択中の器具だけ表示」で隠れるときは、その設定をオフにする）。作った直後に見えなくなることがないようにする。
- 元に戻す・やり直し・状態の変更（例: 未回答の指摘を回答済みにして、状態「未回答」の絞り込みから外れる）では、反映を変えない（一覧と同じく、図面からも消える）。

### 6. 解除の通知と状態欄

- 反映を自動でやめたときは、状態欄に「図面の絞り込みを解除しました（{理由}）」と出す。理由は「器具の印を数えるため」「隠れている種類の書き込みを作ったため」「次の未対応指摘を表示するため」「器具の印を表示するため」。
  - 仕組みは問わないが、ストアは DOM・`window` に依存させない（例: ストアに解除の購読 `subscribeDrawingFilterRelease(listener)` を置き、App が表示中の文書について購読して状態欄に出す）。
- `drawingFilterActive()` のあいだ、状態欄に「図面の表示: {絞り込みの表示名}だけ」と、ボタン「解除」を出す（解除は反映をやめるだけで、一覧の絞り込みは残す）。

### 7. ヘルプ

- `HelpDialog` の書き込みの説明に1段落を足す: 書き込みタブの「図面にもこの種類だけ表示」で、図面に出す書き込みを一覧の種類・分野・状態に合わせられること。隠したものは図面で選べないこと。印刷・保存には影響しないこと。個数カウントの道具を選ぶ・隠れている種類の書き込みを作ると解除されること。状態欄の「解除」でもやめられること。
