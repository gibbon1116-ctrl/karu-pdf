## 目的

SPEC-05b の実装（未コミット。作業ツリーにある）を、Claude Code が実際の図面で確かめた。図面名称は七ヶ浜町の30ページすべてで正しく読めたが、**図面番号は1つも読めなかった**。

七ヶ浜町の表題欄（`work/spec05b/shichi-*.png`、`work/spec05b/七ヶ浜町_実施設計図.pdf.json`）:

- 見出しの文字が `図面\t\r No.`（タブと改行が途中に入る）として取り出されていて、見出しとして認められていない。
- 図面番号は、見出しの右に大きな文字の `1116`・`1304`・`1401` など**数字だけ**（4桁）。SPEC-05b で「英字1〜3字＋数字」に限ったため、候補にならなかった。

日本の公共建築の図面では、数字だけの番号や、`電-01`・`機-1`・`E-01-1` のような番号も多い。

## 変更内容（`src/core/drawingInfo.ts` と試験だけ）

1. **見出しの正規化**: 見出しを探す前に、行の文字のタブ・改行・連続した空白を1つの空白にまとめ、`図面 No.`・`図面No.`・`図面 No`・`図 番`・`DWG. No.`・`Drawing No.` などを、空白の有無にかかわらず図面番号の見出しとして認める。名称の見出しも同じく（`図 面 名 称` など）。
2. **見出しの隣の値の形を広げる**（見出しの右・直下にあるときだけ。見出しの無い候補は今の形のまま）:
   - 数字だけ: 2〜5桁（例 `1116`。先頭の 0 を保つ `001`）。
   - 日本語の分野の字＋番号: `電-01`・`電気-1`・`機-12`・`建-001`・`構-1`・`衛-1`・`空-1`・`設-1`（1〜2字の漢字・かな ＋ ハイフン有り無し ＋ 数字1〜4桁 ＋ 任意の枝番）。
   - 英字＋数字の今の形と、枝番が2段まで（`E-101-1-2`）。
   - 前に付く `No.`・`No`・`№`・`#` は取り除いてから判定する。
   - 値の候補は、見出しと同じ行の右（間に別の見出しが無い）か、見出しのすぐ下の行。今の決まりのまま。
   - 見出しの右に、文字の高さが大きく違う行がある（表題欄で番号だけ大きく書く）場合も、同じ表題欄の枠の中（見出しの右で、縦の位置が見出しの行と重なるか近い）なら隣とみなす。七ヶ浜町では見出し `[1047,803,1063,807]` に対し番号 `[1137,807,1165,821]`（右へ約 75pt、下へずれる）。
3. **ページをまたいだ判定**: 数字だけの番号も「多数のページで同じ形（桁数）」の加点の対象にする。全ページで同じ値のものを除く決まりは今のまま。
4. 誤読を避ける決まり（寸法の数字 `2500`・`8000` などを番号にしない）は保つ。数字だけの番号は**見出しの隣にあるときだけ**採る。

## テスト
