## 変更内容

### 1. 「全図面」の内訳（`QuantityBreakdown.tsx`）

- 数量タブの各行の「全図面」の数と、上の要約の「全図面: …」を、押せるボタンにする（`aria-label`「〈表示名〉の全図面の内訳」）。数が 0 のときは押せない。
- 押すと、数量タブの中（一覧の下、または一覧に重ねた小さな枠。画面を移らない）に内訳を出す。`Esc` か「閉じる」で閉じる。

```
EM-CE 3C-5.5sq  ケーブル（EM-CE）      全図面 92.40 m
 [ページ別] [階・部屋別]
 E-101  1階 幹線設備平面図      30.20 m   ← 行を押すとページへ移動
 E-102  2階 幹線設備平面図      28.10 m
 E-401  幹線系統図              34.10 m
 p.12   （図面番号 未設定）      …
```

- 最初に出す見方は、集計方式（`quantityAggregation`）で決める: 全図面→「ページ別」、場所別→「階・部屋別」。もう一方にも切り替えられる。
- **ページ別**: 数量のあるページだけを、ページの順に出す。各行に図面番号・図面名称（SPEC-05b。無ければ `p.12` と出し、名称の欄は空）、そのページの数量（単位付き）。最後に合計。
- **階・部屋別**: 階ごとに合計を出し、その下に部屋ごとの数量（例「1階 32台 ／ 事務室 24台 ／ 会議室 8台」）。階・部屋が無いものは「（階なし）」「（部屋なし）」にまとめる。階の並びは、`B2階 → B1階 → 1階 → 2階 → … → RF → PH階` の順（`normalizeFloor` の形を元に並べる。わからない階は名前の順で最後）。各行を押すと、その場所の数量があるページの一覧に絞った「ページ別」を出す。
- 同一経路の拾い（SPEC-05c）は、その項目の条数を掛けた数量で数える（索引がそうなっている）。行に `（経路 3 本、2条を含む）` のような注は要らない。
- 内訳は、索引（`QuantityIndex`）から作る。開いている間に数量が変われば、作り直された索引で描き直す。

### 2. ページと位置への移動

- ページ別の行を押すと、そのページへ移り（今のページ移動の仕組み。表示の履歴にも残す）、そのページにあるその項目の印・拾いのうち、ページの上から順で最初のものを、画面の中央に来るようにスクロールして選ぶ（選択の道具に切り替えず、今の道具のまま選んだ状態にするのが難しければ、選択の道具に切り替えてよい）。
- 同じ行をもう一度押すと、そのページの次の印・拾いへ移る（最後まで行ったら最初に戻る）。行に「1 / 24」のように今どれかを出す。
- 印・拾いが非表示（目のボタン）のときは、その項目を表示に戻してから選ぶ。
- 位置へのスクロールが難しい表示の状態（ページの整理中など）では、ページへの移動だけ行う。

### 3. CSV（`annotationCsv.ts`）

数量タブの「数量をCSVに書き出す」を押すと、小さな画面で種類を選ぶ: 「集計（項目ごとの全図面の合計）」「明細（項目・ページ・場所ごと）」。今の数量表（項目×ページの表）は「集計」の中に含める。

- **集計 CSV**（1行が1項目）:
  - 列: `分類, 略号, 名称, 規格, 種別, 単位, 集計方式, 全図面の合計, 表示中の図面（p.N）, ` の後に、数量のあるページの列。ページの列の見出しは `p.3 E-101`（図面番号が無ければ `p.3`）。
  - 種別: 個数・長さ・面積・体積。集計方式: 場所別・全図面。
  - 数値の書式は今と同じ（個数は整数、それ以外は小数2桁）。
- **明細 CSV**（1行が「項目 × ページ × 階 × 部屋」）:
  - 列: `分類, 略号, 名称, 規格, 種別, 単位, 集計方式, 階, 部屋, ページ番号, 図面番号, 図面名称, 数量, 拾いの件数`。
  - 同じ項目・ページ・階・部屋の拾いを合計する。並びは、項目の一覧の順 → ページの順 → 階の順 → 部屋の名前の順。
- BOM・CRLF・数式化の抑止（`quote`）は今と同じ。ファイル名は `〈文書名〉_数量集計.csv`・`〈文書名〉_数量明細.csv`（文書名は SPEC-05a で保存先の名前になる）。
- 書き込みタブの CSV（`createCsv`）にも、数量拾いの行に `階, 部屋, 図面番号` の列を足す（他の種類の行は空欄）。

### 4. ヘルプ

`HelpDialog.tsx` の数量拾いの説明に、「全図面」を押すと内訳が出てページへ移れること、ページ別・階・部屋別の見方、集計 CSV と明細 CSV を足す。

## 動作の軽さ

- 内訳と CSV は、索引（SPEC-05c）から作る。全注釈を回り直さない。
- 位置への移動のとき、そのページの注釈が読み込まれていなければ読む（数量タブを開いた時点で全ページ読まれているはずだが、念のため）。

## テスト

- **単体**: 集計 CSV・明細 CSV の見出しと行（指示書の例: EM-CE 3C-5.5sq の E-101 30.20・E-102 28.10・E-401 34.10 → 92.40、根切り C-101 12.50・C-102 18.20・C-103 8.40 → 39.10、溝掘削 4.20・6.50・3.10 → 13.80、LED埋込形の 1階事務室 24・1階会議室 8・2階事務室 32）。図面番号の無いページの見出しが `p.N` になること。階の並び順。
- **画面（`e2e/quantity-breakdown.annotate.spec.ts`）**:
  1. 3ページ（図面番号 E-101〜E-103）に長さの項目を拾い、「全図面」を押すと、拾ったページだけが図面番号・名称・数量付きで出て、合計が合う。
  2. 2ページ目の行を押すと、2ページ目へ移り、その項目の拾いが選ばれる。もう一度押すと、同じページの次の拾いへ移る。
  3. 個数の項目（場所別）で「全図面」を押すと、階・部屋別が先に出て、階の合計と部屋の数が合う。部屋の行を押すと、その部屋のページの一覧になる。
  4. ページの整理で、拾いのあるページを1枚削除すると、全図面の合計がその分だけ減る（ケーブル 30+20+50=100 → 20 のページを消して 80。土工も同じ）。並べ替えでは合計は変わらず、内訳のページの番号だけが変わる。
  5. 集計 CSV と明細 CSV を書き出し、列と値が合う。
