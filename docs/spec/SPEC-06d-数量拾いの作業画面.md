## 目的

利用者の指示（要約）:

- 数量拾いでは、左で項目を選ぶ → 中央の PDF で拾う → 右で設定 → 左で項目を替える → PDF に戻る、と画面の端から端までマウスを往復させている。PDF から大きく動かずに、**今の項目の確認・前後の項目への切替・最近使った項目への切替・取消**ができるようにする。
- 拾っている最中に、**今の項目（略号・規格・名称）・この図面の数量・全図面の数量**が一目でわかるようにする。PDF を大きく隠さない。マウスに追従して PDF を隠す画面にはしない。
- 左の数量の一覧は、表示・印・見本・略号・名称・この図面・全図面と情報が多い。**拾う作業の表示と、項目の設定・管理の表示を分ける**。よく使う情報を優先し、詳しいものは必要なときに出す。

## 変更内容

### 1. 最近使った項目（`AnnotationStore`）

- `recentFixtureIds: readonly string[]`（最大 8、新しい順）。`selectFixture(id)` で `id` が null でなければ先頭へ移す（重複は除く）。項目を削除したら除く。PDF には保存しない。`reset()` で空にする（ページ整理の後に項目一覧を読み直す `reset(true)` では保つ）。
- 数量拾いで新しい拾いを作ったとき（`create` に `count` か `quantity` が付くとき）も、その項目を先頭へ移す。

### 2. 左の数量タブの「拾う／管理」

- 見出しの横に2つのボタン（`aria-pressed`）「拾う」「管理」。選んだものはブラウザーに保存（`localStorage` の `karu-pdf:fixture-panel-mode`、読み書きは try/catch、既定は「拾う」）。
- **拾う**（既定）で出すもの:
  - 見出し「数量拾い」（今のまま）。図面番号の読み取りの状態は、読み取り中・失敗のときだけ1行で出す（「読み直す」ボタンは管理に移す）。
  - 選んだ項目の要約（`.fixture-count-summary`。今のまま）。
  - 1行の操作: 「項目を追加」「標準マスタから追加」（名前は今のまま）。
  - 最近使った項目: 「最近」の後に、最大 6 個の小さなボタン（見本の印か線の見本 + `fixtureCode`。`title` に名称）。押すと `selectFixture` + `ui.select()`。最近が無ければ出さない。
  - 現在の場所（階・部屋）を1行に詰めて（今の部品のまま）。
  - 検索欄（今のまま）。
  - 一覧: 分類の見出し（折りたたみ、件数）と、各行に **印か線の見本・略号と規格・名称（省略表示、`title` に全文）・この図面・全図面** だけ。列の見出しは「項目・この図面・全図面」。行のボタンの accessible name（`${fixtureCode(f)} ${f.name}`）と `.fixture-row-count`、全図面の内訳のボタンは今のまま。
- **管理**で出すもの: 今の画面のすべて（読み直す、全部の操作のボタン、3つのチェックボックス、すべて表示、表示切替、見本、つまみとドラッグの並べ替え、7列）。
- 拾うでは出さないもの: 行と分類の表示切替（目）、見本の列、つまみ（ドラッグの並べ替えは管理でだけできる）、複製・編集・削除・他のPDFから読み込む・CSV・上へ・下へ、3つのチェックボックスとすべて表示、図面番号・図面名称を読み直す。
- 拾うの一覧の行は、今より1行の高さを詰める（目安 28px）。数量タブの幅は変えない。

### 3. 拾いバー（`PickupBar.tsx`）

- 置き場所: `.viewer-slot` の中の、図面の表示領域の**左上**に重ねる（`position: absolute`、余白 8px、スクロールしても動かない）。分割表示のときは左（作業中の文書）の表示の左上。ボタンで**左下**に移せる（`localStorage` の `karu-pdf:pickup-bar-position` に `top`/`bottom`）。マウスには追従しない。
- 出すとき: 道具が「数量拾い」（`tool === 'count'`）のとき、または選択が数量拾いの印・経路だけ（`store.selectedPickupsOnly()`）のとき。編集の制限がある文書・ページ整理中・比較中は出さない。
- 大きさ: 高さは1行（目安 32px）。幅は中身に合わせ、図面の表示領域の幅の 70% まで（はみ出す名称は省略）。背景は半透明の白（`rgba(255,255,255,.94)`）、影は弱く。
- 中身（`role="toolbar"`、`aria-label="拾いバー"`）:
  1. 「前の項目」ボタン（◀）
  2. 今の項目: 印か線の見本 + `fixtureCode` + 名称（省略）。押すと「項目を選ぶ」小さな一覧（下の 4.）を開く。項目が無ければ「項目を選んでください」。
  3. 「次の項目」ボタン（▶）
  4. `この図面 12.35 m`・`全図面 48.20 m`（数は今の要約と同じ書式。個数は単位「個」）
  5. 「元に戻す」ボタン（`store.undo()` と同じ。今の Ctrl+Z の処理を呼ぶ。`title="元に戻す（Ctrl+Z）"`）
  6. 位置の切替ボタン（`aria-label="拾いバーを下に移す"` / `"拾いバーを上に移す"`）
- 前後の項目: 数量タブの一覧と同じ並び（`groupFixtures` の順、検索の絞り込みは使わない）で、今の項目の前・後の項目を `selectFixture` + `ui.select()`。端では無効。
- 数量拾いの印・経路を選んでいるときは、今の項目の代わりに、選んだものの項目（1件ならその項目、複数で同じ項目ならその項目、違えば「N件を選択中」）を出す。
- 拾いバーの上でのクリック・ホイールは図面に渡さない（図面に点を打たない）。

### 4. 「項目を選ぶ」小さな一覧（`fixtureQuickList`）

- 拾いバーの今の項目を押すと、バーのすぐ下（バーが下のときは上）に開く（`role="dialog"`、`aria-label="項目を選ぶ"`）。Esc・外側のクリックで閉じる。
- 上に検索欄（`aria-label="項目を検索"`、開いたらフォーカス）。その下に「最近」（最近使った項目）、続いて分類ごとの項目（今の PDF の項目すべて、一覧と同じ順）。検索は数量タブと同じく `fixtureCode + 名称` の部分一致。
- ↑↓ で移動、Enter で選ぶ。押すと `selectFixture` + `ui.select()` して閉じる。
- 描く行は最大 200（それより多ければ「検索で絞り込んでください」）。

### 5. キー（`App.tsx`）

- `[` で前の項目、`]` で次の項目（拾いバーの前後と同じ）。入力欄の中・修飾キー付き・ページ整理中・比較中は無視。数量タブの項目が読み込まれていないときは何もしない。
- ヘルプのキーの一覧に足す。

### 6. 性能

- 拾いバーは `store.quantityIndex()`（今の索引）だけを使う。新しい集計・全注釈の走査をしない（`selectedPickupsOnly()` は選択中の注釈だけを見る）。
- 拾いバー・一覧は、出していないときに描かない。

### 画面（新規 `e2e/pickup-bar.annotate.spec.ts`）

白紙2ページの PDF。項目を3つ（個数 LED、長さ CV、長さ PF22）作る。

1. 数量タブは「拾う」で開く: 表示切替（目）のボタンと「複製」が見えない。「管理」を押すと見える。もう一度開き直しても（`page.reload()` の後）「管理」のまま。「拾う」に戻す。
2. LED を選ぶ → 「数量拾い」の道具になり、拾いバーが出て `LED` と `この図面 0`・`全図面 0` が見える。図面を2回クリックすると `この図面 2`・`全図面 2`。
3. `]` で次の項目（一覧の順で LED の次）に替わり、バーに出る。`[` で戻る。拾いバーの ▶ でも替わる。端では無効。
4. 拾いバーの今の項目を押す → 「項目を選ぶ」が開き、検索欄に `pf` → `PF22` だけ → Enter で PF22 になる。
5. 最近: LED・CV・PF22 の順に選ぶと、数量タブの「最近」の並びが PF22・CV・LED。押すと替わる。
6. 「元に戻す」を押すと直前の拾いが消える。
7. 拾いバーの位置の切替で下に移り、`page.reload()` 後も下。
8. 選択の道具で経路を1本選ぶと、その項目がバーに出る。選択を外し、道具を「選択」にするとバーが消える。
9. 拾いバーの上をクリックしても図面に点が打たれない（拾いの数が増えない）。

- マウスに追従して PDF を隠す画面にしないこと。拾いバーは1行に収める。

- 同じ作業フォルダで、別の作業（同じ記号を探す: `src/core/symbolSearch.ts`・`src/worker/symbolSearch.worker.ts`・`src/client/SymbolSearchClient.ts`、`App.tsx` の試験用フック）が同時に進んでいる。`App.tsx` はキーの処理の所だけを変え、他の行を書き換えないこと。対象外のファイルに型エラーや変更があっても触らず、報告だけすること。
