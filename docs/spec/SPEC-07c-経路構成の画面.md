# SPEC-07c: 経路構成の画面（部分ごとの施工条件・立上りの一覧・一括変更・経路を分ける）

## 実行モデル指定（必須）

- モデル: `gpt-6.1-sol`
- reasoning effort: `high`
- 選定理由: 利用者が毎回使う画面の作り替えで、ストアの操作・Undo・描画にまたがるため

---

## 目的

計画: `docs/調査/施工条件別数量拾い_計画.md`。前提: SPEC-07a（データ・ストアの操作）と SPEC-07b（候補・既定）の実装。必ず両方の SPEC を読むこと。

利用者の指示:
- 「全長／平面＋立上り／立上りのみ」の選択肢をやめる。
- 平面と立上り・立下りに、それぞれ施工条件を簡単に設定できるようにする。
- 同じ経路の部材ごとに、違う条件を設定できるようにする。
- 区間ごとに条件が変わる場合は、区間別に拾えるようにする。
- 平面だけ・立上りだけの拾いにも対応する。
- 立上り・立下りの長さは、今どおり手入力する。
- 入力の操作を増やしすぎない。直前の条件の引継ぎと、一括変更をできるようにする。
- 操作画面を複雑にしない。

- `src/app/RouteItems.tsx`（書式欄の「経路構成」）は次の内容を表示している。
  - 平面の長さ、立上り・立下り（1つの入力）、余長・その他。
  - 部材のカード（主・追加。範囲の選択、条数、長さ）、「＋ 線要素を追加」（`LinePicker`）、「よく使う構成」。
- `src/app/FormatPanel.tsx` 188 行で、線の拾いを1つだけ選んだときに `RouteItems` を出す。
- 192 行の「項目を変更」は、複数選択にも効く。
- 線以外の数量（面積など）と器具には、施工条件の欄が無い。

## 変更内容

### 1. 経路構成（`RouteItems.tsx`）の作り替え

**長さの欄**（経路に1つ）

- 平面: `12.40 m`（計算値、今どおり）。
- 立上り・立下り: 1 か所ごとの行。
  - 各行は、長さの入力（今の `QuantityValueInput`）、位置の選択、削除の「×」。
  - 位置の選択肢は、なし・始点・頂点2…・終点。`Rise.at` に入れ、表示は 07e の印。
  - 「＋ 立上り・立下りを足す」で行を足す。最大 20。
  - 行が無いときは、「＋ 立上り・立下りを足す」だけを出す。
  - 行にマウスを載せる・入力にフォーカスすると、`store.setHighlightedRise({ annotationId, riseIndex })` を呼ぶ（離れたら `null`）。07e でその頂点の印が強調される。
- その他の加算: 今の「余長・その他」の入力。名前を変え、説明（`title`）を付ける（SPEC-07b の文言）。

**部材のカード**（主・追加。今の並び・主にする・外す・条数はそのまま）

- 範囲の選択（全長など）を消す。
- 代わりに、部分ごとに施工条件の選択を出す。
  - 「平面」の選択。
  - 「立上り」の選択。立上りが1か所以上あるときだけ出す。
  - 「その他」の選択。その他の加算が 0 より大きいときだけ出す。
- 選択肢は、未設定（既定の表示）、その項目の候補、候補外の今の値（あれば）、「数えない」、「＋ 条件を追加…」。
  - 「＋ 条件を追加…」を選ぶと、カードの中に入力欄が開く。Enter で、その項目の候補に足して（1 回の Undo）、その条件にする。Esc でやめる。
- **立上りが2か所以上のとき**
  - 「立上りごとに選ぶ」のチェックを出す。
  - オンにすると、`立上り1（3.00 m）` のように1か所ごとの選択を並べる。
  - オフに戻すと、1つ目の値をすべてに適用する。
- **カードの長さの表示**: `平面 12.40 ＋ 立上り 5.50 ＝ 17.90 m（×2条 35.80 m）`。数えない部分は表示しない。
- 未設定の部分がある部材のカードには、小さく「施工条件が未設定」と出す。項目に候補が無いときは出さない。
- 変更は、SPEC-07a の `setRouteMembers`・`setRouteRises`・`setRouteCondition` で行う。どれも Undo できる。
- 部材を足す（`LinePicker`）ときの条件は、SPEC-07b の既定の順（引継ぎ → 項目の既定 → 未設定）。

### 2. 経路を分ける（区間別に拾う）

- 経路構成の下に「経路を分ける」を出す。頂点が3つ以上のときだけ。
  - 押すと、分ける頂点の選択（頂点2〜頂点n−1）と「分ける」「やめる」が出る。
  - 選んだ頂点は、描画で強調する（07e の立上りの印と同じ仕組みでよい。例: ストアに `highlightedVertex` を足す）。
- **ストアの操作** `splitRoute(id, vertexIndex)`（`AnnotationStore.ts`、1 回の Undo で戻る）
  - 元の経路は頂点 0〜`vertexIndex`。新しい経路は `vertexIndex`〜最後。
  - 新しい経路が持つもの:
    - 同じ項目、部材、条数、`cond`。
    - 同じページ・縮尺・階・部屋・書式。
    - 新しい id。
  - 立上りの扱い:
    - `at` が `vertexIndex` 以上の立上りは、新しい経路へ移す（`at` を詰める）。
    - それ以外と、`at` の無い立上りは、元の経路に残す。
  - その他の加算は、元の経路に残す。
  - 分けた後の2本の数量の合計は、分ける前と同じ。
  - 分けた後は、新しい経路を選ぶ。
- 新しい経路の部材の条件は、元と同じ。利用者が新しい経路で条件を変える。

### 3. 線以外の数量と器具の施工条件（`FormatPanel.tsx`）

- 線以外の数量の拾い（面積・体積など）か、器具の印を選んでいるときに、「施工条件」の選択を出す。
  - 選択肢は、未設定・その項目の候補・候補外の今の値・「＋ 条件を追加…」。
  - 項目に候補が無ければ「＋ 条件を追加…」だけ。
- 複数選択（同じ項目）にも効く。`setQuantityCondition` を使い、1 回の Undo。

### 4. 一括変更（線の拾いを2本以上選んだとき、`FormatPanel.tsx`）

「施工条件をまとめて変える」の欄を出す。
- 欄の中身:
  - 部材: 選んだ経路に含まれる項目。主・追加を問わない。
  - 部分: 平面・立上り（すべて）・その他。
  - 条件: 未設定・候補・数えない・「＋ 条件を追加…」。
  - 「適用」ボタン。
- 適用すると `setRouteCondition(ids, itemId, part, condition)` を呼ぶ（1 回の Undo）。
- 結果は「12 本の CV の平面をケーブルラック配線にしました（Ctrl+Z で戻せます）」のように `role="status"` に出す。
- その部材を含まない経路は変えない。

### 5. よく使う構成・引継ぎ

- 「よく使う構成」の登録と適用は、部材と部分ごとの条件を含める（SPEC-07a で保存の形は済み）。
- 一覧の要約（`routeSetSummary`）に、条件を短く出す。例: `CV 5.5sq-3C（ラック／管内）＋ PF22（立上り）`。
- 同じ項目の新しい経路は、直前の条件を引き継ぐ（SPEC-07a）。引継ぎの元は、拾いバーの「構成」の表示（`PickupBar.tsx` の `pickup-template`）と同じ場所に、短く出す。
  - 例: 「直前の条件: ラック／管内」。
  - 「×」で引継ぎをやめる（その項目の引継ぎをストアから消す）。

### 6. ヘルプ（`HelpDialog.tsx`）

経路構成の説明を、次の内容に書き換える。
- 平面と立上り・立下りに分けて、部材ごとに施工条件を選ぶこと。
- 数えない部分の選び方。
- 立上りを1か所ごとに分けられること。
- 経路を分けること。
- その他の加算には、切り無駄を入れないこと。
- 一括変更と引継ぎ。
- 未設定のままでよいこと（後で集計表から探せる）。

## テスト

### 単体

- `splitRoute`: 頂点・立上りの移し方。合計が変わらないこと。1 回の Undo で戻ること。
- 一括変更の対象: 部材を含まない経路は変わらない。

### 画面（e2e、書くだけ。既存の `e2e/route-*.spec.ts` 等の作り方に倣う）

- CV の経路を描く。
  - 平面を「ケーブルラック配線」、立上り（3.00）を「管内配線」にすると、カードの表示と、集計の `byCondition`（`window.__karu` 経由で確かめられるならそれで）が合う。
- PF を追加して、平面を「数えない」、立上りを「隠ぺい配管」にする。PF の数量は立上りだけになる。
- 立上りを2か所にして「立上りごとに選ぶ」で別の条件にする。それぞれの条件に分かれて集計される。
- 「＋ 条件を追加…」で候補が増え、その条件になる。Ctrl+Z で戻る。
- 経路を頂点2で分けると、2本になり、合計が同じ。
- 2本選んで一括変更すると、両方の平面が変わる。
- 古い形式（`scope: 'rise'`）の拾いを開くと、平面が「数えない」と表示され、数量が変わらない。
- 面積の拾いと器具の印で、施工条件を選べる。

既存の e2e で、範囲の選択（全長など）を前提にしているものは、新しい画面に合わせて直す。何をなぜ変えたか報告すること。
