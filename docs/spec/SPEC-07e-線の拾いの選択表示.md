# SPEC-07e: 線の拾いを選んだとき、線そのものを強調する（外接矩形の枠をやめる）

## 実行モデル指定（必須）

- モデル: `gpt-6.1-sol`
- reasoning effort: `high`
- 選定理由: 描画層の選択表示・強調・性能（多数の注釈）にかかわるため

---

## 目的

利用者の指示（2026-10-08）:
- ケーブル等を選んだとき、広い矩形で囲われて、選んだ線が分かりにくい。
- 線状の数量拾いを選んだら、対象の線そのものを強調する。不必要に大きい矩形の枠は出さない。
- 平面と立上り・立下りの数量を確かめるときも、対象の箇所が分かる表示にする。
- 折れ線・頂点の編集・移動の機能は保つ。
- 集計表から対象へ移動したときも、同じ強調にする。
- 表示の処理で動作を遅くしない。

## 変更内容

### 1. 計測・数量の線と面（`annotation.measure && annotation.vertices` を持つ注釈）を選んだとき

- 外接矩形の `annotation-selection` を描かない。
- 代わりに、**選択の経路** `<polyline|polygon className="annotation-selection-path">` を描く。
  - 経路は頂点を結んだ線。面積（`measure.kind === 'area'`）は閉じた多角形の辺。
  - 見た目:
    - 青（`#1473e6`）、不透明度 0.55。
    - 太さは、線の太さ＋ 6 CSS px 相当（今の白い縁取りと同じく、拡大率で換算）。
    - 端と角は丸め、塗りは無し。
  - 線の**下**に描く（線の色を隠さない）。
    - `SelectionHalo` の白い縁取りより下に、青い太い線を置く。
    - 重なりの順は、青い太い線 → 白い縁取り → 線。
- 頂点の取っ手・移動・頂点の編集の操作は今のまま。当たり判定の要素（`annotation-hit`）も変えない。
- 複数を選んだ場合も、それぞれに選択の経路を描く。矩形は描かない。
- 個数の印・文字・図形など、計測でない注釈は今のまま（矩形）。

### 2. 立上り・立下りの位置

SPEC-07a の `QuantityMark.rises[i].at`（頂点の番号）があり、その拾いを選んでいるとき:
- その頂点に、小さな印（「↕」と番号。立上りが2か所以上なら `↕1`・`↕2`）を描く。
  - 大きさは画面上で一定（拡大率で換算）。
  - `pointer-events: none`。
- ストアに `highlightedRise: { annotationId: string; riseIndex: number } | null` と `setHighlightedRise(...)` を足す（Undo の対象外。画面だけの状態）。
  - 該当の印を強調する（橙・少し大きく）。
  - 07c の経路構成の画面が、立上りの行にマウスを載せたときにこれを設定する。この段階では、ストアの操作と描画だけ作る。

### 3. 集計表・内訳から移動したとき（`flashPickup`）

- 計測・数量の線・面は、外接矩形の枠ではなく、**経路に沿った橙の線**を光らせる。
  - 太さは線の太さ＋ 10 CSS px 相当。1.2 秒で不透明度 1 → 0。
  - 拡大の変形はしない（線から外れるため）。
- 移動後は今どおりその拾いを選ぶので、1. の選択の経路も表示される。
- 個数の印は今のまま（矩形の枠）。

### 4. 性能

- 選択の経路は、選ばれた注釈だけに描く。選ばれていない注釈の描画は今と同じ。
- 頂点の多い経路（1,000 頂点）を選んでも、ドラッグ中の描画が遅くならないこと。
  - 頂点の文字列は、今の当たり判定の `points` の文字列を使い回してよい。
- 新しいフィルタ（SVG の `filter`）やアニメーションの常時実行は使わない。
