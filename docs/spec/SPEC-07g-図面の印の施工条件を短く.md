# SPEC-07g: 図面上の拾いの文字では、施工条件を短く書く

## 実行モデル指定（必須）

- モデル: `gpt-6-luna`
- reasoning effort: `max`
- 選定理由: 文字の短縮表と、既存の関数1つの差し替えだけの局所修正

---

## 現状

- `src/core/quantity.ts` の `conditionSuffix(cond)` は、経路の部材の施工条件を全文で返す。例: `（二重天井内・二重床内・ピット内・トラフ内配線／管内配線）`。
- これを `quantityLabel`（図面上の拾いの文字。PDF に保存される文字）が使うため、図面の上に長い文字が出て、図面に重なる。
- `src/app/routeSets.ts` の `routeConditionSummary` には、別に短縮の処理がある（よく使う構成の一覧用）。

## 変更内容

1. `src/core/quantity.ts` に `export function conditionShortName(name: string): string` を作る。
   - 次の表にある名前は、表の略称を返す。
   - 表に無い名前は、全角・半角の括弧「（…）」「(…)」の部分を除く。それが 8 文字を超えたら、7 文字＋「…」にする。

| 施工条件 | 略称 |
|---|---|
| 管内配線 | 管内 |
| 合成樹脂管内配線（PF・CD・FEP） | PF管内 |
| ケーブルラック配線 | ラック |
| 二重天井内・二重床内・ピット内・トラフ内配線 | 天井内等 |
| ダクト内配線 | ダクト内 |
| サドル止め（コンクリート） | サドル |
| サドル止め・ステープル止め（木造） | ステープル |
| 地中管路内 | 地中 |
| 架空（ちょう架） | 架空 |
| 隠ぺい配管 | 隠ぺい |
| 露出配管 | 露出 |
| コンクリート埋込配管 | 埋込 |
| 地中埋設 | 地中 |
| 屋内一般配管 | 屋内一般 |
| 機械室・便所配管 | 機械室 |
| 屋外配管（架空・暗渠内・共同溝内） | 屋外 |
| 屋外露出配管 | 屋外露出 |
| 地中配管 | 地中 |
| 屋内露出（一般居室・廊下） | 屋内露出 |
| 屋内隠ぺい（天井内・パイプシャフト） | 隠ぺい |
| 機械室・書庫・倉庫 | 機械室 |
| 屋外露出・浴室・厨房 | 屋外露出 |
| 隠ぺい（埋込） | 埋込 |

2. `conditionSuffix(cond, short = false)` に引数を足す。`short` のとき、各名前を `conditionShortName` で短くする。
   - 重複の除去は、短くした後で行う。
3. `quantityLabel` は `conditionSuffix(..., true)` を使う。
4. `routeSets.ts` の `routeConditionSummary` は、独自の短縮をやめ、`conditionSuffix(cond, true)` を使う。
5. 画面の説明（`title` など）で全文を出している所は、今のまま全文。
