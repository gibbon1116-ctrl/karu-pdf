## 変更内容

### 1. 添字の語の規則（`src/core/symbolLabels.ts`・`src/worker/labelExtract.ts`）

- 数字を3つ以上含む語は、添字にしない（回路番号 `G301`・`222` など）。
- 同じ文字で、矩形がほぼ同じ（中心の差が 0.3pt 以内）の語は、1つにまとめる（重ね書き）。
- **1つの候補に、G 以外の語が2つ以上割り当たったとき**
  - 最も近い語との距離 `d0` を求め、`d0 + 0.5pt` 以内の語だけを残す。
  - 残った語の数は、結果の説明に出さなくてよい。
- G の分離（SPEC-08a）は今のまま。G は、距離にかかわらず `gc` に数える（R 以内であること）。

### 2. 見本からの配線の除去（`prepareVectorTemplate`）

今の「同じ直線上の連鎖」の規則に加えて、**枠の外へつながる線の道**を除く。

**起点**
- 次の線が起点になる（どちらも見本の中の線）。
  - 片方の端が枠（± tol0）の外にあり、枠と交わるページの線（今と同じ）につながる線。
  - 片方の端が、枠の辺から tol0 以内にある線。

**たどり方**
- 端点どうしが tol0 以内でつながる見本の線を、順にたどる。
- 進めるのは、つながりの数（その端点に集まる線の数）が2の点だけ（折れ線の曲がり）。

**止まる所**
- 3本以上が集まる点。
- 端点が他の線の途中（端点でない所）に tol0 以内で触れる点（配線が円に当たる所など）。
- その手前までの線を「配線」として除く。

**守る線**
- 閉じた輪（円・四角）の線は除かない。
  - 輪の線は、たどる途中で起点に戻ってくる。たどった線が閉路を作るなら、その道は除かない。

**戻す条件**
- 除いた後の見本が、元の長さの 40% 未満、または 2 本未満になったら、この規則での除去をやめる（今の戻す条件と同じ）。
- `removed.wiring` に、この規則で除いた本数も足す。

### 3. 試験

**単体**
- 添字:
  - `G301`・`222` を除く。
  - 重ね書きを1つにまとめる。
  - `2C` と `4H` が1つの候補に割り当たり、4H が近いと `4H` だけ残る。
  - 同じ距離の `ET` と `LK`（差が 0.5pt 以内）は両方残る。
- 配線の除去（合成の線で）:
  - 円＋2本線の記号に、枠の外から入ってきて途中で直角に2回曲がって円に当たる配線 → 配線の3本が除かれ、円と2本線が残る。
  - 円に当たらずに枠の中で終わる配線の道 → 除かれる。
  - 四角い記号（閉じた輪）が枠の辺に接していても、除かれない。
  - 記号の中の線が、輪の途中から出て輪の途中に戻る（2本線のような）場合、除かれない。

  - 記号だけ: `[279.6,96.9,284.6,101.9]`
  - 広め: `[275.5,93.5,284.6,101.9]`
- 合否は、広めの見本で 300 件以上見つかり、添字に `G3` で始まる語が無いこと。
