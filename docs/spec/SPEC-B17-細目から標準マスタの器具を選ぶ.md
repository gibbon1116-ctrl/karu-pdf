# SPEC-B17: 内訳書の細目（ＬＥＤ照明器具など）から標準マスタの器具の種類・規格を選ぶ

## 実行モデル指定（必須）

- モデル: `gpt-6.1-sol`
- reasoning effort: `high`
- 選定理由: 品目一覧の組み立て（細目の行と既存マスタの重ね合わせ）、内訳書から選ぶ画面の表示、既存の試験の見直し、e2e にまたがる

---

## 背景（利用者の試用の結果、2026-10-12）

> 標準マスタから追加の内訳書から選ぶを選んだ時、電灯分岐から照明器具の選定ができない。

調べた結果（Claude）: 「内訳書から選ぶ」→ 電気設備 → 庁舎 → 電灯設備 → 電灯分岐 の「ＬＥＤ照明器具（個）」は、チェックを付けると「記号」の自由入力だけが出る。標準マスタの照明器具の種類（DL ダウンライト φ100…、BL ベースライト 40形… など）を選べない。別紙明細の明細では `DetailTemplate.master`（例: 電線 → 標準マスタの電線の種類）で既存マスタの規格を選べるが、細目の行には同じ仕組みが無い。

データは Claude が作成済み（**変えないこと**）: `src/core/breakdown/electricalDetails.ts` の `ELECTRICAL_ROW_MASTERS`（細目の行の名前 → 既存マスタ（`quantityMaster.ts` の `QUANTITY_MASTER`）の種類（`type`）の一覧）。ＬＥＤ照明器具 → DL・BL・BE・BR・PD・SP・OL、非常用照明器具 → 非常用照明、誘導灯 → 誘導灯（避難口）・誘導灯（通路）、煙感知器 → SD、熱感知器 → HD、スピーカ・天井形スピーカ → SPK、カメラ → CAM。

## 対象

- 変更: `src/core/catalog.ts`（`catalogItemsForBreakdownRow`・品目の組み立て）、必要なら `src/app/BreakdownPicker.tsx`
- 試験: `tests/catalog.test.ts` に追記・期待値の見直し、`e2e/breakdown-master.annotate.spec.ts` に 1 件
- 変えない: データ、`quantityMaster.ts`、ほかの画面

## 1. 細目の行から既存マスタの規格を選ぶ（`catalog.ts`）

- 電気設備の別紙明細でない行で、`ELECTRICAL_ROW_MASTERS[行の名前]` があるとき、`catalogItemsForBreakdownRow(entry)` は次を返す:
  1. 対応する既存マスタの種類ごとの品目（別紙明細の `master` の明細と同じ重ね合わせの作り方。規格（`specs`）ごとの選択肢、略号・名前・規格・施工条件の候補は既存マスタのまま）。重ね合わせた品目の鍵は既存の品目の鍵と別にする（例: `${既存の鍵}#row:${行の鍵}`）。**品目の単位は行の単位**（個・灯）、内訳書の位置は行（細目 = 行の名前）、摘要の区分は行の `summary`（記号など）を重ねる。
  2. その後ろに、今の行の品目（記号だけで作る、今と同じもの）。
- 追加される項目: 名前・略号・規格は既存マスタのもの（例: `DL ダウンライト φ100`）、内訳書の位置は 電気設備／庁舎／電灯設備／電灯分岐／ＬＥＤ照明器具、単位は行の単位、摘要の「記号」は既存マスタの略号を既定値に入れる（入力があればそれ）。
- 「規格から選ぶ」の既存の品目（照明器具の DL など）は変えない（内訳書の位置を付けて追加する今の流れもそのまま）。

## 2. 画面（`BreakdownPicker.tsx`、必要なときだけ）

- 細目の行の下に、重ね合わせた品目ごとの選択（既存の別紙明細の明細と同じ見た目: 種類の名前の下に規格のチェック）と、最後に今の記号の入力の品目が並ぶ。行が多いときは、別紙明細の「明細を選ぶ（n）」と同じように、`器具を選ぶ（n）` のボタンで開閉してよい（最初は閉じる。記号の入力の品目は常に出す）。

## 3. 試験

- `tests/catalog.test.ts`: 電灯分岐の ＬＥＤ照明器具（個）の `catalogItemsForBreakdownRow` が DL・BL・BE・BR・PD・SP・OL の 7 品目＋記号の品目の 8 件。DL の品目の規格は φ100・φ125・φ150・φ200、単位は 個、内訳書の位置の細目は ＬＥＤ照明器具。外灯の ＬＥＤ照明器具（灯）では単位が 灯。誘導灯は 2 品目＋記号の品目。`ELECTRICAL_ROW_MASTERS` のすべての種類が既存マスタにある（無い種類があれば試験で失敗する）。「規格から選ぶ」の DL の品目（鍵・単位・内訳書の位置なし）は今のまま。
- e2e（`e2e/breakdown-master.annotate.spec.ts` に追記）: 内訳書から選ぶ → 電気設備 → 庁舎 → 電灯設備 → 電灯分岐 → ＬＥＤ照明器具 で DL ダウンライト の φ150 を選んで追加 → 項目の名前・略号・規格・内訳書の位置（細目 ＬＥＤ照明器具）・単位 個・摘要の記号 DL。

## 禁止事項

- データを変えないこと。既存の品目の鍵・選択肢を変えないこと（重ね合わせた品目は新しい鍵）。依存パッケージを足さないこと。指定外のファイルを変えないこと。
