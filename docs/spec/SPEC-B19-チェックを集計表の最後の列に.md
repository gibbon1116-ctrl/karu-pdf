# SPEC-B19: チェックの判定を集計表の最後の列に出す（集計表は常に表示）

## 実行モデル指定（必須）

- モデル: `gpt-6.1-sol`
- reasoning effort: `high`
- 選定理由: 仮想スクロールの表への列の追加、遅延読込の判定と項目の対応、表示の切り替えの作り直し、e2e の見直しにまたがる

---

## 背景（利用者の要望、2026-10-12）

> チェックシートは集計表の列の最後につけてください。集計表を表示する方が優先度は高いです。

SPEC-B15 では、集計表の `チェックシート` を押すと表の代わりにチェックの表示（`QuantityChecks`）が出た。これを、**集計表はいつも表示し、判定は表の最後の列に出す**形に変える。基本の値の入力と判定の一覧は、表の上に開閉できる欄として残す（表を隠さない）。

## 対象

- 変更: `src/app/QuantityTable.tsx`、`src/app/QuantityChecks.tsx`（基本の値の入力と判定の一覧の欄として使う。表を置き換えない）、`src/app/QuantityChecks.css`、`e2e/quantity-checks.annotate.spec.ts`
- 新規（必要なら）: `src/app/quantityCheckColumn.ts`（項目 → 判定の対応。遅延読込）
- 変えない: `src/core/quantityChecks.ts`・`checkSheets.ts`・保存・Excel（Excel の `チェックシート` のシートは今のまま）

## 1. 最後の列「チェック」

- 建築の項目（`breakdown.book === '建築'`）が 1 つ以上あるとき、集計表の列の**いちばん最後**（図面・階・部屋の列の後ろ）に `チェック` の列（幅 260px 程度、見出し `チェック`）。建築の項目が無い文書の表は今のまま（列なし）。
- 各項目の行のセル: その項目が内訳数量に入っている判定（`QuantityCheckResult.items` にその項目の id がある判定）を 1 行ずつ: `${判定の名前（内訳数量の表示名）}: ${判定}`（`OK`／`範囲外`／`基本の値なし`）。範囲外は `quantity-check-out` のクラスで赤系。セルの `title` に、チェック項目の文・内訳数量（合計）・判定の範囲。当たる判定の無い項目は空。
- 見出しの行・施工条件の行は空。
- 判定の計算は、表のデータ（`index.total`）と基本の値が変わったときだけ（`useMemo`）。判定の計算とデータ（`quantityChecks.ts`・`checkSheets.ts`）は、建築の項目があるときだけ遅延読込（`import()`）する。基本の値は表を開いたとき（建築の項目があるとき）に `ensureSessionQuantityChecks` で読む。
- 列の表示は、ツールバーの `チェック` の切り替え（`aria-pressed`、既定オン、`karu-pdf:quantity-table-check-column` に覚える）で消せる。

## 2. 基本の値と判定の一覧の欄

- ツールバーの今の `チェックシート` のボタンは、表の**上**に開閉する欄（`<details>` または同等、`aria-label="チェックシート"`）を開く・閉じるものに変える。表は欄の下にいつも表示する。欄の中身は今の `QuantityChecks`（基本の値の入力・候補のボタン・要約・シートごとの判定の表）。欄の高さは集計表の高さの半分まで（それ以上は欄の中でスクロール）。開閉の状態は今の鍵 `karu-pdf:quantity-table-checks` に覚える（既定は閉じる）。
- 基本の値を変えると、最後の列の判定もその場で変わる。

## 3. 試験

- `e2e/quantity-checks.annotate.spec.ts` を新しい形に直す: 集計表を開くと表（`数量の集計`）が見えたまま、最後の列 `チェック` の見出しがある。普通コンクリート（軸部）の行のチェックの列に `コンクリート総量: 基本の値なし`。`チェックシート` を押して欄を開き、延べ面積 2 → 行のチェックの列が `コンクリート総量: OK`、10 → `範囲外`（赤）。Ctrl+Z・保存して開き直しは今の試験のまま。`チェック` の切り替えで列が消える。
- 建築の項目の無い文書（`e2e/quantity-table.annotate.spec.ts` の文書）ではチェックの列もボタンも無い（今の試験が通ること）。

## 禁止事項

- 判定の計算・データ・保存・Excel を変えないこと。建築の項目の無い文書の表を変えないこと。依存パッケージを足さないこと。
