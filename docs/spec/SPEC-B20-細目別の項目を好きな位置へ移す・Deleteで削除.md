# SPEC-B20: 細目別の項目を内訳書の好きな位置へ移す、一覧で Delete キーを押して削除する

## 実行モデル指定（必須）

- モデル: `gpt-6.1-sol`
- reasoning effort: `high`
- 選定理由: 並べ替えの規則の拡張（種目・科目・中科目をまたぐ移動）、移動先を選ぶ新しい画面、キー操作と確認、取り消し、e2e にまたがる

---

## 背景（利用者の要望、2026-10-12）

> 細目別の項目を好きな場所に移動できるようにして下さい。例えば、庁舎-電灯設備-電灯幹線のケーブルの細目一覧から、屋外-構内配電線路-電力引込みに移動できるようにして下さい。要は、細目別の記載欄であれば好きな場所に移動できるようにして下さい。また、（数量タブの一覧で）項目を選択した状態で、「delete」ボタンを押した場合、項目を削除できるようにして下さい。なお、削除前には削除してよいか確認してください。

今（SPEC-B03i）は、別紙明細の項目は**同じ中科目の**別紙明細の間でしか動かせない（`src/app/breakdownOutline.ts` の `moveFixtureInOutline` が `quantityBreakdownGroupKey` の一致を求める）。

## 対象

- 変更: `src/app/breakdownOutline.ts`、`src/app/FixturePanel.tsx`、`src/styles.css`
- 新規: `src/app/BreakdownMoveDialog.tsx`（移動先を選ぶ画面。遅延読込）
- 試験: `tests/breakdownOutline.test.ts`（あれば追記、無ければ新規）、e2e（`e2e/breakdown-master.annotate.spec.ts` などの並べ替えの試験に倣って新規 `e2e/breakdown-move.annotate.spec.ts`）
- 変えない: データ、保存の形式、集計表

## 1. ドラッグでの移動の規則（`moveFixtureInOutline`）

内訳書の構成で表示しているときの数量タブの一覧で:
- **別紙明細の項目**（位置の細目が別紙明細の行）は、**同じ編**のどの別紙明細の項目の前後・どの別紙明細の見出し（段 4）へも移せる（種目・科目・中科目が違ってよい）。移した項目の位置は移した先の `section`・`subject`・`middle`・`item`。
- **細目そのものの項目**（別紙明細でない行、例: 分電盤）は、同じ編で、移す先の中科目に**同じ名前の細目の行が内訳書のマスタにある**ときだけ、その中科目の細目の項目の前後・中科目の見出し（段 3）へ移せる（位置は先の `section`・`subject`・`middle`、`item` はそのまま）。マスタに無ければ動かさず、理由を出す（`移す先の中科目に「分電盤」の細目がありません`）。
- 別紙明細の項目と細目そのものの項目の間、編の違う所へは移せない（今のまま）。
- 取り消しは Ctrl+Z 1 回。並び（`order`）は移した先の場所に入る。

## 2. 移動先を選ぶ画面（`BreakdownMoveDialog.tsx`）

ドラッグでは、まだ項目の無い位置（例: 屋外 › 構内配電線路 › 電力引込み のケーブル）へ移せないので、選ぶ画面を作る。
- 数量タブの選んだ項目の操作（`編集`・`複製`・`削除` の並び）に `位置を移す…` のボタン（内訳書の位置を持つ項目を選んでいるとき）。押すと画面 `内訳書の位置を移す`（`role="dialog"`）。
- 候補（内訳書のマスタ `breakdownEntries(編)` から）:
  - 別紙明細の項目: 同じ編の、**同じ名前の別紙明細の行**（例: ケーブル）すべて。`ほかの別紙明細も表示` のチェックで、同じ編の別紙明細の行すべて。
  - 細目そのものの項目: 同じ編の、同じ名前の細目の行すべて。
  - 候補は `種目 › 科目 › 中科目 › 細目` の文で、検索の欄（`aria-label="移す先を検索"`）で絞れる。今の位置には `（今の位置）` と出して選べない。
- `同じ別紙明細の項目をすべて移す`（既定オフ）: オンなら、選んだ項目と同じ位置（同じ `section`・`subject`・`middle`・`item`）の項目をまとめて移す。
- `移す` で移し、移した先の見出しを開いて項目を選んだまま表示する（一覧をその行までスクロール）。取り消しは Ctrl+Z 1 回。
- 内訳書のマスタは画面を開いたときだけ読む（遅延読込）。

## 3. Delete キーで削除（`FixturePanel.tsx`）

- 数量タブの項目の一覧（`fixture-panel` の中の一覧）にフォーカスがあり、項目を選んでいるとき、`Delete` キーで今の `削除` ボタンと同じ処理をする（確認の文も同じ: 拾い・経路・連動項目への影響、無ければ `${名前}を削除しますか？`）。確認で取り消せば何もしない。
- 入力欄・選択肢・テキスト欄にフォーカスがあるとき、編集の画面などのダイアログが開いているとき、編集できないとき（`canEdit` が偽）は何もしない。図面の注記の Delete（図面上の選択の削除）は今のまま（フォーカスが一覧に無いとき）。
- 削除の後は、一覧の次の項目（無ければ前の項目）を選ぶ。

## 4. 試験

- 単体（`breakdownOutline`）: 電気設備 庁舎 › 電灯設備 › 電灯幹線 › ケーブル の項目を 屋外 › 構内配電線路 › 電力引込み › ケーブル の項目の後ろへ移す → 位置が移り順も入る。別紙明細の見出しへ移す。細目の項目（分電盤）を、分電盤の行がある別の中科目へ移す（可）・無い中科目へ移す（不可、null）。編の違う所へは null。
- e2e: (1) 標準マスタから 電灯幹線のケーブル（CV など 1 件）と 電力引込みのケーブル（1 件）を追加し、一覧で前者を後者の見出しへドラッグ → 位置が電力引込みに変わる。Ctrl+Z で戻る。(2) `位置を移す…` で 電灯幹線のケーブルの項目を、項目の無い別の中科目のケーブル（例: 動力設備 › 動力幹線 › ケーブル）へ移す → 位置が変わり、一覧のその見出しの下に出る。(3) 一覧で項目を選んで `Delete` → 確認（`page.on('dialog')` で受ける）で `dismiss` なら残る、`accept` なら消える。名称の検索欄で `Delete` を押しても項目は消えない。

## 禁止事項

- データ・保存の形式を変えないこと。内訳書の構成で表示していないとき（分類で表示）の並べ替えを変えないこと。依存パッケージを足さないこと。指定外のファイルを変えないこと。
