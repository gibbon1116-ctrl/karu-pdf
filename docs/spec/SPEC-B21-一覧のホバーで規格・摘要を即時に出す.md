# SPEC-B21: 数量タブの一覧で、カーソルを合わせると規格・摘要などを瞬時に出す

## 実行モデル指定（必須）

- モデル: `gpt-6-luna`
- reasoning effort: `max`
- 選定理由: 既存の見本の拡大表示（`fixture-sample-hover`）を広げるだけの局所的な画面の修正（2 ファイル、判断を伴う設計なし）

---

## 背景（利用者の要望、2026-10-12）

> 器具等にカーソルを合わせたとき、名称が同じで摘要や規格に記載された内容で区別されているものは区別がつかない。カーソルを合わせたときにそういった点も分かるようにしたい。また、これはカーソルを合わせると瞬時に表示されるようにしたい。

今は、数量タブの項目の行にカーソルを合わせると、見本の画像がある個数の項目だけ見本の拡大（`fixture-sample-hover`、`src/app/FixturePanel.tsx` の `sampleHover`）が出る。名前が同じ項目（例: 熱感知器 が 6 件）は、規格・摘要で区別しているのに一覧では見分けられない。名前の欄の `title` はブラウザの既定の遅れて出る表示で、規格しか入っていない。

## 対象

- 変更: `src/app/FixturePanel.tsx`、`src/styles.css`
- 試験: e2e を 1 件（`e2e/count-fixtures.annotate.spec.ts` に追記）
- 変えない: ほかのファイル

## 1. 項目の説明の表示（ホバーカード）

- 一覧の項目の行（`li[data-fixture-id]`）にカーソルが入ったら**すぐに**（遅れなし）、今の見本の拡大と同じ位置（行の右、画面内に収める）にカード（`role="tooltip"`、クラス `fixture-hover-card`）を出す。すべての項目で出す（見本の画像が無くても、個数以外でも）。行から出る・一覧をスクロールする・ドラッグを始める・ダイアログを開くと消す（今の見本の拡大と同じ）。
- カードの中身（値の無い行は出さない）:
  1. `${略号} ${名前}`（太字）
  2. `規格: ${spec}`
  3. `摘要: ${summaryText(項目)}`（`countFixtures.ts` の `summaryText`。区分名と値）
  4. `内訳書: ${種目} › ${科目} › ${中科目} › ${細目}`
  5. `単位: ${quantityUnit(項目)}`、`分類: ${category}`
  6. `備考: ${remark}`
  7. 連動の項目なら `連動` と、元なしなら `元なし`
  8. 見本の画像があれば下に今と同じ大きさ（160px）で
- 同じ名前の項目が一覧に 2 件以上あるときは、カードの 2・3 行目（規格・摘要）を強調（太字）する。
- 名前の欄の `title`（ブラウザの遅れて出る表示）は、カードと重ならないように外す（行のボタンの `aria-label` は今のまま）。
- キーボードで行のボタンにフォーカスしたときも同じカードを出してよい（任意）。

## 2. 試験（e2e）

- 名前が同じで摘要の違う 2 項目（例: 熱感知器 で 摘要 `種別 差動式` と `種別 定温式`）を作り、一覧の 1 件目の行に `hover` → すぐに（既定の待ち時間内で）`role="tooltip"` のカードが出て `摘要: 種別 差動式` を含む。2 件目に移すとカードが `定温式` に変わる。行から外すとカードが消える。見本の画像が無い項目でも出る。

## 禁止事項

- 一覧の並び・操作・ドラッグを変えないこと。依存パッケージを足さないこと。指定外のファイルを変えないこと。
