# SPEC-B26: 体積（囲む × 深さ）の拾いで、すべての RC 部材の種類を選べるようにする

## 実行モデル指定（必須）

- モデル: `gpt-6.1-sol`
- reasoning effort: `high`
- 選定理由: RC 部材の計算式の拡張（平面の形と深さから部材の寸法を読む）、入力の検査の条件分け、画面、単体・e2e にまたがる

---

## 背景（利用者の試用の結果、2026-10-12）

> コンクリートの項目を編集しようとしても、部材の種類で基礎スラブと床板しか選択できない。

今（`src/app/FixtureDialog.tsx` の `rcKindsFor`、`src/core/rcMember.ts` の `computeRcMember`）は、体積（`polygonDepth`: 囲む × 深さ）の拾いでは床板・基礎スラブだけ。壁は長さ×高さ、梁・基礎梁は線、柱・独立基礎は個数の拾いが前提。標準マスタの「普通コンクリート（基礎部）」「普通コンクリート（軸部）」は体積で拾う項目なので、壁・梁・柱・独立基礎のコンクリートに配筋を入れられない。

囲む × 深さの拾いは「平面の形 × 高さ」なので、次の読み方ですべての部材を計算する。

## 1. 体積の拾いでの部材の読み方（`computeRcMember`、`metrics.method === 'polygonDepth'`）

記号: A = 拾いの面積（㎡、穴を引いた後）、P = 外周の周長（m）、h = 拾いの深さ `metrics.depthM`（m）、平面の外接の長方形の長辺 Lmax・短辺 Lmin（`metrics.polygonM` から。回転していない外接の長方形でよい）、n = 拾いの数。

| 部材 | 寸法の読み方（入力があれば入力を優先） | コンクリート | 型枠 | 鉄筋 |
|---|---|---|---|---|
| 床板・基礎スラブ | 今のまま（厚さ = 入力 または h） | 今のまま | 今のまま | 今のまま |
| 壁 | 厚さ t = 入力（無ければ Lmin）、長さ L = A ÷ t、高さ H = 入力の高さ（無ければ h） | A × H | 2 × L × H | 今の壁の式に L・H を入れる（縦筋は L ÷ 間隔、横筋は H ÷ 間隔 −1） |
| 梁・基礎梁 | 幅 b = 入力（無ければ Lmin）、長さ L = A ÷ b、せい D = 入力（無ければ h）、床板控除は今のまま | L × b × (D − 控除) | 今の梁の式に L を入れる | 今の梁の式に L を入れる |
| 柱 | 断面 = 平面の形（A・P）、高さ H = 入力（無ければ h） | A × H | P × H | 主筋は今のまま（高さ H）、フープは 1 本 = P（断面の周長）、本数 = H ÷ 間隔 の切り上げ＋1 |
| 独立基礎 | 平面 = 平面の形、高さ H = 入力（無ければ h） | A × H | P × H | ベース筋は床板と同じく平面の形で平行線を切り取る（x・y 両方向。役割 `base` の筋を両方向に割り付ける） |

- 拾いの数 n を掛ける（今と同じ）。
- 入力の寸法（`widthMm`・`depthMm`・`heightMm`・`thicknessMm`）は、体積の拾いでは**省略できる**（無ければ上の読み方）。ほかの拾い方では今のまま必須。
- 根拠の文（SPEC-B22 の `rcBarCountText` など）に、読んだ寸法を出す（例: `梁 面積 6.00㎡ ÷ 幅 0.40m = 長さ 15.00m、せい 0.70m（拾いの深さ）`）。

## 2. 入力の検査（`rcMemberError`）

- `rcMemberError(member, options?: { fromShape?: boolean })`。`fromShape` が真なら、壁の厚さ・梁の幅とせい・柱と独立基礎の幅・長さ・高さの必須を外す（値があれば正の数の検査は今のまま）。既定（省略）は今のまま。
- 計算時に、読み方でも寸法が決まらない（深さが 0、面積が 0 など）ときは `RC部材の寸法を入れるか、深さ（体積）で拾ってください。` の誤り。

## 3. 画面（`FixtureDialog.tsx`）

- 体積（`polygonDepth`）の項目では、部材の種類の選択肢を 7 種すべて選べるようにする（`rcKindsFor`）。
- 寸法の入力の `placeholder` を、体積の項目では `空なら拾いの形から` とし、欄の下に読み方の文を 1 行（例: 梁 `幅が空なら平面の短い辺、長さは 面積 ÷ 幅、せいが空なら拾いの深さ`）。
- 保存時の検査は `rcMemberError(rc, { fromShape: quantityMethod(項目) === 'polygonDepth' })`。SPEC-B14 の「囲む（深さなし）の床板の厚さは必須」は今のまま。
- SPEC-B25 の名前からの既定の種類（基礎 → 基礎スラブ、柱 → 柱、梁 → 梁、壁 → 壁）は、体積の項目でもそのまま使う（選べる種類が増えるので、柱・梁・壁の名前ならその種類になる）。

## 4. 試験

- 単体: 体積の拾い 0.6m×10m（A = 6㎡、P = 21.2m）・深さ 0.7m の梁（幅・せいの入力なし）→ b = 0.6、L = 10、D = 0.7、コンクリート 4.2㎥、型枠 10 × (2×0.7 ＋ 0.6) = 20㎡。同じ形で幅 0.4 を入れると L = 15。柱 0.6m×0.6m・深さ 3.5m → コンクリート 1.26㎥、型枠 2.4 × 3.5 = 8.4㎡、フープ D10@100 → 36本 × 2.4m。独立基礎 2m×2m・深さ 0.8m → コンクリート 3.2㎥、型枠 8 × 0.8 = 6.4㎡。壁 0.2m×5m・深さ 3m → コンクリート 3㎥、型枠 2 × 5 × 3 = 30㎡。ほかの拾い方（線の梁・個数の柱など）の結果は今と同じ（既存の試験が通ること）。`rcMemberError` の `fromShape`。
- e2e: 普通コンクリート（軸部）（体積）を開き、RC 部材の種類に 梁・柱・独立基礎 などが選べる。梁を選び、幅・せいを空のまま、鉄筋 上端筋 D22 4本・下端筋 D22 4本・スタラップ D10@200 を入れて保存し、0.6m×10m を深さ 0.7m で拾う → 見本にコンクリート `4.20 ㎥`・型枠 `20.00 ㎡`。
