# SPEC-B28: 「規格から選ぶ」で項目を選んだら、内訳書の位置をその項目の代表的な細目に自動で合わせる

## 実行モデル指定（必須）

- モデル: `gpt-6.1-sol`
- reasoning effort: `high`
- 選定理由: 品目から内訳書の細目への逆引き（重ね合わせた品目を含む）、選んだ項目ごとの位置の持ち方、位置の欄との連動、e2e にまたがる

---

## 背景（利用者の要望、2026-10-12）

> 標準マスタから追加をするとき、規格から選ぶを選択し、細目に入れる項目を選択した段階で、内訳書の位置は、その細目を入れるべき代表的な項目を自動で選択するようにしたい。代表的な項目以外を選択したいときは、自分でドロップダウンから修正する。

今の「規格から選ぶ」（`src/app/FixturePresetDialog.tsx`・`src/app/CatalogChooser.tsx`）は、上の「内訳書の位置」（編・種目・科目・中科目のドロップダウン、`karu-pdf:master-breakdown-position` に覚える）が既定で「付けない」で、選んだ品目すべてに同じ位置が付く。

## 対象

- 変更: `src/core/catalog.ts`（逆引きの関数）、`src/app/FixturePresetDialog.tsx`、`src/app/CatalogChooser.tsx`
- 試験: `tests/catalog.test.ts` に追記、e2e を 1 件（`e2e/breakdown-master.annotate.spec.ts` に追記）
- 変えない: データ、「内訳書から選ぶ」の動き

## 1. 代表的な細目の逆引き（`catalog.ts`）

- `representativeBreakdownPosition(item: CatalogItem): BreakdownPosition | undefined`。
  - 内訳書のマスタの細目を**マスタの順**（編の順 電気設備 → 機械設備 → 昇降機設備 → 建築、その中は `breakdownEntries` の順）に見て、`catalogItemsForBreakdownRow(entry)` がその品目（同じ鍵、または重ね合わせた品目なら元の品目の鍵）を含む最初の細目。
  - 種目は「庁舎」（新営）を優先し、改修（`庁舎（改修）`）・屋外などは庁舎に無いときだけ。
  - 位置の `item` は細目の名前（別紙明細の品目なら別紙明細の行の名前）。
  - 逆引きの表は最初に呼ばれたときに 1 回だけ作る（品目一覧と同じく遅延）。
- 例: 照明器具の DL（ダウンライト）→ 電気設備 › 庁舎 › 電灯設備 › 電灯分岐 › ＬＥＤ照明器具（SPEC-B17 の重ね合わせ）。CV（ケーブル）→ 最初にケーブルの別紙明細を持つ中科目（電灯幹線など）。建築の形鋼 → 建築 › 庁舎 › 鉄骨 › 本体鉄骨・鋼材 › 形鋼。

## 2. 選んだ項目ごとの位置（`FixturePresetDialog.tsx`・`CatalogChooser.tsx`）

- 「規格から選ぶ」で品目の規格に**最初のチェックを付けたとき**、その品目の位置を `representativeBreakdownPosition` で決めて覚える（品目ごと。チェックを全部外すと忘れる）。代表が無い品目は今の位置の欄の値（「付けない」を含む）。
- 位置の欄（編・種目・科目・中科目）は、**最後にチェックを付けた品目**の位置を表示する。欄を利用者が変えると、その品目の位置が変わる（ほかの品目の位置は変わらない）。
- 選んだ品目の見出しの下に、その品目の位置を 1 行出す: `内訳書: 電気設備 › 庁舎 › 電灯設備 › 電灯分岐 › ＬＥＤ照明器具`（位置なしは `内訳書: 付けない`）。行を押すと、その品目が「位置の欄で直す品目」になる（欄がその品目の位置を表示する）。
- 追加するとき、各品目の項目に、その品目の位置（細目を含む）と、今と同じ摘要・規格を付ける。
- 位置の欄の値を覚える（`karu-pdf:master-breakdown-position`）のは今のまま（欄を手で変えたときだけ）。

## 3. 試験

- 単体: DL → 電灯分岐・ＬＥＤ照明器具、形鋼 → 本体鉄骨・鋼材・形鋼、改修にしかない品目 → 改修の位置。代表の無い品目 → undefined。
- e2e: 規格から選ぶ → 電気設備 → 照明器具 → DL の規格を 1 つ選ぶ → 位置の欄が 電気設備／庁舎／電灯設備／電灯分岐 になり、品目の下に `内訳書: … › ＬＥＤ照明器具`。続けて 電線 の IV を選ぶ → 位置の欄が IV の代表の位置に変わる。IV の位置を欄で別の中科目に変える → 追加すると、DL は電灯分岐、IV は変えた中科目の位置で追加される。
