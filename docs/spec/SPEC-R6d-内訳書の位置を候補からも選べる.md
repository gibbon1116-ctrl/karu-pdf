# SPEC-R6d: 項目の画面の「内訳書の位置」を、自由入力のまま候補からも選べるようにする

## 実行モデル指定（必須）

- モデル: `gpt-6-luna`
- reasoning effort: `max`
- 選定理由: `FixtureDialog.tsx` の1区画で完結し、候補の出し方は SPEC で決め切っている局所修正のため luna-max。

---

## 背景（利用者の意見、2026-10-14）

> 項目を編集の表示されている画面で（内訳書の位置の）それぞれドロップダウンと自由入力それぞれ可能にしたい。

今の「内訳書の位置」:
- 編: ドロップダウン（なし・建築・電気設備・機械設備・昇降機設備）
- 種目・科目・中科目・細目: 自由入力の欄

## 決めごと（Claude）

- **編はドロップダウンのまま**にする。保存形式と内訳書・Excel の出力が4つの編を前提にしていて（`BREAKDOWN_BOOKS`、`validFixtureBreakdown`）、自由な文字は保存できないため。
- **種目・科目・中科目・細目**は、今の自由入力の欄（`<input>`、`aria-label` は今のまま）の右に、候補のドロップダウンを置く。
  - `<select aria-label="種目の候補">` 等。先頭は値 `""` の「候補から選ぶ…」。
  - 選ぶとその値を欄に入れる。
  - 選んだ後は、ドロップダウンを「候補から選ぶ…」に戻す。
  - 欄は自由に直せる。
- 候補は内訳書標準書式のデータ（`src/core/breakdownMaster.ts` の `breakdownEntries(book)`）から、上の段の今の値で絞る。

| 欄 | 候補 |
|---|---|
| 種目 | その編の `section` の一覧（重複なし、出てくる順） |
| 科目 | その編で `section` が今の種目と同じものの `subject` の一覧。種目が空なら、その編のすべての `subject` |
| 中科目 | 同じく、編・種目・科目が今の値と同じものの `middle` の一覧（`undefined` は除く）。上の段が空ならその段では絞らない |
| 細目 | 同じく、編・種目・科目・中科目で絞った行の `row.name` の一覧（重複なし） |

  - 候補が0件のときはドロップダウンを無効にする（`title`「候補がありません」）。
  - 編が「なし」のときは、欄と同じく無効にする。
- `breakdownMaster` は大きいので、**「内訳書」の区画（`details.fixture-breakdown`）が開いたときだけ** `import('../core/breakdownMaster')` で読み込む。読み込む前・読み込み中は候補のドロップダウンを無効にする。
- 上の段を変えても、下の段の入力値は消さない（今と同じ）。
- 見た目: 欄とドロップダウンを1行に並べる（欄は伸びる、ドロップダウンは最小幅 7em 程度）。狭い画面では折り返してよい。

## 対象

- `src/app/FixtureDialog.tsx`（内訳書の位置の区画）
- 必要なら `src/styles.css`（`.fixture-breakdown` の中の並び）
- 試験

## 試験

e2e（`e2e/fixture-breakdown-position.annotate.spec.ts`。既存の項目の画面の e2e の開き方にならう）:

- 項目を追加の画面で「内訳書」を開き、編に「電気設備」を選ぶ。
- 「種目の候補」に「庁舎」がある。
- 「科目の候補」から1つ選ぶと科目の欄にその値が入る。
- 「中科目の候補」「細目の候補」が絞られる（科目を変えると細目の候補が変わる）。
- 細目の欄に自由な文字を入れて保存すると、その文字が `breakdown.item` に保存される。

## 受入条件・停止条件

- 既存の項目の画面・内訳書の e2e（`breakdown-master`・`fixture-*`）と単体試験全件が合格。
- 戻し方: この段階のコミットの revert。

## 禁止事項

- 保存形式・検査（`validFixtureBreakdown`）を変えない。
- 外部通信を足さない。`https://` を含む文字列を足さない。git 操作をしない。
