# SPEC-R6e: 数量の一覧で、内訳書の位置を同じ階層ならどこへでも移せるようにする

## 実行モデル指定（必須）

- モデル: `gpt-6.1-sol`
- reasoning effort: `high`
- 選定理由: 一覧の並び（order）と内訳書の位置の書き換え規則を変え、既存の制限の試験を意図ごと直す判断を伴うため既定の sol-high。

---

## 背景（利用者の意見、2026-10-14）

> 内訳書の位置なしの項目で、内部足場に移動させようとしても移動できない。細目別、中科目、科目、種目等、階層の同じものであればどこでも自由に移動できるようにしたい。

今の制限（`src/app/breakdownOutline.ts`、`src/app/FixturePanel.tsx` の `drop`）:

- **項目:**
  - 内訳書の位置が無い項目は、位置のある所へ移せない。
  - 違う編へは移せない。
  - 別紙明細の項目は、ほかの別紙明細へだけ移せる。
  - 細目の項目は、同じ名前の細目がある中科目へだけ移せる。
- **見出し**（科目・中科目・別紙明細）: 同じ親の中でだけ並べ替えられる。種目は動かせない。

## 決めごと（Claude）

内訳書の位置は自由入力でもよい（保存の検査 `validFixtureBreakdown` を満たせばよい）。**移す先の位置をそのまま項目の位置にする**。

### 項目を落とす先と、新しい位置

| 落とす先 | 新しい位置 |
|---|---|
| 項目の行（位置あり） | その項目の位置（編・種目・科目・中科目・細目）すべて。前・後ろはマウスの位置 |
| 別紙明細の見出し | その見出しの位置（細目 ＝ 見出しの別紙明細の名前）。その別紙明細の末尾 |
| 中科目の見出し（中科目がある群） | 編・種目・科目・中科目 ＝ 見出し。細目 ＝ 項目の今の細目、無ければ項目の名称（41字以上は先頭40字）。群の細目の末尾（別紙明細より前） |
| 科目の見出し | 中科目の無い位置（編・種目・科目 ＝ 見出し、中科目なし）。細目は上と同じ |
| 種目・編の見出し | 移さない。状態の文「科目より下の見出しか項目へ落としてください」 |
| 「（内訳書の位置なし）」の見出し、または位置の無い項目の行 | 内訳書の位置を外す（`breakdown` を消す）。位置の無い項目の末尾、または落とした行の前・後ろ |

- 違う編へも移せる（項目の位置を書き換えるだけ）。
- 細目の項目を別紙明細へ、別紙明細の項目を細目へ移すのも、上の表のとおり許す。
- 同じ位置の中での並べ替えは今のまま（`order` の空きを保つ）。
- 新しい位置が保存の検査を満たさない（文字数超え 等）ときは移さない。理由を状態の文に出す。

### 見出しを落とす先

見出しの階層:

| 階層 | 見出しのキー |
|---|---|
| 種目 | `[編, 種目]` |
| 科目 | `[編, 種目, 科目]` |
| 中科目 | `[編, 種目, 科目, 中科目]` |
| 別紙明細 | `[編, 種目, 科目, 中科目または '', 細目]` |

| 落とす先 | 動き |
|---|---|
| 同じ階層の見出し（親が違ってもよい） | 見出しの下の項目すべての位置の前の部分を、落とした先の見出しの親の位置に置き換える。見出し自身の名前と、その下の部分は保つ。並びは落とした先の見出しの前・後ろ（マウスの位置）。<br>例: 中科目「X」（`[電気設備, 庁舎, 電灯設備, X]`）を `[電気設備, 庁舎（改修）, 動力設備]` の下の中科目の見出しへ落とすと、下の項目の位置が `[電気設備, 庁舎（改修）, 動力設備, X, …]` になる |
| 1つ上の階層の見出し | その見出しの子として末尾に入る（例: 中科目を科目の見出しへ落とす） |
| 2つ以上上の見出し、下の階層の見出し、項目の行 | 移さない。状態の文「同じ階層の見出し、または1つ上の見出しへ落としてください」 |

- **種目の見出しもドラッグできる**ようにする（今は科目より下だけ）。種目は同じ階層（種目）の見出し・編の見出しへ落とせ、編が変わる。
- 落とした先に同じ名前の見出しがあれば、そこに合わさる（同じ位置の項目として並ぶ）。
- 中科目の無い群の別紙明細（中科目 `''`）は、中科目のある群の別紙明細と同じ階層として扱う。移す先の中科目に合わせる（無ければ `''`）。

### 共通

- 1回の移動は1つの `store.setCountFixtures`（Ctrl+Z 1回で戻る）。
- 状態の文は今の作り（「…を「種目 › 科目 › …」へ移しました（Ctrl+Z で戻せます）」）にそろえる。
- 「位置を移す…」（`BreakdownMoveDialog`）は今のまま。
- 内訳書の位置でまとめない表示（分類の表示）の並べ替えは変えない。
- 制限の文 `BREAKDOWN_REORDER_STATUS` と `OUTLINE_MOVE_STATUS` は、新しい規則に合う文に直すか、使わなくなるなら消す。

## 試験

- 単体（`tests/breakdownOutline.test.ts` に追加・修正）:
  - 位置の無い項目を別紙明細の見出しへ → その位置になる。
  - 位置の無い項目を中科目の見出しへ → 細目は項目の名称。
  - 位置のある項目を「（内訳書の位置なし）」へ → 位置が消える。
  - 細目の項目を、同じ名前の細目の無い中科目へ → 細目は今の細目のまま、位置が変わる。
  - 違う編の項目の行へ → その位置になる。
  - 中科目の見出しを別の科目の下の中科目の見出しへ → 下の項目すべての位置の前の部分が変わる。
  - 中科目を科目の見出しへ → 子として末尾。
  - 種目を別の編の種目へ → 編が変わる。
  - 2つ以上上の見出しへは移さない。
  - 名前が41字以上の項目を中科目へ → 細目は先頭40字。
- e2e（`e2e/breakdown-master.annotate.spec.ts` か新規 `e2e/breakdown-outline-move.annotate.spec.ts`）:
  - 位置なしの項目を「内部足場（別紙明細）」の見出しへドラッグすると、その下に入る。
  - Ctrl+Z で戻る。
