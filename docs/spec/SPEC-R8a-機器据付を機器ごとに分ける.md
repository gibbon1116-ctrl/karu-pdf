# SPEC-R8a: 構成要素の「機器据付」等を、親の機器ごとに別の項目として計上する

## 実行モデル指定（必須）

- モデル: `gpt-6.1-sol`
- reasoning effort: `high`
- 選定理由: 構成要素の追加の3つの経路（構成要素の追加・構成要素で拾う・関連の自動反映）にまたがり、項目の作り分けと既存データの分け直しを伴うため既定の sol-high。

---

## 背景（利用者の意見、2026-10-14）

> 空調設備のボイラーと冷却塔で機器据え付けをそれぞれ構成要素の追加で入れた際に、機器据え付けが２と計上されるが、ボイラーと冷却塔の機器据え付けは別途計上する必要がある。接続される配管は JIS 規格等になるためまとめて計上しても構わないが、重量や容積によって機器据え付けは別項目になるため、別々に計上できるようにしたい。機器据付(冷却塔)のような形で、据付の内容を区別できるようにしたい。他の空調設備だけでなく、他の機器にも同様に。

Claude がデータを作成済み: `src/core/breakdown/perEquipmentComponents.ts`
- `PER_EQUIPMENT_COMPONENT_NAMES`: 機器据付・機器用基礎・機器取外し再取付け・機器撤去
- `PER_EQUIPMENT_SUMMARY_LABEL = '名称'`

## 決めごと

構成要素にする項目（個数の項目）の名称が `PER_EQUIPMENT_COMPONENT_NAMES` のどれか（**基の名称**。名称の正規化は `normalizeItemName` と同じでよい）のとき、親の個数の印の項目（親の機器）ごとに、次の**機器別の項目**を使う。

- 名称: `基の名称（親の項目の名称）` 例 `機器据付（冷却塔）`
- 摘要（`summary`）: 基の項目の摘要に、区分 `名称` の値として親の項目の名称を入れる（区分があれば値を置き換え、無ければ先頭に足す）。
- そのほか（分類・単位・内訳書の位置・施工条件の候補・種類・連動 等）は基の項目と同じ。`id` は新しく、`order` は末尾、`style` は `nextCountStyle`。
- 同じ機器別の項目（名称と摘要が同じ。`fixtureIdentity` で比べる）がすでにあれば、それを使う（新しく作らない）。

対象の経路（**全部**で同じ規則にする）:

1. 右の数量拾いの「＋ 構成要素を追加」（`ComponentPicker`）で選んだとき。文書の項目・標準マスタの候補のどちらでも。
2. 関連の候補の「構成要素で拾う」（`store.addComponentToFixture`）。
3. 関連の「追加する」の自動反映（R7b `store.applyRelatedAdditions` の個数 → 個数）。
4. 「同じ項目の印すべてにこの構成を反映」（`CountItems`）。反映先の印の親が同じ項目なので、そのままでよい（変更不要のはず。違えば合わせる）。

- 機器別の項目を作るときは、構成要素の追加と同じ履歴に入れる（Undo 1回で戻る）。今の `setCountComponents(ids, extra, newFixtures)` 等の `newFixtures` を使う。
- 基の名称そのものの項目（例「機器据付」）は、構成要素として選ばれたときに機器別の項目に置き換わる。基の項目は文書から消さない。

## 既にまとめて入っているものの分け直し

右の「構成要素」の一覧（`CountItems`）で、構成要素が基の名称そのもの（例「機器据付」）のとき、その行に「機器ごとに分ける」ボタン（`aria-label="{基の名称}を{親の名称}の項目に分ける"`）を出す。

- 押すと、**親と同じ項目のすべての印**の構成要素で、基の項目を機器別の項目に置き換える。
- 数・施工条件は保つ。
- これからの印の記憶（`lastCountComponents`）も置き換える。
- 1つの履歴。

## 試験

- 単体 `tests/perEquipment.test.ts`:
  - ボイラー・冷却塔の印にそれぞれ「機器据付」を構成要素で足す。
  - 「機器据付（ボイラー）」「機器据付（冷却塔）」の2項目ができ、摘要の名称がそれぞれ入る。
  - 数量（`QuantityIndex`）がそれぞれ 1。
  - 同じ親に2回足しても項目は1つ。
  - 対象外の名称（例「スリーブ」「冷媒管」）はそのまま共通の項目。
- 単体（ストア）: 分け直しで、親の印すべての構成要素が置き換わり、Undo 1回で戻る。
- e2e（`e2e/per-equipment-components.annotate.spec.ts`。`count-components.annotate.spec.ts` の作りにならう）:
  - ボイラー・冷却塔の個数の項目と「機器据付」の項目がある PDF。
  - それぞれの印に構成要素で「機器据付」を足すと、一覧に「機器据付（ボイラー）」と「機器据付（冷却塔）」が1ずつ出る。
  - 既に「機器据付」が入った印の「機器ごとに分ける」で分かれる。
  - Ctrl+Z で戻る。
