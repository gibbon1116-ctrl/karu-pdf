## 変更内容（`src/core/symbolFeatureProfile.ts`）

### 1. 線のつなぎ方（`probeSymbolVectorFeatures` の所有の判定）

- **見本の線幅の範囲の線**は、つながない。1本ずつ判定する。
  - 線幅の範囲 = `strokeWidth` の 0.5〜2 倍。今の `local` と同じ式。
  - `strokeWidth` が 0 か、線の幅が 0 のときは、範囲の中とみなす。
  - 判定は今と同じ。芯 C に入り、端点が B を `out` 広げた枠の外にある線が、外の線になる。
- **範囲の外の線**（細い・太い背景の線）だけを、run にまとめる。条件は次のすべて。
  - 両方が範囲の外。
  - 線幅の差が、大きい方の 10% 以内。
  - 向きの差が 3° 以内で、同じ直線上にある（今の条件）。
  - 端点どうしの最も近い距離が `gap = max(2, 0.15·long)` 以内（破線のすき間を越える）。
- run の判定（芯に入る、外まで続く）は今と同じ。
- `ownership` に `strokeWidth`（probe に渡した値）を足す。

### 2. 内部のマスク（`describeSymbolInterior`、所有を渡したとき）

**守る線と消す線**
- 守る線（その線の `r` 以内の格子を消さない）は、`owned` のうち**線幅の範囲の中の線だけ**にする。
- 外の線を消す処理は、今と同じ。

**構造の領域（`regions`）**
- 外の線を消した後のマスクから、範囲の外の `owned` の線の `r` 以内にある格子を、さらに白にした「構造のマスク」を作る。
  - ただし、範囲の中の `owned` の `r` 以内にある格子は、白にしない。
- 構造のマスクで、今の穴と同じ規則（境界に触れない、8 格子以上）で白い領域を求める。
- 結果に次を足す（所有を渡したときだけ）。
  - `regions: Uint8Array`: 格子ごとの領域の番号。0 は領域でない。
  - `regionAreas: number[]`: 番号 `k` の面積は `regionAreas[k-1]`（全格子に対する割合）。
- 領域が `MAX_INTERIOR_REGIONS`（32）を超えたら、`regions` を付けない。
- `holes`・`ink`・`mask` は今と同じ。
  - `mask` は外の線を消した後のもの。範囲の外の線のインクは残す。

### 3. 白い領域の比較（新しい関数 `compareSymbolFills(a, b)`）

**不明にする条件**
- どちらかが `known: false` か、`regions` が無い。

**領域の芯**
- 領域の格子のうち、上下左右の4つの隣も同じ番号の格子だけを使う。マスクの縁の格子は除く。
- 対象にするのは、面積 0.02 以上で、芯の格子が 6 以上の領域。

**またがりの確認（構造の違い）**
- a の対象の領域ごとに、その芯の格子が b のどの領域に入るかを数える。
- b の対象の領域で、数えた数が「その b の領域の芯の格子数」の 25% 以上のものが2つ以上あれば `unknown`。
  - 仕切りの有無が違う、ということ。
- b から a も同じに調べる。

**塗りの確認**
- a の対象の領域ごとに、その芯の格子のうち、b の `mask` がインクの割合を求める。
- b から a も同じに求める。
- 最大の割合が 0.35 を超えれば `different`。
- どちらにも対象の領域が無ければ:
  - `|a.ink − b.ink| ≤ 0.1` なら `same`。
  - それ以外は `unknown`。
- 最大の割合が両方とも 0.15 以下なら `same`。
- それ以外は `unknown`。

**判定の順**
- またがりの確認を、塗りの確認より先に行う。

### 4. 比較の入口

- `compareSymbolFeatureProfiles` の `interiorAppearance` は、`compareSymbolFills` を使う。
- `compareSymbolInteriors` は消さず、今のまま残す（既存の試験のため）。

## 試験（`tests/symbolFeatureProfile.test.ts`）

既存の試験の作り方に倣う。S01 で足した試験のうち、この SPEC と合わなくなる期待値は直し、何をなぜ直したか報告すること。

1. **記号の中の線を守る**
   - 半円の感知器（今の `cup`）の中に横線があり、同じ線幅の配線が外から縁まで来て、横線と一直線に並ぶ。
   - 横線は `owned` に入り、`foreign` に入らない。
   - 横線ありと横線なしの感知器（どちらも配線あり）は、`compareSymbolFills` で `same` にならない。
2. **見本と同じ線幅の配線が、縁で2本に切れている**
   - S01 の試験2。中の1本は `owned` に残る（記号の線と区別できないため）。
   - `same` にならないことを確かめ、試験名にその理由を書く。
3. **細い破線**
   - 線幅 0.1 の破線が長形器具を斜めに横切る。器具の中に収まる短い線を含み、すき間は 1.4。
   - 破線のすべての線が `foreign` に入る。破線の無い器具と `compareSymbolFills` で `same`。
4. **細い文字の線**
   - 翼の中だけにある、線幅 0.1 の短い線の組（外へ出ない）。
   - 構造の領域を分けない。文字の無い器具と `same`。
5. **円の有無**
   - 円の無い四角と、円のある四角（どちらも配線あり）→ `compareSymbolFills` は `same` にならない（`unknown` か `different`）。
6. **塗り**
   - 白い円と黒く塗った円の長形器具 → `different`。
7. **斜線**
   - 翼に見本と同じ線幅の斜線がある器具と、無い器具 → `same` にならない。
8. **寸法の差**
   - 見本より 1% 大きい器具（端の縦線がマスクの外へ出る）→ `same`。
9. **領域の上限**
   - 構造の領域が 32 を超えると `regions` が付かず、`compareSymbolFills` は `unknown`。
10. **入口**
    - `compareSymbolFeatureProfiles(…, ['interiorAppearance'])` が `compareSymbolFills` の結果を返す。
11. **不変性**
    - S01 と同じ。
