## 変更内容（`src/core/symbolFeatureProfile.ts` の `compareSymbolFills` だけ）

### 1. 対象にする領域

- 構造の領域のうち、面積が **0.04 以上**（今は 0.02）で、芯の格子が 6 以上のもの。
- この下限は、またがりの確認と塗りの確認の両方に使う（今と同じく、1つの `core` で）。

### 2. 塗りの確認で、小さなずれを許す

- b のマスクを、a に対して `dx, dy ∈ {−2, −1, 0, 1, 2}`（格子の数）ずらした 25 通りで測る。
  - a の対象の領域の芯の格子 `(x, y)` で、b のマスクの `(x+dx, y+dy)` がインクかを数える。
  - b の領域を a で測るときは、逆向きにずらす（a のマスクの `(x−dx, y−dy)`）。
  - マスクの外になる格子は、インクでないとして数える（分母には入れる）。
- ずらし方ごとに、`af`（a の領域で測った b のインクの最大の割合）と `bf`（逆向き）を求める。
- `max(af, bf)` が最も小さいずらし方の `af`・`bf` を使う。
- そのあとの判定は今と同じ。
  - `max > 0.35` なら `different`。
  - 両方 `≤ 0.15` なら `same`。
  - それ以外は `unknown`。

### 3. 変えないこと

- またがりの確認は、ずらさずに今のまま行う（判定の順も今と同じ。またがりが先）。
- どちらにも対象の領域が無いときの規則（インクの差 0.1）は今のまま。
- `compareSymbolInteriors`、所有の判定、`describeSymbolInterior` は変えない。

## 試験（`tests/symbolFeatureProfile.test.ts` に足す。既存の試験はすべて通ること）

1. **ずれ**
   - 二重丸（内側の円の中に斜線3本）の同じ記号を、姿勢の中心を 0.25pt ずらして調べる → `same`。
   - ずらさない元の比較なら `unknown` になる配置を選ぶこと。
2. **塗りは違うまま**
   - 白い円と黒く塗った円の長形器具。どちらの向きにずらしても `different`。
3. **円の有無は同じにしない**
   - 円の無い四角と円のある四角 → `same` にならない（今の試験が通ること）。
4. **細い領域**
   - 面積 0.02〜0.04 の細い白いすき間だけが違う2つの記号 → またがりの確認で `unknown` にならない。
