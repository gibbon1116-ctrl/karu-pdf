# SPEC-S04: 線で引いた見本の部分は、塗りの輪郭（太字の文字など）と照合しない。形の比較の既定をオフに戻す

## 実行モデル指定（必須）

- モデル: `gpt-6.1-sol`
- reasoning effort: `high`
- 選定理由: 今の線の検索（方式 A）の中心の照合を変えるため。既存の結果を壊さないことが最重要

---

## 利用者の要望

ある実案件の図面のように、図面の文字が太字の場合の問題。

- P14（床用 LAN の差込口）や P10（小さな太い丸）で探すと、文字や壁の部分まで候補になる。
- 反応しないようにしたい。
- ただし、これまで正しく見つかっていた記号が見つからなくなるのは避けたい。

## 現状（Claude Code が確かめたこと）

**この図面の描き方**
- 文字は、塗りの輪郭（線幅 0 の線分。`VectorPage` では塗りの輪郭は幅 0）で描かれている。
- 記号は、主に線幅 0.54 の線で描かれている。
  - 床用 LAN の差込口は、0.54 の線が 43 本、塗りの輪郭が 3 本（三角など）。
  - 小さな丸は 0.54 と 0.84 の線。

**今の照合**
- `vectorSymbolSearch.ts` の `acceptsWidth` は、幅 0 の線を、どの線幅の見本とも照合する。
- そのため、文字の輪郭（「O」「D」「0」「8」の丸い部分）が、見本の円の線の代わりになって一致する。

**結果**
- P14 の床用 LAN（見本は図面の1個）：66件。本物は約 25件で、残りは文字・流し台・壁。
- P10 の小さな丸：288件。約半分が数字や「D1」などの文字。
- 文字の候補の多くは幅 0 の輪郭だけでできている。一部は線幅 0.30 の細い文字。

## 変更内容

### 1. `src/core/vectorSymbolSearch.ts` の `vectorSymbolSearch`

**種類を分けて照合する**
- 見本の各線分の種類を保つ。
  - 線：幅 > 0
  - 塗りの輪郭：幅 0
  - `paintTemplateGeometry` が返す `widths` は、`segments` と同じ並び。これを使う。
- 次の**すべて**が成り立つとき、見本の「線」から作った照合点は、ページの「線」（幅 > 0 で、今の線幅の範囲に入るもの）とだけ照合する。
  - `segmentWidths` が渡されている。
  - 見本の `strokeWidth > 0`。
  - 見本に幅 > 0 の線分がある。
- 見本の「塗りの輪郭」から作った照合点は、今どおり、ページのすべての線（幅 0 を含む）と照合する。
- 上の条件が成り立たないときは、今とまったく同じに照合する。

**実装の要点**
- 今の `widthFiltered` は線分だけを返し、線幅がそろわない。線幅も一緒に返すように変える（または幅 > 0 の線分だけの配列を別に作る）。
- 照合点（`samples`）に種類を持たせ、`hits` が種類に応じた格子（全体、または線だけ）を引く。
  - 線だけの格子は、条件が成り立つときだけ作る（メモリと時間の増加を抑える）。
- 確度の計算に使う逆向きの確認（`extra`）、周りの線（`around`）は今のまま、全体の線で測る。
- 候補の上限・並び・重複除去は変えない。
- `shouldStop` で止める動作も変えない。

### 2. 形の細部の比較の既定をオフにする（`src/app/SymbolSearchPanel.tsx`）

- 「形の細部（円弧・枠・斜線・塗り）も見本と比べる」の既定をオフにする。
  - `localStorage` の値が `'true'` のときだけオン。
  - 理由：見本が壁の線の上にあると、壁を「外の枠」と読み、本物の記号まで「形が違う」として隠すことを確かめたため。直すまでの措置。
- ヘルプ（`HelpDialog.tsx`）の該当の文の「オンなら」は、そのままでよい。初期状態の説明があれば「初めはオフ」と直す。
- 既存の e2e で、オンを前提にしているもの（`e2e/symbol-shape.annotate.spec.ts`、`e2e/symbol-search.annotate.spec.ts` の比較オンの部分）は、チェックを入れる操作を足す。
  - 「既定でオン」を確かめる行は、「既定でオフ」に直す。

## 試験

### 単体（`tests/vectorSymbolSearch.test.ts` に足す）

MuPDF で作る合成のページ。
1. **太字の文字に反応しない**
   - 線（幅 0.54）で描いた丸い記号を2つ置く。
   - 同じ大きさの「O」を、塗りの輪郭（外と内の2つの閉じた曲線を `f*` で塗る）で2つ置く。
   - 線の記号を見本に探す → 記号の2件だけ見つかる。
   - 幅を渡さない（`segmentWidths` なし）と、今どおり4件見つかる。
2. **塗りの見本は今どおり**
   - 黒く塗った丸の記号を見本にすると、塗りの丸に今どおり一致する。
3. **線と塗りの両方を持つ見本**
   - 丸（線）＋黒い三角（塗り）の記号を見本にすると、同じ記号に一致する。
   - 三角だけが同じで、丸が塗りの輪郭の図形には一致しない。
4. **既存の試験**
   - 今の `tests/vectorSymbolSearch.test.ts`・`vectorSymbolWidth`・`vectorSymbolWiring`・`vectorAppearance`・`vectorSearchSnap`・`symbolRecognition*` の試験がすべて通ること。
