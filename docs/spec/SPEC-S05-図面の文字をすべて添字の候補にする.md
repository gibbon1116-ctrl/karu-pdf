# SPEC-S05: 図面の文字（数字だけの語・日本語を含む）を、すべて添字の候補にする

## 実行モデル指定（必須）

- モデル: `gpt-6.1-sol`
- reasoning effort: `high`
- 選定理由: 1.5.1 で決めた添字の規則を変えるため。既存の分け方への影響の確認が要る

---

## 利用者の要望

ある実案件の電気図で、四角に×の記号（ボックス）を見本に探すと、上の「332」が添字にならない。

> この文字に限らず、日本語含めて図中の文字は添字として判定できるようにしたい。判定の対象にするかどうかは「添字で種類を分ける」のチェックボックスで判定するようにしたい。

## 現状（Claude Code が確かめたこと）

**今の規則**
- `normalizeSymbolLabel` は、次をすべて満たす語だけを添字にする。
  - NFKC にして大文字にした結果が、英数字 1〜6 文字。
  - 数字だけではない。
  - 数字が 2 つまで。
- 「332」（数字だけ）、日本語、7 文字以上、数字 3 つ以上（回路番号 `G301`）は捨てる。
- 数字 3 つ以上の除外は SPEC-08b で、P71 の回路番号が添字に混ざったために入れた。

**作業フォルダの写しで試した結果**（`work/.../label-variants.mjs`）

規則を「12 文字以内のどの文字でも」にした場合。

| 図面 | 結果 |
| --- | --- |
| P11 のボックス 6 件 | 332：3件、443：2件、554：1件（今はすべて添字なし） |
| P71 のコンセント | 4H 122、ET+G 33、ET 17、S 9、4H+G 7、ETLK 4、20A 3、2ET+G 3、30A 2 などは変わらない |

- P71 で変わるのは、「添字なし」104 件のうち 12 件と、「なし＋G」7 件のうち 3 件。
  - 近くの回路番号（301・G305 など）や「集中」「2.6」が添字になり、1〜2 件ずつの小さな種類に分かれる。
  - どれを対象にするかは、利用者がチェックで選ぶ（利用者の指定どおり）。

## 変更内容

### 1. `src/core/symbolLabels.ts` の `normalizeSymbolLabel`

- 語を NFKC にし、英字は大文字にする（今と同じ）。
- 次をすべて満たせば添字にする。
  - 長さ 1〜12 文字（NFKC 後の文字数）。
  - 少なくとも 1 文字が、文字か数字（`\p{L}` か `\p{N}`）。記号だけの語（「-」「・」など）は捨てる。
  - 空白を含まない（今の切り方で空白は入らない）。
- 数字だけの語、数字 3 つ以上の語、日本語の語も添字にする。
- `UNKNOWN_SYMBOL_LABEL`（`?`）は、今どおり返さない。
  - `?` は文字・数字を含まないので、上の規則で自然に捨てられる。

### 2. G の分離（`assignSymbolLabels`）

- 今の条件（語が `G`、または 3 文字以上で `G` で終わる）は変えない。
- ただし、条件に当てはまっても、残りが英数字だけでない語（日本語を含む語など）は分けない。

### 3. 変えないこと

- 語の持ち主の決め方（最も近い本体、半径 R 以内）。
- 1 つの本体に語が複数あるときの規則（最も近い語から +0.5pt 以内）。
- 重ね書きのまとめ方。
- 局所画像の字形の読み取り（`symbolGlyphs`）。英数字だけのまま。
- パネル（「添字で種類を分ける」のチェックの一覧、初めは見本の添字だけを選ぶこと）。

### 4. ヘルプ（`src/app/HelpDialog.tsx`）

添字の説明の段落に、次を足す。

> 図面に文字として書かれている語は、数字だけの語（回路番号など）や日本語も添字の候補になります。分けたくない語のチェックを外してください。
