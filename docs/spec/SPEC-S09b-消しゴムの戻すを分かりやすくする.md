# SPEC-S09b: 見本の線を整える画面の「戻す」を分かりやすくする

## 実行モデル指定（必須）

- モデル: `gpt-6-luna`
- reasoning effort: `max`
- 選定理由: 1 ファイル内の文言と小さなキー操作の追加。判断を伴う変更は無い

---

## 利用者の要望

> 同じ記号を探すの見本の線を整える機能で、消しゴムで線を消した後に戻すボタンを押しても反応しない。誤って消した線を戻せるようにしたい。

## 現状（Claude Code が確かめたこと。`src/app/SymbolSampleEraser.tsx`）

- 「消しゴム」「戻す」は、なぞる操作の種類を切り替えるボタン（`mode`）。「戻す」を押しただけでは線は戻らない。その後に消した線（薄い赤の破線）をなぞるか押すと戻る。処理は正しく動く（画面の試験あり）。
- 直前の操作を取り消すのは「元に戻す」（`undo`）。キーでは使えない。
- 案内文は「不要な線を消しゴムで消してください。「戻す」で消した線を使う線に戻せます。」の 1 つだけ。

## 変更内容（`src/app/SymbolSampleEraser.tsx` だけ）

1. ボタンの表示の文字を次にする（`aria-pressed` などは今のまま）。
   - 「消しゴム」→「消す（なぞる）」
   - 「戻す」→「戻す（なぞる）」
   - 「元に戻す」→「1つ前に戻す（Ctrl+Z）」
   - ボタンの名前（`aria-label`）は、試験と合わせるため今の名前を残す：`aria-label="消しゴム"`、`aria-label="戻す"`、`aria-label="元に戻す"`。
2. 案内文（今の 1 つの `<p>`）を、今の状態に合わせて替える。`role="status"` を付ける。
   - 消すとき：「消す線をなぞるか押してください。消した線は赤い破線になります。」
   - 戻すとき：「戻す線（赤い破線）をなぞるか押してください。」
   - その下に常に：「直前の操作は「1つ前に戻す」か Ctrl+Z で取り消せます。」
3. 画面（`<dialog>`）で Ctrl+Z（Mac は ⌘+Z）を押したら `undo()` を行う。入力中の欄が無いので、そのまま扱ってよい。既存の `onKeyDown={event => event.stopPropagation()}` の中で処理し、`preventDefault()` する。
4. 消す・戻すを切り替えたとき、図面上のポインタの円の色が変わるのは今のまま。

## 変えないこと

- 線の選び方・決定・保存・検索。ほかのファイル。

## 試験（`e2e/symbol-sample-eraser.annotate.spec.ts` に足す）

- 戻すに切り替えると、案内文が「戻す線（赤い破線）を…」に替わる。
- 線を消した後に Ctrl+Z で、消した線が戻る（`data-state="use"`）。
