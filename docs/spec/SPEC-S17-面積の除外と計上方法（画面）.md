# SPEC-S17: 面積の除外範囲・開口部・建具の寸法・計上方法の切替（画面）

## 実行モデル指定（必須）

- モデル: `gpt-6.1-sol`
- reasoning effort: `high`
- 選定理由: 図面に描く操作（MeasurementOverlay）に新しい段階を足し、書式欄・拾いバー・項目の編集をまたいで変える。Undo・選択・ページ切替との関係を壊さない判断が要る

---

## 背景

SPEC-S16（コミット `da94792`）で、データと計算はできている。

- `QuantityMark.holes?: Point[][]`（`polygon`・`polygonDepth`）、`QuantityMark.openings?: QuantityOpening[]`（`polygon`・`lengthHeight`）、`QuantityOpening = { itemId?; widthM?; heightM?; count }`。
- `CountFixture.opening?: { widthM; heightM }`（個数の項目）。`fixtureOpeningSize(fixtures)`、`store.openingSize(itemId)`。
- `MeasureSettings.holes?: Point[][]`（計測の面積）。
- 値・札・PDF の描画・アプリの図面の斜線は、データがあれば出る。

この SPEC は、それを入力・変更する画面を作る。利用者の要望（計画書「面積の除外と計上方法」）：

- 床・天井など「囲む」で拾う面積から、柱・吹抜・シャフトなどを図面で囲んで除外する。
- 壁など「長さ×高さ」の面積から、開口部を「幅×高さ×箇所数」で除外する。分類で設定した建具（個数の項目）を指定しても除外できる。
- 「計測▼ → 面積」でも、除外範囲を囲める。
- 面積を「長さ×高さ」と「図面の範囲を囲む」のどちらで計上するかを選べる。

## 変更内容

### 1. 計上方法を拾うときに選ぶ

- `AnnotationStore` に、項目ごとの「次に拾うときの方法」を持たせる（保存しない。文書を開いている間だけ）。
  - `pickupMethod(fixture): QuantityMethod`：選んであればそれ、無ければ項目の拾い方（`quantityMethod(fixture)`）。
  - `setPickupMethod(itemId, method)`：`method` が `QUANTITY_METHODS[種別]` に含まれるときだけ。変えたら `notify(false)`。
- `MeasurementOverlay.tsx` の `quantityMark()` は、`quantityMethod(quantityItem)` の代わりに `store.pickupMethod(quantityItem)` を使う。
  - 初期値の寸法（`quantityItem.defaults`）は、その方法に要る寸法だけを入れる（`quantityDimensions(method)`）。要る寸法が無ければ、今と同じく拾った後に寸法を聞く。
  - 描く形（多角形か折れ線か）も、その方法に合わせる（`quantityPoints(method)`）。今は項目の拾い方から決めているところがあれば、同じく直す。
- 拾いバー（`PickupBar.tsx`）：今の項目が面積か体積なら、切替のボタンを出す。
  - 面積：「長さ×高さ」「囲む」。体積：「囲む×深さ」「長さ×幅×深さ」。`aria-pressed` で今の方法を示す。
  - 押したら `setPickupMethod`。描いている途中なら、その描画は今と同じく取りやめる（`MeasurementOverlay` の既存の取りやめの条件に、方法の変化を足す）。
- 項目の編集（`FixtureDialog.tsx`）の「拾い方」：
  - 見出しを「拾い方（拾うときの初期値。拾いバーで切り替えられます）」にする。
  - 拾いがあっても変えられるようにする（`disabled={hasMarks}` を外す）。変えても、すでに拾ったものは変わらない。
- 書式欄の「項目を変更」と、項目の付け替え（`reassignCounts`）：
  - 今は「拾い方が同じ項目」だけが候補。面積・体積の拾いは「種別が同じで、その拾いの方法を持てる項目」を候補にする（`QUANTITY_METHODS[種別]` にその方法がある）。個数・長さは今と同じ。

### 2. 除外範囲を囲む

- 対象：選んでいる拾いが 1 つで、`polygon`・`polygonDepth` の拾い、または計測の面積（`measure.kind === 'area'`、数量拾いでない）。
- 書式欄に「除外範囲」の欄を出す（数量拾いの書式と、計測の面積の書式の両方）。
  - 一覧：除外 1、除外 2 … とその面積（m²、小数 2 桁）、行ごとに「削除」。
  - ボタン「除外範囲を囲む」。
- 「除外範囲を囲む」を押すと、図面で多角形を描く状態にする（今の面積の描き方と同じ。クリックで点、ダブルクリックか Enter で決定、Backspace で 1 点戻す、Esc でやめる）。
  - 画面の上に案内を出す：「除外する範囲を囲んでください（Enter・ダブルクリックで決定、Esc で中止）」。
  - 描いている形は、除外の見た目（斜線か破線）で示す。
  - 決定したとき：点が 3 つ以上で、すべての点が外形の内側（辺の上も可）なら、その拾い・計測に除外範囲を足す。外にはみ出す点があれば、足さずに「除外範囲は外形の内側を囲んでください」と出し、描く状態を続ける。
  - 足したら、続けて次の除外範囲を描ける状態のままにする（Esc か書式欄の「囲み終える」で終える）。
  - 別の注釈を選ぶ・ページを替える・ツールを替える・選んでいる注釈が消えたら、描く状態を終える。
- ストアに、除外範囲を変える関数を足す（例：`setAreaHoles(id, holes)`）。
  - 1 回の変更を 1 回の Undo で戻せる（今の `mutate` と同じ仕組み）。
  - 札（`text`）と範囲（`rect`）を直す（今の `updateQuantityValues` と同じ）。
  - 50 個まで。点は 500 まで。
- 外形の頂点を動かしても、除外範囲は動かさない（今のまま）。

### 3. 開口部を入力する

- 対象：選んでいる拾いが 1 つで、`lengthHeight`・`polygon` の数量拾い。
- 書式欄に「開口部（差し引く）」の欄を出す。
  - 行ごと：
    - 種類の選択：建具（開口寸法のある個数の項目）か「寸法を入力」。建具は分類ごとにまとめ、「AW-1 アルミ窓（1.80×1.20）」のように出す。分類「建具」があれば先頭。
    - 「寸法を入力」のときだけ：幅（m）・高さ（m）。
    - 箇所数（1〜999）。
    - その行の面積（m²）。寸法が分からない行は「?」。
    - 「削除」。
  - ボタン「開口部を追加」（初めは「寸法を入力」、幅・高さは空、箇所 1。空のまま決定しない）。
  - 合計（m²）。
  - 建具を選んだ行は、`itemId` と、その時点の寸法の控え（`widthM`・`heightM`）を保存する（S16 の決まり）。
  - 開口寸法のある建具が 1 つも無いときは、「開口寸法のある建具がありません。項目の編集で個数の項目に開口寸法を入れると選べます」と出す。
- ストアに、開口部を変える関数を足す（例：`setQuantityOpenings(id, openings)`）。1 回の変更を 1 回の Undo で戻せる。札と範囲を直す。50 件まで。
- 入力の確定の仕方は、今の寸法の入力（`QuantityValueInput`）に合わせる（入力欄を離れたとき・Enter で確定）。

### 4. 建具の開口寸法を入れる（`FixtureDialog.tsx`）

- 個数の項目のとき、「開口寸法（壁・塗装などの面積から差し引くとき）」の欄：幅（m）・高さ（m）。どちらも空なら寸法なし。
  - 片方だけ・0 以下・100 を超える値は、保存できない（理由を出す）。
- 保存すると、その建具を使う拾いの値と札が変わる（S16 で対応済み）。

### 5. 計測の面積

- 計測の面積の書式（数量拾いでない面積）にも、2 の「除外範囲」の欄を出す。値は S16 の `measureText`。

### 6. ヘルプ（`src/app/HelpDialog.tsx`）

面積の拾いの説明の近くに足す：

> 面積は、拾いバーで「長さ×高さ」と「囲む」を切り替えて拾えます（体積は「囲む×深さ」と「長さ×幅×深さ」）。項目の拾い方は、拾うときの初期値です。囲んで拾った面積と計測の面積は、書式欄の「除外範囲を囲む」で内側の柱・吹抜などを囲むと差し引きます（斜線で表示）。長さ×高さ・囲む面積は、書式欄の「開口部（差し引く）」で、建具か幅×高さと箇所数を入れると差し引きます。建具の開口寸法は、項目の編集で個数の項目に入れます。建具の寸法を変えると、その建具を差し引いた面積も変わります。

## 変えないこと

- 除外範囲・開口部を使わないときの拾い・計測の操作と結果。
- 長さ・個数の拾い。保存の形（S16 のまま）。

## 試験

**単体**：
- `pickupMethod`・`setPickupMethod`（種別に合わない方法は無視）。
- `setAreaHoles`・`setQuantityOpenings`：値・札が変わる、1 回の Undo で戻る、上限。
- 項目の付け替えの候補：面積の拾いを、拾い方の違う面積の項目へ付け替えられる。

**画面**（新規 `e2e/area-exclusions.annotate.spec.ts`。既存の面積の画面の試験 `e2e/quantity-area-volume.annotate.spec.ts` を参考に）：
1. 面積の項目（拾い方「長さ×高さ」）で、拾いバーの「囲む」に切り替えて四角を囲む → 拾いの方法が `polygon`、値が四角の面積。
2. その拾いを選び、「除外範囲を囲む」で内側の小さな四角を囲む → 値が差し引かれ、札が「…−…=…」。Ctrl+Z で戻る。
3. 外にはみ出す除外範囲は足されず、案内が出る。
4. 建具の項目に開口寸法を入れ、「長さ×高さ」の拾いの開口部に建具×2 と寸法入力×1 を足す → 値が差し引かれる。建具の寸法を変えると値が変わる。
5. 計測の面積でも除外範囲を囲める。

**変わらないことの確認**（Claude Code が実行する）：数量拾い・計測の既存の画面の試験。
