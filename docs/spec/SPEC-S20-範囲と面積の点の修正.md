# SPEC-S20: 部屋の範囲の形を直す・面積の点を足す／消す

## 実行モデル指定（必須）

- モデル: `gpt-6.1-sol`
- reasoning effort: `high`
- 選定理由: 図面の上の操作（`MeasurementOverlay` のドラッグ・ダブルクリック）に、新しい編集の状態を足す。選択・Undo・部屋の囲み（S18）・除外範囲（S17）との取り合いを壊さない判断が要る

---

## 利用者の要望

> 一度設定した部屋の名称は修正できるが、範囲の修正ができない。範囲の修正ができるようにしたい。ポイントの数を追加したい場合には、ポイントを追加できるようにしたい。これは面積の図り方の方でも修正可能にしたい。

## 現状（Claude Code が確かめたこと）

- 面積（計測の面積、数量拾いの「囲む」「囲む×深さ」）の頂点は、選択の道具で 1 つだけ選ぶと四角のつまみ（`AnnotationLayer.tsx` 931 行付近、`data-measure-vertex`）が出て、ドラッグで動かせる。
  - 処理は `MeasurementOverlay.tsx` の `vertex.current`（`pointerDown` 516 行付近・`pointerMove`・`pointerUp`）。離すと `store.updateMeasureVertices(id, points)`（`AnnotationStore.ts` 1342 行付近、1 回の Undo）。
  - `updateMeasureVertices` は点の数が変わっても動く（札と範囲を作り直す）。
  - 点を足す・消す操作は無い。
- 部屋の範囲（S18）は、数量タブの一覧で「名前を変える」「削除」だけ。形は直せない。
  - 範囲は `store.roomRegions`（ページ → 一覧）。`setRoomRegions(pageIndex, regions)` で 1 回の Undo。
  - 図面には `AnnotationLayer.tsx` 1167 行付近で描く（`pointer-events: none`）。
  - 囲む操作は `MeasurementOverlay.tsx` の `capturingRoom`。既存の拾いへ部屋を入れるかの確認は `RoomPickupDialog`。
- `AnnotationLayer` のダブルクリックは `measurement.doubleClick()`（引数なし）を呼ぶ。

## 変更内容

### 1. 面積の点を足す・消す

- 対象：選択の道具で 1 つだけ選んだ注釈のうち、`measure.kind === 'area'` のもの（計測の面積、数量拾いの `polygon`・`polygonDepth`）。
  - 長さの拾い・計測の距離や周長・雲形は対象外。線の拾いは、頂点の番号に立上り・立下りがひもづくため。
- 辺の中点に、点を足すつまみ（小さな丸、`data-measure-midpoint={辺の番号}`、`data-annotation-id`、`data-testid="measure-midpoint-{番号}"`）を出す。
  - 閉じた多角形なので、最後の点と最初の点の辺にも出す。
  - 見た目は、今の頂点のつまみより小さく、白地に青の枠。頂点のつまみと区別できること。
- 中点のつまみを押してドラッグ → 辺の間に新しい点を入れ、その点を動かす（今の頂点のドラッグと同じ描き方・スナップ・Shift）。離すと `updateMeasureVertices`（1 回の Undo）。
  - 押してそのまま離した（ほとんど動かさない）ときは、中点に点を入れる。
- 頂点のつまみをダブルクリック → その点を消す（1 回の Undo）。
  - 点が 3 つのときは消さず、状態の欄に「面積の点は3つより少なくできません」と出す。
- 点は 500 まで。超えるときは足さず、「点は500までです」と出す。
- 除外範囲（`holes`）は動かさない（外形を動かしたときと同じ）。

### 2. 部屋の範囲の形を直す

- 数量タブの部屋の一覧の各行に、ボタン「範囲を直す」を足す（「名前を変える」の前）。
  - 押すと、その範囲を直す状態にする（`store.startRoomEdit(pageIndex, id)`・`roomEditTarget: { pageIndex; id } | null`・`endRoomEdit()`。保存しない、履歴に入れない）。
  - 直している間は、そのボタンを「直し終える」にする（押すと終える）。
  - 部屋の範囲を囲む状態（`roomCapturePage`）・除外範囲を囲む状態とは同時に使わない（どれかを始めたら他は終える）。
- 直している間の図面：
  - その範囲を、ふだんより濃い枠で描き、頂点のつまみ（`data-room-vertex={番号}`）と辺の中点のつまみ（`data-room-midpoint={番号}`）を出す。つまみは押せる（`pointer-events`）。
  - 案内を出す：「部屋の範囲の点をドラッグで動かし、辺の中の○をドラッグで点を足します。点のダブルクリックで消します（Enter・Esc で終える）」。
  - 頂点のドラッグで動かす。中点のドラッグ（またはそのまま離す）で点を足す。頂点のダブルクリックで消す（3 点より少なくしない。500 点まで）。スナップ・Shift は面積の頂点と同じ。
  - 1 回の操作（離したとき・ダブルクリック）ごとに `setRoomRegions` で 1 回の Undo。名前・階・id は変えない。
  - つまみ以外の図面の操作（拾い・選択）は、今の部屋を囲む状態と同じく止める。
  - 範囲の表示を消している（`showRoomRegions` が false）ときも、直している範囲は描く。
- 終えるとき（Enter・Esc・「直し終える」）：
  - 形を変えていて、範囲の中に、部屋名（範囲に階があれば階も）が範囲と違う拾いがあれば、S18 と同じ確認を出す：「この範囲の {N} 件の拾いの部屋を「{部屋名}」にしますか（Ctrl+Z で戻せます）」［部屋を入れる］［入れない］。対象はその違う拾いだけ。
  - 範囲の外に出た拾いの部屋は変えない。
- 次のときは、確認を出さずに終える：ページを替える、道具を替える、範囲を削除した（Undo で消えたときも）、別の範囲を直し始める、部屋の範囲を囲み始める。

### 3. ヘルプ（`src/app/HelpDialog.tsx`）

部屋の範囲の説明（S18 で足した段落）の後に足す：

> 部屋の範囲は、一覧の「範囲を直す」で形を直せます。点をドラッグで動かし、辺の中の○をドラッグすると点を足せます。点をダブルクリックすると消せます。Enter か Esc で終えます。形を変えたときは、範囲の中で部屋が違う拾いに部屋を入れるかたずねます。計測の面積と「囲む」で拾った面積も、選択の道具で選ぶと同じように点を足せます（点のダブルクリックで消す）。

## 変えないこと

- 頂点のドラッグで動かす今の操作（面積・線・雲形とも）。線の拾いの頂点の数。
- 部屋の範囲が無いページ、面積を選んでいないときの表示と速さ。
- 保存の形（S18 のまま）。

## 試験

**単体**：
- 多角形に点を足す・消す純粋な関数を作るなら、その試験（辺の番号、最後の辺、3 点の下限、500 点の上限）。
- ストア：`startRoomEdit`・`endRoomEdit`、囲む状態との排他、範囲の削除で終わる。

**画面**（新規 `e2e/polygon-vertex-edit.annotate.spec.ts`。部屋の手順は `e2e/room-regions.annotate.spec.ts` を参考に）：
1. 面積の拾い（囲む、四角）を選び、辺の中点をドラッグ → 点が 5 つ、値が変わる。Ctrl+Z で 4 つに戻る。
2. 頂点をダブルクリック → 点が 1 つ減る。3 点のときは消えない。
3. 計測の面積でも 1 と同じ。
4. 部屋の範囲を囲み、「範囲を直す」→ 頂点をドラッグして範囲を広げる → 1 回の Ctrl+Z で戻る。中点のドラッグで点が増える。
5. 広げた範囲の中に、別の部屋の拾いがある → Enter で終えると確認が出る →「部屋を入れる」で部屋が変わる。
6. 直している間に「範囲を直す」の範囲を削除（Ctrl+Z で囲んだのを戻すなど）→ 直す状態が終わる。
