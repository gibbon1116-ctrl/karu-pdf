# SPEC-T13: 連動の自動の元を「起点と同じ名称の項目」に限り、同じ壁・床の二重計上をなくす

## 実行モデル指定（必須）

- モデル: `gpt-6.1-sol` / reasoning effort: `high`
- 選定理由: 連動の自動の元の条件（保存形式の省略可能フィールドの追加を含む）と点検の判定を、二重計上の防止のために同時に直す判断を伴うため。

## 不具合（Claude が e2e と実データで確認）

T9・T12 の連動の自動の元は、関連ルールの起点の条件（`origin.any` の `names` 全部）を `auto.originAny`・`auto.nameIncludes` に写している。
A-wall-01（壁の品目 → 墨出し）の起点の名称は「壁ボード撤去・軽量鉄骨壁下地撤去・壁紙撤去・壁仕上げの撤去・間仕切壁の撤去・軽量鉄骨壁下地・ビニル幅木・壁せっこうボード張り・壁タイル張り・壁仕上げ…」の15語で、**同じ壁の下地・ボード・仕上げ・撤去・幅木の数量がすべて合計される**（同じ壁を何重にも数える）。幅木・壁紙張り・床仕上げ・天井の廻り縁なども同じ。

## 変えること

### 1. 自動の元は「押した起点と同じ名称の項目」（`src/app/relatedLinkRules.ts`）

- 計画関数が作る連動の `auto` は、ルールの起点の条件ではなく、**押した起点の名称**から作る:
  - `auto.nameIncludes = [origin.name]`（同じ名称の項目は、拾い方〈囲む・長さ×高さ・線〉や略号・規格が違ってもすべて元になる。後から拾った同じ名称の項目も自動で入る）。
  - 起点の名称に「撤去」を含まないときは `auto.nameExcludes = ['撤去']`（新しく足す省略可能フィールド。名称に含む項目を除く）。
  - `auto.kinds`・`factorFrom`・`sizeMatch` は今までどおり。
  - `auto.originAny`・ルール由来の `categories` は、計画関数では付けない（既存の保存データに付いている `originAny` の読込・計算はそのまま動くこと）。
- 起点の名称が空・40字超・改行を含むなど、`auto` の検証に通らないときは `sources: [origin]`（押した1項目）にする。
- RC・鉄骨・発生材などの標準の連動規則（`STD`）の `auto` は変えない（規則の条件のまま）。

### 2. `LinkAutoSources.nameExcludes`（`src/core/breakdown/linkRules.ts` の型、`src/core/fixtureLink.ts`）

- `nameExcludes?: readonly string[]`（1〜20件、各40字、前後空白・改行なし）。検証・保存・複製・`fixtureLinkSources` の照合（名称にどれかを含む項目を元にしない）に足す。
- `FixtureDialog.tsx` の自動の元の説明（`autoDescription`）・規則との一致判定（`autoKey`）に足す（説明: 「名称に『撤去』を含む項目を除く」）。
- 旧データ（`nameExcludes` 無し）はそのまま読めること。

### 3. 点検（`src/app/relatedLinkAudit.ts`）に二重計上の判定を足す

- 連動の行ごとに、ルールの起点の品目（点検で使っている起点の品目一覧、同じルールの全起点）を `fixtureLinkSources` に通し、**元になる項目の名称がすべて起点の名称を含み、撤去の有無が起点と同じ**であることを確かめる。違えば ERROR「E9: 同じ部位の別の項目（〇〇）も元になり二重に数える」。
- 点検の CSV の `sources` 列は、自動の元の条件の要約に加えて、点検で元になった品目名（最大5件）を出す。

### 4. 試験

- `tests/relatedLinkRules.store.test.ts`: 壁 A（軽量鉄骨壁下地・長さ×高さ 10m）＋壁 B（軽量鉄骨壁下地・囲む 5m×3.6m）＋壁ボード（壁せっこうボード張り・長さ×高さ 10m）＋撤去（軽量鉄骨壁下地撤去・長さ×高さ 4m）があるとき、壁 A から墨出しを追加すると 15 ㎡（ボード・撤去を含まない）、幅木は 30 m。
- `tests/fixtureLink*.test.ts`: `nameExcludes` の検証・照合・旧データの読込。
- `tests/relatedLinkAudit.test.ts`: 実データで ERROR 0（E9 を含む）。E9 に当たる例・当たらない例の単体試験。
- 既存の試験で、連動の `auto` の形（`originAny` 等）を確かめているものは、新しい形に直す（直した試験を最後に一覧で書く）。

## 守ること

- 判定を甘くして ERROR を消さない。新しい画面・自由記入欄を作らない。保存形式には省略可能な `nameExcludes` だけを足す。
