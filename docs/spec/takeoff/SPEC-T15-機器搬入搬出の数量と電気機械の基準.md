# SPEC-T15: 機器搬入・搬出の数量が 0 になる不具合と、電気・機械の基準の違いへの対応

## 実行モデル指定（必須）

- モデル: `gpt-6.1-sol` / reasoning effort: `high`
- 選定理由: 連動の計算・保存形式（省略可能フィールド）・3か所の連動の作成処理を、電気と機械の基準の違いに合わせて同時に直す設計判断を伴うため。

## 不具合（利用者の報告 2026-10-18）

電気の「機器搬入」（区分を選ばずに標準マスタから追加）で、高圧引込盤（1面・質量 500kg・外形あり）が 0 t になる。見本は「高圧引込盤 1面 × 質量 500kg × 補正率 適用なし ÷ 1000（容積品・補正率 適用なし） = 0 t（容積品）」。

原因（Claude が確認）:
- 区分（重量品・容積品）を選ばないと、連動の `carry.class` が `'heavy'` になる（`linkFromRule.ts`・`FixturePresetDialog.tsx`）。
- 計算（`fixtureLink.ts` の carry）は、元の区分（質量÷容積 600kg/㎥ 以上が重量品）が連動の区分と違うと、警告なしで 0 にする。高圧引込盤は容積品なので 0。
- 電気にも機械にも同じ自動の元（個数・100kg 以上の全項目）を使っている。

## 基準（Claude が利用者の PDF で確認）

- 公共建築設備数量積算基準（令和7年改定）第2編 共通事項 第1章第1節 機器搬入・搬出（電気・機械共通）: 単体の質量 100kg 以上の機器類に適用。600kg/㎥ 以上を重量品、未満を容積品に区分。重量品の質量は質量に対応した補正率、容積品の質量は容積当たりの質量に対応した補正率を乗じる。
- 公共建築工事標準単価積算基準（令和8年改定）:
  - 第3編 電気設備工事 第1章 5 機器搬入（-E22-）・第2章第2節 機器搬出: 単独の機器の質量 100kg 以上。「なお、機器は、受変電、電力貯蔵装置等とする」。歩掛り・補正率は第4編 機械設備工事による。搬入費の注がある細目工種は 表 E1-2-22 受配電盤、E1-2-23 変圧器、E1-2-24 高圧進相コンデンサ、E1-2-25 直列リアクトル、E1-2-29 直流電源装置（電力貯蔵設備）。
  - 第4編 機械設備工事 第1章第1節 5 機器搬入（表 M1-1-67・補正率 表 M1-1-68、単独搬入は 30％増し）: 単独の機器の質量 100kg 以上の機器（機器の種類を限らない）。第2章第1節 2 機器搬出（-M140-）: 機器類の搬出に適用、歩掛りは機器搬入による。

## 変えること

### 1. 区分を選ばない搬入・搬出は、元ごとに重量品・容積品を判定して合計する

- `FixtureLink.carry.class` を省略可能にする（`class?: 'heavy' | 'bulky'`）。省略は「区分を問わない（元ごとに判定）」。検証・複製・保存は省略を許す。旧データ（class あり）はそのまま。
- 連動を作るとき（下の 3 か所すべて）: 摘要の区分が「重量品」→ `heavy`、「容積品」→ `bulky`、未選択 → `class` を付けない。
- 計算（`fixtureLink.ts`）: `class` が無いときは、元ごとの区分（重量品・容積品）の補正率を使う。`class` があり元の区分と違うときは 0 のままにするが、**警告を出す**: 「〇〇は容積品（123kg/㎥）のため、区分『重量品』のこの項目には入れていません。区分を外すと重量品・容積品の両方を合計します。」
- 見本（`LinkBasisSource` の note と `FixtureDialog.tsx` の `carrySourceText`）: 「容積品 245kg/㎥・補正率 1.20」「重量品 1,250kg・補正率 0.85」のように、区分・根拠の値・補正率を出す（「適用なし」を出すのは対象外の元だけ、理由付き: 100kg未満・質量未設定・外形未設定・区分違い・対象外の機器）。
- 連動の画面の区分の選択（`FixtureDialog.tsx` の `fixture-link-carry-class`）を 3 択にする: 「両方（元ごとに判定）」（既定）・「重量品だけ」・「容積品だけ」。摘要の区分を変えたら連動の区分も合わせる（未選択 → 両方）。

### 2. 電気と機械で自動の元を分ける

- `LinkAutoSources` に省略可能な `books?: readonly BreakdownBook[]` を足す（1〜4件）。照合: 元の項目に内訳書の位置（`breakdown`）があり、その `book` が含まれないときは元にしない。位置の無い項目は今までどおり元になり得る。検証・複製・`autoKey`・`autoDescription`（「内訳書が電気設備の項目」）に足す。
- `src/core/breakdown/linkRules.ts` に `carryAutoFor(book: BreakdownBook | undefined, base: LinkAutoSources): LinkAutoSources` を足す:
  - 電気設備: `base` ＋ `books: ['電気設備']` ＋ `nameIncludes: ['受配電盤', '受電盤', '配電盤', '引込盤', '高圧', 'キュービクル', '変圧器', 'トランス', 'コンデンサ', 'リアクトル', '直流電源', '蓄電池', '電力貯蔵', '無停電']`（受変電・電力貯蔵装置等。根拠を JSDoc に書く）。
  - 機械設備: `base` ＋ `books: ['機械設備']`（機器の種類を限らない）。
  - それ以外・不明: `base` のまま。
  - 規則 `carry-in`・`carry-out` の note を、電気と機械の違いが分かる文に直す。
- `linkFromRule(rule, name, summary, book?)` に内訳書の編を渡し、carry のときは `carryAutoFor` を使う。呼出側: `FixtureDialog.tsx`（`value.breakdown?.book`）、`relatedLinkRules.ts` の標準規則の計画（`target.breakdown?.book`）。
- `FixturePresetDialog.tsx` の標準マスタから追加するときの連動の組み立て（325〜400行付近）は、独自に組み立てずに `linkFromRule` を使う（rc・shape・crossing・steel の既存の判定・`hasSource` の判定は変えない）。

### 3. 機械の「機器搬出」を標準マスタに足す

- `src/core/breakdown/mechanicalDetails.ts` の `'搬入・据付費'` に `{ name: '機器搬出', unit: 't', linked: 'carry', summary: [slot('区分', list('重量品、容積品'))], note: '改修の撤去機器（単価積算基準 第4編第2章第1節2）' }` を足す。規則 `carry-out`（撤去（廃棄）の機器を元にする）が付くこと。

## 試験（vitest）

- `tests/fixtureLink.test.ts`（又は新しい `tests/fixtureLink.carry.test.ts`）:
  - 高圧引込盤（電気設備・1面・500kg・外形 1,000×2,350×1,000mm → 213kg/㎥・容積品 補正率 1.70）＋送風機（機械設備・800kg・外形 1,000×1,000×1,000 → 800kg/㎥・重量品 1.10）。
  - 電気の機器搬入（区分なし）= 0.5 × 1.70 = 0.85 t（送風機は入らない）。機械の機器搬入（区分なし）= 0.8 × 1.10 = 0.88 t（高圧引込盤は入らない）。
  - 区分「重量品」の電気の機器搬入は 0 t ＋区分違いの警告。区分「容積品」は 0.85 t。単独搬入は ×1.3。
  - 電気の機器搬入の元に、名称に受変電の語の無い電気の機器（例: 照明制御盤 150kg）は入らない。
  - 旧データ（class: 'heavy'、books 無し）は今までどおり計算できる。
  - `books`・`class` 省略の検証・複製・読込。
- `tests/catalog.test.ts` 等: 機械の機器搬出が標準マスタにあり、規則 carry-out が付く。区分未選択で追加すると `class` が無い連動になる。
- 既存の試験で、区分未選択 → heavy を前提にしているものは直す（直した試験と理由を最後に一覧で書く）。e2e `linked-fixtures` の「標準マスタの機器搬入は重量品の補正率と単独搬入を反映する」は区分「重量品」を選ぶ操作なので、通ることを確かめる想定で変えない。

## 守ること

- 補正率の表（`linkData.ts`）の値は変えない。新しい画面・自由記入欄を作らない。保存形式に足すのは省略可能な `books` と、`class` の省略だけ。
