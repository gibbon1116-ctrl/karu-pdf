かるPDF — HTML ファイル1つの版（固定・閉域）

1. ZIP を展開したフォルダを、自分の PC または共有フォルダに置きます。
2. 「デスクトップにショートカットを作る.cmd」を1回ダブルクリックします。
   デスクトップとスタートメニューに「かるPDF」ができます。管理者権限は不要です。
3. 以後は、デスクトップの「かるPDF」から起動します。
   Edge（無ければ Chrome）の、タブ・アドレスバー・お気に入りの無い専用の窓で開きます。
4. ショートカットを作らずに使うときは「かるPDFを開く.cmd」をダブルクリックします。
   HTML を直接ダブルクリックすると、普通のタブで開きます（編集機能は使えます）。
5. フォルダを移したら、もう一度 2. を行います。
6. 組織のポリシーで cmd・PowerShell・file:// が禁止されている場合は使えません。

PDF を開き、編集して、上書き保存または別名で保存します。
PDF の本体はブラウザの中だけで処理し、最近使ったファイルにも保存しません。
起動用のファイルは Windows 標準の PowerShell 5.1 を使い、普段のブラウザの
プロファイルで開くため、最近使ったファイルを引き継ぎます。
普通のタブで開いたときの案内は「今後表示しない」で消せます。
新しい版は配布物を一式差し替え、2. をもう一度行います。自動更新はありません。

受け取った HTML の SHA-256 を PowerShell で確認してください。
  Get-FileHash -LiteralPath .\karu-pdf-v1.1.0.html -Algorithm SHA256
結果を、信頼できる経路で受け取った karu-pdf-v1.1.0.html.sha256 の値と比較します。
ZIP 全体も同じ方法で .zip.sha256 と比較してください。
ハッシュの一致だけでは配布者の真正性は証明できません。

印刷はブラウザの PDF 表示タブから行います。ポップアップを許可してください。
印刷タブが表示できない環境では、PDF を別名で保存し、Edge で開いて印刷します。

アプリは CSP で外部通信と同じフォルダのファイルの取得を禁止します。
ブラウザ自体の通信、拡張機能、PC・OS の管理は保証の対象外です。
組織のブラウザのポリシーで file://、Blob Worker、WASM、ファイル選択が
禁止されている場合は使えません。管理者に確認してください。
file:// の IndexedDB は別のローカル HTML と保存場所を共有しうるため、
信頼できないローカル HTML を同じブラウザで実行しないでください。

LICENSE、THIRD_PARTY_LICENSES、VERSION.txt、SHA256SUMS.txt、SBOM.cdx.json は
配布記録とライセンス確認のため、HTML とあわせて保管してください。
