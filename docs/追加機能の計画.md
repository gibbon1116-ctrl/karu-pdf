# 追加機能の計画（第1版の後）

2026-09-30 に、利用者の要望と、こちらからの提案をもとに決めた。**動きを重くしないこと**を、すべての機能の条件とする。重い処理は、ボタンを押したときだけ動かす。

## 利用者の要望（2026-09-30）

- ページ整理でページを選んだら、その内容を大きく表示したい。
- ページ整理で、方向キーで選択を動かしたい。
- 文字を選択できない、画像だけの PDF として保存したい。
- 上部のメニューは一覧できるが、まとまりがない。プルダウンにしたい。
- 「回転▼」などのプルダウンが、外をクリックしても閉じない（不具合）。

## 提案から利用者が選んだ機能

- 確認の機能: 文字の検索（Ctrl+F）、しおり（目次）の表示、書き込みの一覧と CSV 出力、距離・面積の計測
- 書類づくりの機能: ページ番号・ヘッダー・フッター、画像（写真）→ PDF、2つの PDF の比較、左右に並べて表示

| 02b | ページ整理のプレビュー欄、方向キーでの選択、拡大プレビュー |
| 02b-2 | 書き込みのコピーと貼り付け（複数の選択を含む）、透明度（文字と背景を別々に）、記号の大きさ、蛍光ペンの後は選択に戻る（2026-09-30 の追加の要望） |
| 02c | 画像として保存 |
| 02d | 左の欄のタブ化（ページ一覧・しおり・検索・書き込みの一覧）、文字の検索、しおりの表示、書き込みの一覧と CSV 出力 |
| 02d-2 | 文字の選択とコピー、選んだ文字へのハイライト・下線・取り消し線（2026-09-30 の追加の要望） |

## 上部のメニューの形（利用者が選んだ形）

```
┌──────────────────────────────────────────────┐
│ ファイル▼  編集▼  表示▼  ページ▼  ヘルプ▼        設計図.pdf ● │
├──────────────────────────────────────────────┤
│ [選択] [文字▼] [図形▼] [ペン▼] [記号] │ ↶ ↷ │ − 100% ＋ 幅 │
└──────────────────────────────────────────────┘
```

- 「文字▼」「図形▼」「ペン▼」は、最後に使った道具をそのまま押せる形（分割ボタン）にする。
- 新しい機能は、このメニューに加えていく（例: ファイル▼ → 画像として保存、ページ▼ → ページ番号、表示▼ → 左右に並べて表示）。
